Description

This task is a follow-on to:
https://jira.duraspace.org/browse/FCREPO-1703

When versioning containers, the UUID of the version shows up in the HTML UI display. To reproduce:

  • Create a container
    curl -i -XPUT localhost:8080/rest/book
  • Version the container
    curl -i -XPOST -H"slug: v0" localhost:8080/rest/book/fcr:versions
  • View the version in the HTML UI
    ...boom, see UUID in breadcrumb and resource title
