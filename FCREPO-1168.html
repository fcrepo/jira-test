Description

Currently, our deployed version of Apache Commons Pool is 1.3, which is pretty old. This comes from a dependency of commons-dbcp. Other libraries already in play ask for newer versions of Commons Pool (e.g. activemq-pool wants commons-pool 1.5.6).

Commons Pool 1.6 provides a generics-enabled API which is much more pleasant to work with. It might be best if we try to step up to that and "bring along for the ride" any libraries which turn out to be incommoded by the change.
