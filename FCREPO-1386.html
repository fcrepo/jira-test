I am not sure exactly which classes are in scope for this task, but in general, I prefer the guaranteed existence of instance variables provided by dependency injection via constructors versus via setters.

A. Soroka, 2015-03-04 16:38 UTC

"Constructor arguments vs. method parameters" is orthogonal to whether or not DI is in use at all.

The habit in much of the rest of the F4 work has been to use a constructor argument only when there is no sensible default for the reference but the reference must be available. That's hardly universal, tho'.
