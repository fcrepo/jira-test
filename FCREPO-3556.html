Description

Currently the migration utils outputs the OCFL root directly in the output directory.  So if you specify "output" as your directory,  your migrated OCFL we live at output/ocfl-root .   This is inconvenient since Fedora 6 expects the directory structure under fcrepo.home to look like this:  <fcrepo.home>/data/ocfl-root. 

The task here is to update migration utils to output to the fcrepo home directory structure (fcrepo-home by default) ie (<output-dir:  fcrepo-home>/data/ocfl-root).
