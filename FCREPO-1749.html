A. Soroka, 2015-11-02 11:46 UTC

The current repo ontology proposes that Fedora resource-types are subtypes of LDP types. It would be more accurate to say that Fedora resource-types map to subtypes of LDP types via a "represented-by" relation. This is because LDP types feature particular interaction models that Fedora resources only acquire when represented in HTTP. For example, operating on a serialization of a Fedora object on disk (a use case that many users have) means that the LDP interaction models are meaningless and irrelevant. The ldp-fedora-mapping ontology shows this mapping. To complete this ticket correctly, that mapping should be finished (accounting for all the various kinds of Fedora resource) and the subtype-of relationships in the main ontology should be removed.
