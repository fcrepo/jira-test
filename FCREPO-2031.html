Andrew Woods, 2016-11-14 21:09 UTC

There are triples and headers that indicate:

  • where versions of a resource can be found
  • where the fixity service for a resource can be found
  • where the endpoint to start a batch-op can be found.

That is what I meant by "advertise". Fedora users should be following these links that advertise the location of various services and resources. Ideally, the the fcrepo-java-client README would illustrate exactly those types of usage patterns.
