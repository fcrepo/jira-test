Danny Bernstein, 2017-10-03 19:18 UTC

WebAC currently works in conjunction with the container managed authentication.  Namely the former depends on the later to work.  However,  the security constraints are defined in web.xml which does not allow for deploy time modification.  In other words,  once security constraints are introduced in web.xml, they can't be changed or disabled based on a system property or any other mechanism.  Since this capability doesn't seem to be a requirement for any production systems, I suggest we bring this, as well as this related issue (https://jira.duraspace.org/browse/FCREPO-2637)  on the next fedora tech call.
