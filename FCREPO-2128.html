The RDF Serializer code is just few brief Camel routes:

https://github.com/fcrepo4-exts/fcrepo-camel-toolbox/blob/master/fcrepo-serialization/src/main/java/org/fcrepo/camel/serialization/SerializationRouter.java

For example, the route to serialize metadata is:

from("direct:metadata")
    .routeId("FcrepoSerializationMetadataUpdater")
    .to("fcrepo:{{fcrepo.baseUrl}}?accept={{serialization.mimeType}}")
    .log(INFO, LOGGER,
            "Serializing object ${headers[CamelFcrepoIdentifier]}")
    .setHeader(FILE_NAME)
        .simple("${headers[CamelFcrepoIdentifier]}.{{serialization.extension}}")
    .log(DEBUG, LOGGER, "filename is ${headers[CamelFileName]}")
    .to("file://{{serialization.descriptions}}");

So I don't think we can import or copy this code, but it's still useful for documenting the serialization format.
