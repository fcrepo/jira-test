Description

When attempting to view the content of a Redirect-type datastream via the web admin, an error is produced: "Security error accessing url" even if the redirect points to url with no security requirements.

To Reproduce: Use the web admin to create an R datastream with location set to: http://www.yahoo.com, then attempt to view the content.
