Description

If you put up an authorization without an acl:accessTo or acl:accessToClass defined then the authorization is completely useless.

Because we are adding the ACLs to the resource it would be beneficial to assume the current resource if none is specified.

So a ACL submitted to http://localhost:8080/rest/test_resource/fcr:acl of

<> a webac:Acl .

<#authorization1> a acl:Authorization ;
   acl:mode acl:Read ;
   acl:agent "testuser" .

 

Would be parsed and stored as if it was

</rest/test_resource/fcr:acl> a webac:Acl .

</rest/test_resource/fcr:acl#authorization1> a acl:Authorization ;
   acl:mode acl:Read ;
   acl:agent "testuser" ;
   acl:accessTo </rest/test_resource> .
