FCREPO-663 Remove XML/HTML documents from Java code and use templates instead

Depends onFCREPO-738 The REST api create xml return values by hand

Description

There are a number of occurrences where xml or html documents/fragements are embedded within the code. This has an impact on maintainability,readability,testability and separation of concerns. Most documents could easily be factored out by using a template engine, such as StringTemplate (http://www.stringtemplate.org).
