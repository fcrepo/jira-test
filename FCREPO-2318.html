Description

The RdfNamespaces class is unnecessary and should be removed from fcrepo-camel. There are plenty of other places where those values are defined (e.g. jena, fcrepo-vocabulary, etc). Code that uses those values (fcrepo-camel-toolbox) should be updated to make use of those other projects.
