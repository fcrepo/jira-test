FCREPO-1844 migration-utils should ignore corrupt import files

Description

When running migration-utils to import content (particularly fedora3-exported content), if there is a file that won't import correctly the process will die with errors.

Perhaps this is desired functionality; however, if there is a .DS_Store file or other hidden file the process will die with a message like "Content is not allowed in prolog". The migration-utils app should either:

1. automatically ignore these types of files, or
2. have an ignore file with these kinds of files pre-populated, or
3. evaluate the files and display a list of problems with the suggestion to delete or fix them
