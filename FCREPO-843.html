FCREPO-843 Ban all known slf4j bindings except logback

Fix versionsFedora 3.4.2

Description

If multiple slf4j bindings are in the classpath at runtime, slf4j behaves unexpectedly. Although none of our transitive dependencies currently pull in other slf4j bindings, it could happen, unnoticed, as new dependencies are added. This change ensures that the build fails (so it gets noticed) if bindings besides logback are brought into Fedora's dependency tree.
