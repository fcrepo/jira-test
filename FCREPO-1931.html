FCREPO-1931 Fedora 4 returns a 400 error when uploading a file larger than the available space in the temp directory.

Description

When uploading a large file Modeshape stores it in the temp directory. If there is insufficient space, a 400 error is returned with no useful message. It is especially difficult to debug this error since there is no stack trace (no matter how much logging is enabled) and because, non-intuitively, fedora 4 writes to the temp space, which may be on a different volume than the storage space fedora is configured to use.

I would probably go for 507 (Insufficient Storage) as per that link to WebDAV extensions.
