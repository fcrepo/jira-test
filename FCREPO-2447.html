Description

The WebApplicationException is designed to be associated with a HTTP status (500 by default; cf https://docs.oracle.com/javaee/7/api/javax/ws/rs/WebApplicationException.html). The WebApplicationExceptionMapper should choose it's log level based on the HTTP status borne by the exception: I would recommend ERROR for 5xx, WARN for 4xx, and INFO for 3xx.
