Description

The task here is to add a method to OCFLObjectSession
CommitOption getCommitOption()

This method will return the appropriate CommitOption based on a system property.

With this feature in place,  the CommitOption param can be removed from PersistentStorageSession.commit().

In the future, the commit option will be configurable per OCFL object. 

The default option will be UNVERSIONED.   The user will be able to change that value at runtime by setting the system property "fcrepo.autoversioning.enabled" to "true"
