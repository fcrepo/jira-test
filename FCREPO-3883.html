Description

Currently the only way to re-use a URI in Fedora is to delete & purge the URI. Then PUT a new object at that URI.

With https://fedora-repository.atlassian.net/browse/FCREPO-3881 we are disallowing this pattern for parts of an Archival Group which prevents the re-use of a URI without deleting the entire object.

This ticket is to consider whether we should and if we do, how we might implement the ability to PUT over a tombstone to recreate the object.

Considerations:

  • We would need a check to ensure the PUT is understood to be re-creating the object. i.e. some header must be included.
  • This PUT would be considered part of the previously deleted object, so there would be no change to interaction model allowed.
  • The previous version history of the object would also be maintained.
  • The previous version history of the object would contain versions where the version was DELETEd and you will get a 410 Gone
