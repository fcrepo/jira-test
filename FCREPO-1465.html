Michael Durbin's response for the above error.

Seems like it's a problem with the idresolver.

We can either fix the id resolver or add a new one that works for your directory structure.

First, pull down the latest version of migration-utils (I just pushed a change) and run the program again. You should get a better error message.

Second, look in the datastream directory and let me know what some of the filenames look like (when you get down to the files).

Third... there's a slim chance you have a cache problem... delete whatever directory your idresolver is using for its cache and try again. (in the indexRoot) bean.
