Description

The server currently disallows edit of METHODMAP, DSINPUTSPEC and WSDL datastreams of BMechs/BDefs. Now that we have CMDA we longer need this safety precaution.

Completion of this item:

MUST remove from the SERVER the current constraint that these datastreams cannot be edited. See the fedora.server.management package.

SHOULD add a test to the TestAPIM suite that modifyDatastream requests to these special datastreams succeed.
