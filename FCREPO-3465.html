FCREPO-3465 Creating a memento on a resouce should always create a new memento

Description

The memento creation behavior from F5 to F6 changed. In F5 you could always create a memento on a resource regardless of whether or not the resource changed since the last memento was created. Because of the relationship between mementos and OCFL versions, this behavior was changed in F6 so that a new memento is only created if the resource was changed since the last memento was created.

The problem with the current F6 behavior is that mementos also capture containment and membership, which is not related to whether or not the resource has changed. This means, that its impossible to create a memento to capture containment or membership changes.

The F6 behavior should be reverted to the original F5 behavior. In order to achieve this, the last modified timestamp in the resource headers must be modified on every create memento request.
