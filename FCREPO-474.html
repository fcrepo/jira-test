Description

Richard Green reports:

We have recently had a small issue with oaiprovider when the British Library tried to harvest our thesis metadata. Using the ListRecords verb results in a set of records each wrapped as

<record xmlns="http://www.openarchives.org/OAI/2.0/ <http://www.openarchives.org/OAI/2.0/> ">
...
</record>

Instead of just

<record>
...
</record>

This caused them some problems because one of their transforms wasn't set up to deal with this response which seems, from the OAI-PMH spec, to be non-standard.

To fix this issue, Simon removed the following from Line 173 of FedoraOAIDriver.java :-

out.println("<record xmlns=\"http://www.openarchives.org/OAI/2.0/\">");

And replaced with:-

out.println("<record>");
