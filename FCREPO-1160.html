FCREPO-1160 FESL LDAP AuthN should reject blank passwords

Description

If the FESL LDAP authN module is configured with a simple bind strategy, then blank passwords may be accepted as valid credentials when the backing LDAP server permits anonymous binds. While this can be corrected by using with search-and-bind configurations, it is almost certainly not expected and should not be the default behavior. If necessary, a configuration option may preserve the behavior.
