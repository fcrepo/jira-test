Description

When performing a PUT request on a binary resource, a stacktrace is returned to the user.

Instead, a "405 Method Not Allowed" https://httpstatuses.com/405.

To reproduce:

  • Create a binary resource
    • curl -i -ufedoraAdmin:fedoraAdmin -XPUT --data-binary "some-content" -H"Content-Type: text/plain" localhost:8080/rest/binary
  • Attempt to create a child of the binary resource
    • curl -i -ufedoraAdmin:fedoraAdmin -XPUT localhost:8080/rest/binary/xx
    • BOOM!
