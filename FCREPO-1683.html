Description

This is a ticket to track the migration of github repositories to their "proper" home, as discussed at various tech meetings. This is mostly about projects moving from fcrepo4-labs to fcrepo4-exts or from fcrepo4 to fcrepo4-exts.

Most projects will include a minor PR to update SCM information listed in the maven configuration.
