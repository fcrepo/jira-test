FCREPO-2468 import/export tool should support certificate authentication

TypeNew Feature
StatusOpen
PriorityMajor
ReporterJoshua Allan Westgard
Created2017-05-22 22:00 UTC
Updated2017-05-23 13:11 UTC
Componentsf4-import-export

Description

For production servers, basic authentication poses a security risk in that username/password gets persisted to a configuration file and/or must be entered as a command line argument. A better solution for production use of import/export would be certificate authentication.

Presumably this would require:
1. ability to enter client_cert and client_key params pointing to location of those items locally
2. persist the path to the cert/key as part of the config file so it can be used by the verification tool or when import/export is re-run.
