Description

While running a custom process that performs many Fedora reads (including retrieval of RDF in XML format), I encountered an intermittent problem with a java.lang.IllegalStateException being thrown. This occurred 32 times over the course of 3 days, at a time when at least 600,000 requests were made. Retrying always succeeded, so the problem was intermittent – presumably related to system resources rather than specific data.

See an example backtrace in the attached trace.txt for more details.

Demian Katz, 2022-08-20 12:21 UTC

From Peter Winckles in Slack

The issue here is that there's an encoder being used as a singleton, but it's actually not thread-safe. Per the javadoc in CharsetEncoder:

Instances of this class are not safe for use by multiple concurrent threads.
