Reported by Stuart Chalk: SaxonServlet startup fails with this version of Tomcat due to the webapp not including the commons-logging library in WEB-INF/lib. Although older versions of Tomcat work due to an implementation detail of Tomcat, there should no harm in including this in the webapp.

Whoever takes this on, can check if it's true for the other localservices as well? Feel free to widen the scope of this bug if so.
