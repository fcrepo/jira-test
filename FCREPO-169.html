Description

While it is no problem to store a 2 GB file in Fedora it seems to be impossible to get that file back from Fedora.

After digging into the source code I found a check for a maximum file size in

fedora.server.storage.lowlevel.GenericFileSystem line 170:

if (lFileLength > Integer.MAX_VALUE) {
throw new LowlevelStorageException(true, "file " + getPath(file) + "too large for reading");
}

What is the reason behind that check? Could the check be removed?

In my tests I could successfully retrieve a 2 GB file after commenting out the above code.
