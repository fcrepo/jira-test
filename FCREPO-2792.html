Description

To reproduce: 

1. Create versioned resource 

curl -i -XPOST  -H "Slug: versioned_resource4" -H "Link: <http://mementoweb.org/ns#OriginalResource>; rel=\"type\"" "http://localhost:8080/rest" -H "Content-Type: text/plain" --data-binary "Test" 

2. verify that metadata versions endpoint returns 200 

curl -v -X GET http://localhost:8080/rest/versioned_resource4/fcr:metadata/fcr:versions

3. create a binary version against binary timemap

curl -v -X POST  http://localhost:8080/rest/versioned_resource4/fcr:versions

4.  verify that the binary description timemap is there and is listing the newly created description memento 

curl -v -X GET http://localhost:8080/rest/versioned_resource4/fcr:metadata/fcr:versions 

5. Create a second binary description memento

curl -v -X POST  http://localhost:8080/rest/versioned_resource4/fcr:metadata/fcr:versions

6.  Now call the binary description timemap 

curl -v -X GET http://localhost:8080/rest/versioned_resource4/fcr:metadata/fcr:versions

It should return a 200. It returns a 404.

7. Now delete the previously created binary description memento.

curl -v -X DELETE http://localhost:8080/rest/versioned_resource4/fcr:metadata/fcr:versions/<memento>

8.  Now call the binary description timemap again and verify that it now returns 200 with a listing of the original description memento.

curl -v -X GET http://localhost:8080/rest/versioned_resource4/fcr:metadata/fcr:versions

Danny Bernstein, 2018-05-07 20:55 UTC

The problem appears to be right here:  https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-kernel-modeshape/src/main/java/org/fcrepo/kernel/modeshape/NonRdfSourceDescriptionImpl.java#L80.  In order to resolve the list of description mementos, it appears that each memento description is being loaded and the getContent() method is being called on each one of those description mementos.   The current code attempts to resolve that content node by getting the binary memento with a matching timestamp.  If no such memento exists,  as is the case when a binary description memento is created independent from the binary itself,  a PathNotFoundException is thrown.
