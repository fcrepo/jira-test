Description

curl -v -XPOST localhost:9080/reindexing -H"Content-Type: application/json" -d '["broker:queue:solr.reindex"]'

will reindex all resources.

However 

curl -v -XPOST localhost:9080/reindexing/myresource -H"Content-Type: application/json" -d '["broker:queue:solr.reindex"]'

does not reindex http://<fedora host port>/myresource as it should.
