FCREPO-1074 debug messages in gsearch 2.4 and 2.4.1

TypeBug
StatusClosed
ResolutionFixed
PriorityMinor
ReporterRastislav Hudak
AssigneeGert Schmeltz Pedersen
Created2012-03-08 04:17 UTC
Updated2012-06-20 20:12 UTC
Resolved2012-05-25 18:46 UTC
Componentslegacy - GSearch

Environment

redhat, tomcat6, fedora 3.3

Description

When I deploy fedoragsearch.war (2.4 or 2.4.1) there are debug messages turned on filling catalina.out. Everything seems to be logged, even some 'binary' data and oaiprovider stuff so the log fills extremely fast. I've tried to remove/edit all log4j.xml and logging.properties I found with no success. The logs from tomcat (and I think also gsearch itself) were turned off but there were still debug messages going in from activemq, axis and other libraries.
The only thing finally seemed to helped was using /lib dependencies from gsearch 2.3 and adding only what was necessary from 2.4 (tika-1.0, fcrepo-3.5, lucene-3.5, servlet-api-2.4).
Any idea which dependency is turning this on or what is happening?
