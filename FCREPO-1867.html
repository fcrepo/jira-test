Description

The fcrepo-kernel-api relies on javax.jcr.version.Version and javax.jcr.version.VersionHistory. If those constructs are a necessary part of the fedora API, there should be equivalent (non-JCR) types that implement these types, defined in the fcrepo-kernel-api.
