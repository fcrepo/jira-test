FCREPO-3586 Attach volume for storing OCFL data

Description

Currently the persistent state of Fedora (contained in the OCFL)  resides within the docker instance.   fcrepo-docker supports specifying an attached volume.  However fcreop-aws-deployer does not make use of this capability.

Thus it would be good if we could do the following three things: 1) by default,  create and attach an EBS volume  to the beanstalk instance and 2) enable users to specify an existing volume if they desire and 3) ensure that the mount point is passed to the docker container running on the ec2 instance.

With these updates in place it should be possible to update the docker container without losing one's repository data.
