Description

Via the use of Git submodules or some similar functionality, the metadata in the travis.yml file of individual projects should be factored out into some easily-updated master file.

The common .travis.yml should also check for javadoc errors:
mvn javadoc:jar
mvn javadoc:test-aggregate
