FCREPO-2433 Error when using fixity check on a version of binary object

Affects versionsFedora 4.7.0, Fedora 4.7.1

Environment

Ubuntu 14.04, Tomcat 7, Postgres 9.5

Description

When accessing an object with a historic version, attempting to use the fixty service on the version via the web application generates a namespace error.
http://IP:8080/fedora/path/location/object/files/binary/fcr:fixity
functions normally for the object.
When accessing version1 in the versions, using
http://IP:8080/fedora/path/location/object/files/binary/fcr:versions/versionid/fcr:fixity
generates an error.

This has been tested with Fedora 4.7.0 and 4.7.1 on both postgres and the file-simple configuration.

See attached document for the full error displayed on the site.

Tomcat error logs also include the following line:
ERROR (WildcardExceptionMapper) Exception intercepted by WildcardExceptionMapper: Error converting "fcr:fixity" from String to a Name
