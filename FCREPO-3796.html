FCREPO-3796 Disable on demand internal id translation of outgoing RDF

TypeStory
StatusReopened
PriorityMinor
ReporterDanny Bernstein
AssigneeDan Field
Created2022-01-13 17:15 UTC
Updated2024-05-23 15:55 UTC
Componentscore, f4-core
Affects versionsFedora 6.4.0

Description

RDF with subjects or objects prefixed by

 info:fedora

are automatically translated on retrieval such that "info:fedora" is replaced with the base Fedora URI. In some cases users may want to see the internal resource identifiers instead of the translated ones.

The task here is to provide a means for indicating in the request that the user would like to suppress the translation behavior. Whether this ability is accomplished by means of a query param, header, or some other means is up for discussion.
