FCREPO-1553 Add support to the migraiton-utils to explicitly (or implicitly) register useful namespace prefixes.

Description

If you create properties on a resource using an unregistered namespace the HTML UI for fedora 4 will forever present an automatically generated namespace prefix.

To improve this experience for migrated data, either allow the migration utility to specify namespace prefix mappings that will be assigned, or perhaps use the namespace prefix specified in the RELS-EXT or RELS-INT you're importing... or both.
