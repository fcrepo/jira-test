FCREPO-3360 Square brackets in pairtree id cause WebAC exception

TypeBug
StatusOpen
PriorityMinor
ReporterBen Pennell
Created2020-06-29 16:20 UTC
Updated2021-05-05 18:13 UTC
Affects versionsFedora 5.1.0

Description

Pairtree resources which contain ] and [ characters in their identifiers appear to trigger a URI parsing exception. For example, with webac enabled, if you access the following path:

http://localhost:8080/fcrepo/rest/61496e92-cc40-4e67-8b1f-719be7b160ce%5B4%5D/ab/c1/ef/obj1

where 61496e92-cc40-4e67-8b1f-719be7b160ce%5B4%5D is a pairtree node, you will get the stacktrace below.

Note: it is generally not easy to produce a pairtree with these characters, but it can occur as a side effect of https://jira.lyrasis.org/browse/FCREPO-3359
