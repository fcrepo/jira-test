Description

This task is to update the fcrepo `.travis.yml` to begin deploying Fedora snapshot Maven artifacts.
The successful completion of this task should result in snapshots being deployed on every successful build of the `master` branch to:
https://oss.sonatype.org/content/repositories/snapshots/org/fcrepo/

====
As a separate note, the current Fedora Jenkins service is unable to successfully build due to:
https://jira.lyrasis.org/browse/FCREPO-3281

In addition to building, that service is also responsible for two other tasks:

  • publishing snapshot artifacts
  • deploying the fcrepo.war to http://demo.fcrepo.org:8080/

If this ticket is successful, and we find another way of deploying the demo instance, we could potentially remove the Jenkins service.
