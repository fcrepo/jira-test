FCREPO-2813 Improved fcrepo/rest UI

TypeNew Feature
StatusOpen
PriorityMinor
ReporterNat Kanthan
Created2018-06-28 18:02 UTC
Updated2021-09-17 17:42 UTC
Affects versionsFedora 4.7.5

Description

When developing against Fedora, fcrepo/rest UI provides a quick way to check if a resource has been created, updated or deleted. Current UI is very limited. For instance, it does not have paging mechanism.

Providing a better fcrepo/rest UI would be helpful for developers, system administrators and repository administrators.

For start the following would be very helpful:

  • Paging mechanism
  • Tabular view with additional fields/properties, ability to sort on fields/properties
