FCREPO-2661 HEAD response headers should match GET request non-payload response headers

Description

Per the 28 November 2017 version of the Fedora API spec, section 3.3 HTTP HEAD:

"... the server SHOULD send the same headers in response to a HEAD request as it would have sent if the request had been a GET, except that the payload headers (defined in [RFC7231] section 3.3) MAY be omitted."

According to the HTTP 1.1 spec (RFC 7231), section 3.3, Payload semantics, the following response headers are considered payload headers:

  • Content-Length
  • Content-Range
  • Trailer
  • Transfer-Encoding

..and so may be omitted from HEAD responses.

The following test shows that a HEAD response to a resource omits the headers "Vary:" and "Preference-Applied:", which are returned by a GET request to the same resource.
