Description

Currently OCFL subpaths are expected to just be some form of string, except in the case of RDF where we add the default serialization extension to it (currently .nt).

This causes some difficulty if you have to go from filename (with extension) to subpath (basically filename with no extension).

There probably should be a centralized function to remove only those extensions that Fedora might add itself (currently just .nt)
