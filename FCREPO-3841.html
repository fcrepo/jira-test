Description

The idea is to add two headers to all API responses to help call attention to the importance of user registration.

USER-REGISTRATION: “

{user registration call to action here including link}

“

{{Link: <

{user registration link}

>; rel="user-regisration”}}

Text to be determined by Arran Griffith

If would be nice to add a system property such as fcrepo.user-registration-header.enabled (default to true) so that users can turn these messages off.
