Description

As reported on the dev list, if a dc element in the DC datastream contains an xml:lang attribute (e.g. "<dc:subject xml:lang="da">Tidsinterval</dc:subject>"), the xml:lang attribute is dropped during ingest.

Additionally, the xml:lang attribute is not dropped if the DC datastream is added via addDatastream.

This was reported against 3.0b1, but I believe this affects all versions of Fedora.
