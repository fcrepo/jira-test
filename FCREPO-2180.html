FCREPO-2180 Export utility should map URIs to info:fedora/ URIs

Componentsf4-import-export

Description

To reduce the exported RDF being tied to the original repository URIs, the export client should map the base URIs to info:fedora/ URIs. For example, the resource http://localhost:8080/rest/a/b/c should be mapped to info:fedora/a/b/c

Comments (5)

A. Soroka, 2016-09-08 12:02 UTC

I hope this is adjustable, because it's going to make it harder to use this tool to move things around live systems. E.g. to export triples from Fedora into a triplestore, if you want the URIs to remain dereference-able.

Esmé Cowles, 2016-09-08 12:06 UTC

The intention was to map the repository baseURL to info:fedora/ when exporting, and then map from info:fedora/ to the new repository baseURL when importing (since they may well be different). But it should be very easy to make the translation configurable so you could specify the baseURL.

But maybe it would make more sense to leave the export alone (export the URIs as-is), but have the import utility do the translation to the new repository baseURL?

A. Soroka, 2016-09-08 13:27 UTC

Either assuages my concern, but I incline to the latter on the principle elsewhere espoused: as far as is practical, the output of this tool should be a image of the API at the time of export.
