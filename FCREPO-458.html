Description

The indexDCFields value in fedora.fcfg controls whether DC fields are actually indexed in the underlying database or not. Normally, this is true (the default), but when set to false, indexing of modified objects fails with an ArrayIndexOutOfBoundsException.

Comments (1)

Chris Wilper, 2009-03-01 17:35 UTC

Was caused with the introduction of SQLUtilityImpl. Fixed by looping through the field array (the actual fields we're updating in the db) rather than the value array (which is larger than the field array in this case).

FieldSearchSQLImplIntegrationTest now checks for this case.
