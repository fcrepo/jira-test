Description

I was hoping to have Fedora be the canonical source of a file's mime type and let the underlying http-based storage service only be concerned with storing and slinging bits around. It seems however that Fedora passes the mime type set by the underlying storage service no matter what's set in the datastreamVersion in the object XML.
