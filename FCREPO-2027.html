Description

When you grant a non-fedoraAmin read and write permissions on a container (and all contained nodes) you'd expect them to be able to do any sort of normal read/write operations on nodes in that container.

When performing sparql update that includes a DELETE clause the following error message acompanies the 400 response. (in this case I tried to delete dc:rights from the resource /libra2/prod)

Cannot lookup child permission check information for /{}libra2/{}prod/

{http://purl.org/dc/elements/1.1/}
