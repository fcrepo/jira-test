Description

This task is to align the logging functionality with the documentation:
https://wiki.duraspace.org/display/FEDORA4x/Configuring+Logging+With+System+Properties

This ticket is complete when:
1. The default logging level is INFO
2. All logging can be changed by providing a value for the system property: -Dorg.fcrepo
3. Specific package loggers can be changed independently of 1 or 2 above.

Starting Fedora with the following logging settings should work as expected:
> mvn jetty:run -pl fcrepo-webapp/

    • log all packages at INFO

> mvn -Dfcrepo.log=DEBUG jetty:run -pl fcrepo-webapp/

    • log all packages at DEBUG

> mvn -Dfcrepo.log=DEBUG -Dfcrepo.log.jms=INFO jetty:run -pl fcrepo-webapp/

    • log all packages at DEBUG, except fcrepo.jms at INFO

> mvn -Dfcrepo.log=DEBUG -Dfcrepo.log.jms=INFO -Dfcrepo.log.kernel=INFO jetty:run -pl fcrepo-webapp/

    • log all packages at DEBUG, except fcrepo.jms and fcrepo.kernel at INFO
