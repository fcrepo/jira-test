Description

Test if filesystem backups from the fcrepo home of a live repository could be used to reliably restore the repository.
Steps:

  • Spin up a fedora repository.
  • Use multiple client scripts to load test data to the repository
  • Backup the fcrepo home directory while load scripts are actively ingesting new objects.
  • Use the backup to start a new fcrepo repository.
  • Verify that the repository starts without any issues (such as leveldb getting corrupted).
  • Make the tests repeatable
