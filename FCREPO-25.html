Is related toFCREPO-1156 Performance degradation when adding a lot of datastreams

Description

The Audit trail datastream is currently inline XML. When an object has lots of changes a large audit trail will be inlined within the object, bloating the XML file for the object. We want to be able to store the audit trail as managed content or simply in a repository log file. We should consider whether we should allow the choice to be a repository-wide configuration option, and/or an object-specific option. Also, consider what the default choice should be.
