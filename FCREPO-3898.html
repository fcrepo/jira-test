Description

The confluence documentation for fedora 6 does not currently include any information about how to set a logging configuration file. The two pages where I would have expected to find information about how to configure logging are:

https://wiki.lyrasis.org/display/FEDORA6x/Properties

https://wiki.lyrasis.org/display/FEDORA6x/Logging

But there is no mention of the “logback.configurationFile” java property in either page, and no info on how to configure logback (such as logging to a custom file), just info about separate properties for controlling some log levels. It would be helpful to expand this information, as well as possibly mentioning how logging is configured by default an where logging goes to.
