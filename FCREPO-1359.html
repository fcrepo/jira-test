Description

The RDF ontologies are transformed to HTML with some XSLT, but the resulting HTML is, perhaps, overly utilitarian. By updating the XSLT, it would be possible to improve the appearance to browser-based requests.

This would not involve changing the underlying RDF in any way – just the XSLT.
