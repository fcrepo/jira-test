BUILD FAILED
C:\fedora-src-3.1\build.xml:46: C:\fedora-src-3.1\.svn\entries doesn't exist

Comments (1)

Chris Wilper, 2008-10-27 18:14 UTC

This happens because build.xml now depends on that file to exist in order to create the installer filename with the appropriate "r1234" style svn revision suffix. This assumes the source has been downloaded from subversion.

A simple workaround is to create the file .svn/entries with the follow four lines of content:

this
is a
workaround
7809

Also, optionally, when you compile, use the -Drelease=true flag. This will prevent version mismatch warnings when running the fedora-admin java GUI.
