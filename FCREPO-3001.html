Description

Fedora is unable to import the container due to the presence of server managed namespaces. Here is the precise error coming out of Fedora: 

The http://www.w3.org/1999/02/22-rdf-syntax-ns#type predicate may not take an object in the server managed namespaces (http://www.w3.org/ns/ldp#).

Solution is to add all ldp namespaced objects to the sanitizer routine in the importer.
