Description

DOReaderCache breaks JEE compliance by implementing an unmanaged thread, which is restricted in EJB spec:

  • http://stackoverflow.com/questions/533783/why-spawning-threads-in-j2ee-container-is-discouraged
  • http://java.sun.com/blueprints/guidelines/designing_enterprise_applications/ejb_tier/qanda/restrictions.html

Furthermore the usage of List is quite peculiar, where type and semantics are dependent on the index of the object in the list.
