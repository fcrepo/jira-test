Description

The resolution to this ticket should either resolve the follow Fedora API Test Suite failures, or create follow-on tickets for their resolution.

  • https://fedora.info/2018/11/22/spec/#ldpc
    LDP Containers must distinguish [membership] triples.
  • https://fedora.info/2018/11/22/spec/#ldpdc
    Implementations MUST set the ldp:membershipResource by default when not specified on creation.
  • https://fedora.info/2018/11/22/spec/#ldpdc
    Implementations SHOULD set the ldp:membershipResource to the LDPC by default when not specified on creation.
  • https://fedora.info/2018/11/22/spec/#ldpdc
    Implementations must allow the membership predicate to be set by default to an implementation defined value.
  • https://fedora.info/2018/11/22/spec/#ldpdc
    Implementations should use the default <> ldp:hasMemberRelation ldp:member
