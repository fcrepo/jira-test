FCREPO-4101 Make premis:hasFile server managed again

TypeImprovement
StatusOpen
PriorityHigh
ReporterBen Pennell
Created2026-07-30 20:45 UTC
Updated2026-09-17 15:50 UTC
Fix versions8.0.0

Description

At present fedora supports setting premis:hasSize / premis3:size in an attempt to allow external binaries where fedora either cannot or should not retrieve the external content in order to determine the size of the file. This allowance is problematic and produces unexpected outcomes. In fedora 4 it was server managed, but we changed it to being server generated with the option to set additional values in fedora 5. Updating these properties does not actually affect Content-Size response headers in fedora 6 or 7.

We should change both premis:hasSize and premis3:size to being server managed again. Those properties should be exclusively set from the fedora header file size property. We will need to decide whether a client sending a premis:hasSize/premis3:size property in an RDF body should be silently ignored, or rejected.
