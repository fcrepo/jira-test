Description

The newest version of the import-export tool has some changes to the configuration file that it creates. The current version looks something like this:

mode: export
external: true
predicates: http://www.w3.org/ns/ldp#contains
overwriteTombstones: true
resource: http://localhost:8080/rest/pcdm
inbound: true
dir: /Users/westgard/Desktop/test
map: foo,foo/bar
binaries: true
rdfLang: text/turtle

The verification tool needs to act in a logical and appropriate manner on all these options.
