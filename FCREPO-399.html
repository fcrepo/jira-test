Description

To support continuous integration testing (and to ease on-demand test setup for developers), provide test scripts for automatically running a series of "sanity" tests. These should collectively allow one to run the existing JUnit (unit, integration, system) tests on Unix-based OSes without requiring manual installation/startup/shutdown of the test server instances.
