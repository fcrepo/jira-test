FCREPO-3788 Order of ldp:contains elements in "accept: application/ld+json" is different from "accept: text/turtle" in fcr:versions

TypeBug
StatusOpen
PriorityMinor
ReporterJakov M. Vežić
Created2021-10-18 14:04 UTC
Updated2021-10-18 15:08 UTC
Affects versionsFedora 6.0.0

Environment

Java 11, one-click jetty jar

Description

When requesting a list of versions for a binary resource, for example http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/

text/turtle returns the correct order of versions, in a descending order:

        ldp:contains           <http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20211018121711> ;
        ldp:contains           <http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20210927124149> ;
        ldp:contains           <http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20210429102326> ;
        ldp:contains           <http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20210416115949> ;

but application/ld+json returns a random order:

		        "http://www.w3.org/ns/ldp#contains": [
            {
                "@id": "http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20210429102326"
            },
            {
                "@id": "http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20211018121711"
            },
            {
                "@id": "http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20210927124149"
            },
            {
                "@id": "http://localhost:8080/rest/karaka3:1187/FILE0/fcr:metadata/fcr:versions/20210416115949"
            }
        ],
