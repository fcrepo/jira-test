Description

There is a discrepancy between the wsdl generated by fedora, and the wsdl generated by axis. i.e. http://host/fedora/services/access?wsdl and http://host/fedora/wsdl?api=API-A. Why is that? Is this actually a bug or by design. There really isn't much documentation on consumption of the services as well, so maybe that would help.

Comments (1)

Chris Wilper, 2009-11-24 05:58 UTC

The reason for this discrepancy has been documented in the WSDL section of the documentation at the following URLs:

https://fedora-commons.org/confluence/display/FCR30/API-M#API-M-WSDL
https://fedora-commons.org/confluence/display/FCR30/API-A#API-A-WSDL

The correct URL to use for on-line WSDL is the /fedora/wsdl?api=API-A or API-M one.
