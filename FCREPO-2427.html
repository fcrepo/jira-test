Description

This task is to review and update the audit logging logic to avoid output like the following:
```
2017-01-08 10:59:39,544 import /import-export-testing/data/fcrepo/rest/collection0.ttl to http://localhost:8080/fcrepo/rest/collection0/../collection0
```
Note above: "/rest/collection0/../collection0"

To reproduce the above output:
1. Create a resource in your Fedora repo (collection0)
2. Export that resource:
java -jar fcrepo-import-export-0.1.0.jar -b -a -d data -m export -r http://localhost:8080/f4/rest/collection0
3. Import that resource:
java -jar fcrepo-import-export-0.1.0.jar -b -a -d data -m import -r http://localhost:8080/f4/rest/collection0
4. Inspect log, see:
/rest/collection0/../collection0
