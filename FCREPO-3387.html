Description

This bug can be seen when attempting to create and view version in the HTML UI.

  • Start Fedora
  • Create a new resource (/rest/new)
  • In the new resource, click the button: "Create Version"
    • Notice the UI is redirected to a page with text: "No versions have been created for this resource."
  • Go back to new resource, and click the button: "View Versions"
    • Notice the UI is redirected to a page with text: "No versions have been created for this resource."
  • From command line, observe that version was actually created:
    • curl -i http://localhost:8080/rest/new/fcr:versions
