Description

This task is to upgrade F4's Modeshape dependency to 4.3.0.Final
https://issues.jboss.org/browse/MODE/?selectedTab=com.atlassian.jira.jira-projects-plugin:versions-panel

Modeshape 4.3.0.Final jumps Infinispan versions to 7.2.0.Final, more than a major version number jump. None of the Infinispan configurations now in the code base will even parse with the new version, let alone run. They must all be rewritten, and in the case of clustering config, from scratch.
