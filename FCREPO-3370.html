FCREPO-3370 Simple Search: Allow users to use K (kilobytes), M (megabytes), G (gigabytes) modifier for content size queries

TypeNew Feature
StatusOpen
PriorityMinor
ReporterDanny Bernstein
Created2020-07-08 16:41 UTC
Updated2021-07-07 17:07 UTC
Componentsf4-core
Affects versionsFedora 6.0.0
Labelsfcrepo-6.1.0

Description

Allow the user to modify the size with a B,K,M, or G rather than requiring them to specify precise numbers.  So if you want to look for all files greater than 1 gigabyte you can write content_size>1000000000 or content_size>1G.  Unmodified values will remain in bytes.
