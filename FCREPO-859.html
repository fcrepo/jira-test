FCREPO-859 Custom error pages do not work for /fedora/objects/.....

Description

The error pages located (standard installation) in the fedora/jsp directory do not show up when the new REST api is used, e.g. /fedora/objects/<PID>/methods/<Sdef>/<method> with a wrong method name. Instead, the old-style /gedora/get/<PID>/<Sdef>/<method> with a wrong method name gives the error page as intended. The same holds for any url witth /fedora/objects/<anything>
