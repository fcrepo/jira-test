FCREPO-1363 The fedora:status property cannot be modified

Description

When you try to update the fedora:status property, you get this error:

Ldp::HttpError: STATUS: 409 Could not persist triple containing predicate http://fedora.info/definitions/v4/repository#status

This is because properties in the fedora: namespace are not user-modifiable. So we need to move the property to a different namespace, or provide a mechanism for updating it in the REST API.
