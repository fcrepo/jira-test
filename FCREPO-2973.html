Description

This task is to update the https://wiki.duraspace.org/display/FEDORA5x/Backup+and+Restore and/or https://wiki.duraspace.org/display/FEDORA5x/Import+and+Export+Tools documentation to note that the restoration of an individual resource that has associated Mementos is to:

  • GET memento
  • PUT over existing resource

Comments (2)

Andrew Woods, 2019-01-07 16:07 UTC

There are two options:

  • If you want the server managed triples from the memento, you must restart Fedora in "relaxed" mode:
    https://wiki.duraspace.org/display/FEDORA5x/Configuration+Options+Inventory#ConfigurationOptionsInventory-Allowinguserupdatestocertainservermanagedtriples
  • Or, if you do not need the SMTs to be the same as what is in the memento, you can use "Prefere: handling=lenient"
    https://wiki.duraspace.org/display/FEDORA5x/RESTful+HTTP+API+-+Containers#RESTfulHTTPAPI-Containers-YellowPUTCreatearesourcewithaspecifiedpath,orreplacethetriplesassociatedwitharesourcewiththetriplesprovidedintherequestbody.
Andrew Woods, 2019-01-08 14:39 UTC

It looks like you need to do two things:
1. GET the memento, omitting server-manged triples
```
curl -H "Accept: text/turtle" -H"Prefer: return=representation; omit=\"http://fedora.info/definitions/v4/repository#ServerManaged\"" http://localhost:8080/rest/version-test/fcr:versions/20180530230244 > version.ttl
```
2. PUT the memento over the original resource, specifying that no server-managed triples will be included
```
curl -X PUT -H "Content-Type: text/turtle" -H "Prefer: handling=lenient; received=\"minimal\"" --data-binary @version.ttl http://localhost:8080/rest/version-test -i
```
