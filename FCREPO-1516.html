Description

This task is to redesign the fcr:fixity service to be more in line with RESTful LDP interaction models.
For example, similar to the way that all non-RDF sources have an associated fcr:metadata resource, all resources (RDF or not) should possibly have an fcr:fixity resource.
When performing a GET on fcr:fixity, the most recent fixity check outcome should possibly be returned.
When performing a POST on fcr:fixity, a new fixity check should be run with a newly created outcome resource added as a child of fcr:fixity.
