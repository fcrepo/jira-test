Situ, Longshou, 2016-09-08 15:00 UTC

Andrew Wood: As you know I've opened a ModeShape ticket with a test that replicated the SNS issue we've seen. Horia Chiorean, the assignee of the MODE-2624 ticket, responses back that it's not a valid SNS test because we are asserting before calling session.save (see comment-13290375), which indicates that the SNS path is just a temporal state and it'll gone after the file upload process is completed by calling session.cave. That explains why it's so hard to replicate the SNS issue on the ModeShape level. So I think the problem is partially related to our file upload process, which will ingest some metadata related to that file before calling session.save(). I am not sure whether Horia Chiorean will take any actions on the ModeShape level or not but I think the SNS problem should be solved if we change the ingest process to only ingest those file related metadata after the file ingest process is completed by calling session.save.
