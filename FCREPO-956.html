Description

The JBoss repository http://repository.jboss.org/maven2 is no longer available according to http://community.jboss.org/en/build/blog/2011/06/01/blocking-repositoryjbossorgmaven2. It prevents to build the fcrepo project in case necessary dependencies were not already available in local .m2 repository.

I am attaching a patch of pom.xml that resolves the issue for the master branch.

Older releases (tags) can be affected too. Maybe there should be a notice to put the new repository to local .m2/settings.xml if you do not intend to update older tags.
