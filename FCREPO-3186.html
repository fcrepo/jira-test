FCREPO-3186 WebAC authorization gets wrong list of RDF types when checking access to binaries

TypeBug
StatusOpen
PriorityCritical
ReporterPeter Matthew Eichman
Created2020-01-27 14:23 UTC
Updated2022-09-29 16:30 UTC
Componentswebac
Affects versionsFedora 4.7.5

Description

When the WebAC module retrieves the list of classes for a binary, it always returns the classes of the fcr:metadata description (namely, fedora:NonRdfSourceDescription and fedora:Resource), and not the classes that are actually of the binary itself.

This prevents acl:accessToClass-based WebAC authorizations from working properly.
