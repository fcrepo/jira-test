Description

The Fedora repository can act like a registry of services
via BDef objects. This could be done by having the
BDef objects contain a datastream that is WSDL that
binds to a Fedora repository as the proxy for end-point
service. When Fedora repositories are federated, this
can act like a UDDI repository, but maybe simpler.
