Description

During testing of the verifcation tool's logging feature, I encountered some export errors.

While testing the verification tooling against the tree created by the export with errors, it became apparent that the verification tooling needs better handling of missing resources. Currently it records the error and breaks off. It should continue to check other resources and report the number of errors encountered at the end in order to give the user a sense of how widespread the problems are.
