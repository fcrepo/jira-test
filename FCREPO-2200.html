FCREPO-2200 remove -x flag, set extension from -l

Description

Current behaviour:

-x sets the file extension for exported rdf (default is .ttl)
-l sets the rdf language used (default is text/turtle)

It is possible to change one without changing the other, which could cause misleading file extensions (e.g. .jsonld file with turtle inside).

Suggested change:
Make the -l flag set the file extension to match the rdf language, and remove the -x flag.
