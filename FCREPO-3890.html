Description

We have had several requests for the version of fedora to be advertised via HTTP somehow.

Obvious candidates for this are

  • new endpoint fcr:version which responds with a simple text string,
  • add field to fcr:stats json response
  • add a custom HTTP header e.g. “Fcrepo-version: 6.4.1” so as not to clash with existing Server header
