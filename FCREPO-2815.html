Description

Creating a versioned external binary works, as well as creating a memento from the current version. However, creating an external historic memento fails. See the following commands:

curl -i -XPOST -H "Slug:logov" -H "Link: <http://mementoweb.org/ns#OriginalResource>; rel=\"type\"" "Link: <https://duraspace.org/wp-content/themes/duraspace/assets/images/whitedura.png>; rel=\"http://fedora.info/definitions/fcrepo#ExternalContent\"; handling=\"proxy\"; type=\"image/png\"" "http://localhost:8080/rest/" -ufedoraAdmin:fedoraAdmin
 
curl -XPOST http://localhost:8080/rest/logov/fcr:versions -H "Memento-Datetime: Sat, 1 Jan 2000 00:00:00 GMT" -H "Link: <https://wiki.duraspace.org/download/attachments/31655033/fedora_logo_2in.png>; rel=\"http://fedora.info/definitions/fcrepo#ExternalContent\"; handling=\"proxy\"; type=\"image/png\"" -ufedoraAdmin:fedoraAdmin

Ben Pennell, 2018-07-03 19:59 UTC

There was a typo in the original command in the ticket description, so that error is not valid. However, the ticket is still valid as you cannot create historic versions of external binaries because the VersionService has no way to receive external content uris currently.

A corrected command:

curl -i -XPUT -H "Link: <http://mementoweb.org/ns#OriginalResource>; rel=\"type\"" -H "Link: <https://duraspace.org/wp-content/themes/duraspace/assets/images/whitedura.png>; rel=\"http://fedora.info/definitions/fcrepo#ExternalContent\"; handling=\"proxy\"; type=\"image/png\"" "http://localhost:8080/rest/put_v2" -ufedoraAdmin:fedoraAdmin

This produces a memento as a FedoraInternalBinary with no content and no proxyUri property.
