FCREPO-3800 Make locks on parent resources allow concurrent appends, but block deleting of parent

Description

The change in FCREPO-3584 Closed made it so you could not delete a resource if another process was adding a child to it. But this also does not allow you to concurrently add multiple children. This ticket is to change the locks to differentiate between locks that restrict any type of action and locks that restrict deleting the resource.
