FCREPO-637 Create an object that represents the repository itself

Description

Among the set of "bootstrap" objects that Fedora should include is an object that represents the repository itself. Another step in allowing a repository to be self-documenting. It would also extend FCREPO-636 Closed to represent repository-wide policies.

Comments (2)

Chris Wilper, 2010-05-04 17:32 UTC

Discussed on 6/4/10 committer call, team discussed idea of a standard Fedora object URI that is a symlink to a specific Fedora object representing the repository. References (such as for repo-wide policies) to this object would be treated exactly like direct references to the underlying unique object. Also discussed the idea of having a "Repository" object content model.
