Description

Currently, Direct and Indirect containers are created by providing RDF (as the original PUT/POST or via PATCH) that includes a triple of the form:
<> a <http://www.w3.org/ns/ldp#DirectContainer>

That approach should be disallowed.

Instead, the user should only be able to create a Direct container by POSTing or PUTing a new resource with a `Link` header as:
``Link: <http://www.w3.org/ns/ldp#DirectContainer>; rel="type"```

Likewise, the user should only be able to create an Indirect container by POSTing or PUTing a new resource with a `Link` header as:
``Link: <http://www.w3.org/ns/ldp#IndirectContainer>; rel="type"```

Note: Since Basic, Direct and Indirect containers do not inherit from one another, clients should not be able to change a container's type from one to another.
e.g. Clients should not be able to change a Basic container to a Direct container.
See: https://www.w3.org/TR/ldp/#fig-ldpc-types
