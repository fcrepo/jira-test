FCREPO-1000 Fedora Admin (Swing) Client datastream mimetypes for Word, Excel and Powepoint are inconsistent w/ server mimetype extension mappings

Description

org.fcrepo.client.objecteditor.DatastreamsPane includes the following mime types: "application/ms-word", "application/ms-excel", "application/ms-powerpoint"

However, FEDORA_HOME/server/conf/mime-to-extensions.xml uses the following: application/msword, application/vnd.ms-excel, application/vnd.ms-powerpoint, which appear to be the more recognized variant. Moreover, Richard Green reports that at least IE 9.0.8112.16421, Safari 5.1 (7534.50) and Chrome 14.0.835.186m don't correctly recognize application/ms-word.

DatastreamsPane.ALL_KNOWN_MIMETYPES should be modified so that the above mimetypes accord w/ mime-to-extensions.xml.
