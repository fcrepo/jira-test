Description

The REST API method:
/objects/

{pid}

/datastreams/

{dsid}

/history
incorrectly provides URLs with the query parameter "asOfVersionDate", which is incorrect. It should be "asOfDateTime".

This means that the URLs do not return the correct versions (all URLs will return the latest version).
