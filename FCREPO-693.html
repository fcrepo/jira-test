Stuart Chalk, 2010-05-11 11:23 UTC

Currently certain of the REST API methods output XML via format=xml and others via xml=true. This needs to be standardized across all methods.

Chris Wilper, 2010-05-18 17:07 UTC

Hi Stuart, the right way is format=xml, for the REST API. The documentation page for that, at
http://fedora-commons.org/confluence/display/FCR30/REST+API
...was incorrect in stating that xml=true works. I just fixed that.

The old way, done for "API-A-Lite" (which we're trying to move away from) was xml=true. The old way won't be changed in favor of steering people to use the REST API, which does it consistently.

Thanks,
Chris

Stuart Chalk, 2012-11-02 00:12 UTC

FYI: I know that describeRepository is not implemented yet but when it is you will need to change xml=true to format=xml
