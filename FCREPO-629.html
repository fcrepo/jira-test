FCREPO-629 Ambiguous API call log messages

Description

Each API call is logged by Fedora at the end of its invocation.
The first part of the message always states "Completed [operation]". In case of a failed API call this may suggest success and therefore potentially confuse the person looking at the logs. It would be clearer if the log message would also include the outcome, like "Completed [operation], outcome: [failed|success]".
