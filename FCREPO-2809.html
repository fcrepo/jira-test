Description

An LDPCv, being a container must have a "Link:<http://www.w3.org/ns/ldp#Container>;rel="type"" header. Currently the said header is missing.  This can be confirmed by performing a GET on an LDPCv:

curl -x GET http://localhost:8080/rest/versioned_resource/fcr:versions
