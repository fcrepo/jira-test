Description

This is the same issue as described in:
https://jira.duraspace.org/browse/FCREPO-1505

but instead of preventing POSTing to pairtree resources, this task is to prevent PUTting to pairtree resources.

For example, if a resource has been created with a POST /rest request such that it exists at the following URL:
http://localhost:8080/rest/76/9e/2f/b5/769e2fb5-fa2c-42cc-a467-3482b6a9a721

The following request should fail with a 403:
curl -i -XPUT localhost:8080/rest/76/9e/test
