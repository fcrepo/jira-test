Description

Currently search queries returning the rdf_type field gets very slow as the database grows.  

 

For example this query is relatively fast (.3 secs) on a fedora with 1 million resources.

curl -u fedoraAdmin:fedoraAdmin "http://localhost:8080/fcrepo/rest/fcr:search?fields=fedora_id,mime_type,modified&max_results=10"

However this takes 19 seconds.
curl -u fedoraAdmin:fedoraAdmin "http://localhost:8080/fcrepo/rest/fcr:search?fields=fedora_id,mime_type,modified,rdf_type&max_results=10"
