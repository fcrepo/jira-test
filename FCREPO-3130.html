Description

  • The task here is to complete the TODO in  OCFLPersistentStorageSession.rollback(). Specifically,  we need to implement that rolling back of committed versions in the case of a mid-commit failure across multiple objects.  In order for this to work,  any committed OCFLObjectSessions all must have been committed with the  NEW_VERSION commit option.  A unit test should be included that tests  that the rollback in the aforementioned case succeeds.
