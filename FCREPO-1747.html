Description

The fcrepo4/ontology repository contains a lot of non-core (extension) ontologies. These extension ontologies should be extracted into their own repositories and out of the fcrepo4 organization. Ontologies to be moved include:

audit.rdf -> fcrepo4-exts/fcrepo-audit-ontology/
indexing.rdf -> fcrepo4-exts/fcrepo-indexing-ontology/
oai-pmh.rdf -> fcrepo4-exts/fcrepo-oai-pmh-ontology/
objState.rdf -> fcrepo4-exts/fcrepo-object-state-ontology/
ldp-fedora-mapping.rdf (is this even used? perhaps it can simply be removed: A. Soroka would know)

A. Soroka, Andrew Woods do you agree with the above reorganization?

No, I think things are a little more complicated. For example, the fcrepo-object-state-ontology should evolve to support the Fixity API, which is a first-class API module support for which belongs here. And the LDP mapping ontology needs to be finished and integrated into the main repository ontology. Currently, the repository ontology makes incorrect claims about the relationship between the Fedora model and LDP. You can make a ticket for that I think.
