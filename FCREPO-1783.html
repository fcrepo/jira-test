Description

This task is to update the following pom.xml files to explicitly define an SCM section. During the release of 4.4.0, three projects required special handling during the command:
mvn release:perform -DperformRelease -Dgoals=deploy

Specifically, the connectionUrl had do be specified when running that command, such as:
mvn release:perform -DperformRelease -Dgoals=deploy -DconnectionUrl=scm\:git\:git@github.com\:fcrepo4-labs/fcrepo4-swordserver.git

In analyzing which project needed a specified connectionUrl and which simply worked, I notice that the projects that worked have an SCM section defined in their pom.xml, the ones that did not work did not have an SCM section.

This task is to add SCM sections to the following projects:

  • fcrepo4
  • fcrepo-module-auth-webac
  • fcrepo4-swordserver
  • fcrepo-karaf
