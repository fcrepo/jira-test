Description

According to the specification, one should use the "Atomic-ID: <transaction-endpoint>" when performing CRUD Operations within a transaction. This is working correctly when no WebACs are involved.

However the WebAuthorizingRealm is incorrectly interpreting the value of the Atomic-ID.  Whereas elsewhere outside of the WebAuthorizingRealm GUID is parsed out of the Atomic-ID, in the WebAuthorizingRealm it is not which leads to the TransactionManager returning a null Transaction which using the id to located it.
