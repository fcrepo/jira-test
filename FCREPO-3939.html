Description

Currently you can’t index the ldp:contains relationships of a resource in Solr because we exclude containment triples from the response from Fedora.

I don’t remember if this was a conscious decision or operated differently with LDPath.

But this ticket is to provide a configuration option to allow users to include those triples if they want them.
