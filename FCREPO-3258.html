Description

In the CreateResourceServiceImpl checkParent method we want to use the containment index to check the eventual parent. But that method also needs to know the interaction model of the resource which we don't store.

This ticket is to add an additional field to the resources and transactionOperations tables and adjust functions to add this information and add a method to retrieve this information.

EDIT

This ticket is now just around enforcing the restrictions on changing a resource's interaction model or attempting to PUT/POST or PATCH server managed triples.
