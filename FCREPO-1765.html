Description

This task is to remove the following RDF elements from the default resource view.
Note, these elements show up prominently in the HTML UI; therefore, in the process of working this ticket it should be verified that the HTML UI is also cleaned up as necessary for a clean view.

  • remove UUID from resource HTML view
  • remove mixinTypes
  • remove primaryType
  • remove hasAccessRoles
