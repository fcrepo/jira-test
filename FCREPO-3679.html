FCREPO-3679 After completing a migration run, delete pid/resume.txt

TypeImprovement
StatusOpen
PriorityMinor
Reporterben_cail
Created2021-03-29 13:44 UTC
Updated2021-03-29 14:04 UTC
Componentsmigration-utils

Description

Currently, pid/resume.txt in the working directory isn't deleted after a successful migration run. So, if you kick off another batch after the first successful one, you can run into a conflict with the information in pid/resume.txt. Deleting resume.txt after a successful run would take care of that issue.
