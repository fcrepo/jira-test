Description

Creating a binary with two digests is only returning one digest on GET:

echo "test content" |
curl -ufedoraAdmin:fedoraAdmin -XPUT http://localhost:8080/rest/binary_with_digests --data-binary @- -H "Digest: md5=d6eb32081c822ed572b70567826d9d9d, sha=4fe2b8dd12cd9cd6a413ea960cd8c09c25f19527"

GET

$ curl -ufedoraAdmin:fedoraAdmin http://localhost:8080/rest/binary_with_digests/fcr:metadata

<http://localhost:8080/rest/binary_with_digests>
        ...
        premis:hasMessageDigest  <urn:sha1:4fe2b8dd12cd9cd6a413ea960cd8c09c25f19527> ;

The header file actually has the MD5, SHA1, and SHA512 stored, so its most likely an issue when generating the response:

"digests":["urn:sha1:4fe2b8dd12cd9cd6a413ea960cd8c09c25f19527","urn:md5:d6eb32081c822ed572b70567826d9d9d","urn:sha-512:b22137a0e8969282b85e3f9375448307d14c5aabf41be66c4f6a0323bd03a3935972021e4c34aa30914e37b03c22594fe180eea9790e9ff147016c9dfae39d5a"]

Ideally, the GET response would contain all 3 of the digests.
