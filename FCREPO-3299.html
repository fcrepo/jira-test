When I do this:

curl -i -X POST "http://localhost:8080/rest/fcr:tx" -u fedoraAdmin:fedoraAdmin

I get this:

HTTP/1.1 201 Created
Expires: Wed, 20 May 2020 23:26:46 GMT
Location: http://localhost:8080/rest/fcr:tx/f481b5f7-c019-4f0e-863a-ee0ba44bcaf0
Link: <http://localhost:8080/rest/fcr:tx/f481b5f7-c019-4f0e-863a-ee0ba44bcaf0/commit>; rel="http://fedora.info/definitions/v4/transaction#commitEndpoint" 

To commit - I must use the commitEndpoint url:

curl -u fedoraAdmin:fedoraAdmin  -X PUT http://localhost:8080/rest/fcr:tx/ f481b5f7-c019-4f0e-863a-ee0ba44bcaf0/commit"

I've updated the  documentation accordingly.
