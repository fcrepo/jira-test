FCREPO-3280 Millisecond portion of fedora:created loses zeros

TypeBug
StatusOpen
PriorityMajor
ReporterBen Pennell
Created2020-04-22 14:02 UTC
Updated2020-04-25 14:56 UTC
Affects versionsFedora 5.1.0

Description

Fedora appears to be changing the millisecond portion of datetimes in RDF for fedora:created but not for dc:date. For example, it goes from "2012-03-22T14:18:22.800Z" to "2012-03-22T14:18:22.8Z". My understanding is that it should not make this change, but it is worth investigating.

To test, you'll need to start fedora in relaxed mode:

java -Dfcrepo.properties.management=relaxed -jar fcrepo-webapp-5.1.0-jetty-console.jar

Create with fedora:created

curl -XPOST -H"Content-Type: text/turtle" --data-binary "<> <http://fedora.info/definitions/v4/repository#created>
                \"2012-03-22T14:18:22.800Z\"^^<http://www.w3.org/2001/XMLSchema#dateTime>" http://localhost:8080/rest/


curl http://localhost:8080/rest/fcfa41c1-1519-41ef-8027-7ae200f8720d
#        fedora:created         "2012-03-22T14:18:22.8Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;

Create with dc:date

curl -XPOST -H"Content-Type: text/turtle" --data-binary "<> <http://purl.org/dc/elements/1.1/date>
                \"2012-03-22T14:18:22.800Z\"^^<http://www.w3.org/2001/XMLSchema#dateTime>" http://localhost:8080/rest/


curl http://localhost:8080/rest/da83c0f8-c15f-4730-b2cc-396d0b033371
#         dc:date                "2012-03-22T14:18:22.800Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
