FCREPO-397 Update database in a transaction

Description

Currently Fedora updates its internal database outside of a transaction. The code in DefaultDOManager is designed to manually back out when an error occurs in the process of "committing" a change to an object. This improvement would cause updates to occur in a database transaction. It would both simplify the code in DefaultDOManager and give greater assurance that recovery occurred correctly.

Note: This would require that we beging using InnoDB (not MyISAM) style tables when running Fedora with MySQL.
