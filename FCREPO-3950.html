Description

The Reindexing service is adding ACLs into the containers membership and containment properties 

cat inputs/acl/m-uzivatel.ttl
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix acl: <http://www.w3.org/ns/auth/acl#> .
@prefix foaf: <http://xmlns.com/foaf/0.1/ > .
@prefix webac: <http://fedora.info/definitions/v4/webac#> .
<#authzReadWrite> a acl:Authorization ;
   rdfs:label "Read & Write Authorization" ;
   rdfs:comment "Define users authorized for full control over the container." ;
   acl:accessTo info:fedora/AMCR/model/uzivatel ;
   acl:agent "AMCR" ;
   acl:mode acl:Read, acl:Write .

<#authzRead> a acl:Authorization ;
   rdfs:label "Read Authorization" ;
   rdfs:comment "Define users authorized for access to the container." ;
   acl:accessTo info:fedora/AMCR/model/uzivatel ;
   acl:default info:fedora/AMCR/model/uzivatel ;
   acl:agent "Digiarchiv" ;
   acl:mode acl:Read .

added by:

curl -v -X PUT -ufedoraAdmin:fedoraAdmin -H "Content-type: text/turtle"  --data-binary @inputs/acl/m-uzivatel.ttl http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/fcr:acl
and subsequently requested:
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix fedora: <http://fedora.info/definitions/v4/repository#> .
@prefix ldp: <http://www.w3.org/ns/ldp# > .
<http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel>
        ldp:insertedContentRelation  ldp:MemberSubject ;
        ldp:membershipResource       <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel> ;
        ldp:hasMemberRelation        ldp:member ;
        fedora:created               "2024-07-17T15:28:10.688651Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:lastModified          "2024-07-17T15:28:10.688651Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:createdBy             "fedoraAdmin" ;
        fedora:lastModifiedBy        "fedoraAdmin" ;
        rdf:type                     ldp:IndirectContainer ;
        rdf:type                     ldp:Resource ;
        rdf:type                     fedora:Resource ;
        rdf:type                     ldp:RDFSource ;
        rdf:type                     ldp:Container ;
        rdf:type                     fedora:Container ;
        ldp:contains                 <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/U-000159> ;
        ldp:member                   <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/U-000159> .

BUT after reindexing, note the addition of new ldp:contains and ldp:member for the acl:

@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix fedora: <http://fedora.info/definitions/v4/repository#> .
@prefix ldp: <http://www.w3.org/ns/ldp# > .
<http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel>
        ldp:insertedContentRelation  ldp:MemberSubject ;
        ldp:membershipResource       <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel> ;
        ldp:hasMemberRelation        ldp:member ;
        fedora:created               "2024-07-17T15:28:10.688651Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:lastModified          "2024-07-17T15:28:10.688651Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:createdBy             "fedoraAdmin" ;
        fedora:lastModifiedBy        "fedoraAdmin" ;
        rdf:type                     ldp:IndirectContainer ;
        rdf:type                     ldp:Resource ;
        rdf:type                     fedora:Resource ;
        rdf:type                     ldp:RDFSource ;
        rdf:type                     ldp:Container ;
        rdf:type                     fedora:Container ;
        ldp:contains                 <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/fcr:acl> ;
        ldp:contains                 <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/U-000159> ;
        ldp:member                   <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/fcr:acl> ;
        ldp:member                   <http://localhost:8080/fcrepo/rest/AMCR/model/uzivatel/U-000159> .

should we be excluding the fcr:acl objects from being added as ldp:contains and ldp:members on reindex?
