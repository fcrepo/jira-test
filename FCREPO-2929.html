Description

To reproduce: 

1.   create an RDF resource.

2. Update it with the following : 

 

INSERT
{ <#test>  dc:title "my hash resource title" }
WHERE {} 

 

3. in the UI hit "Create VersIon" or execute the following: 

 

 

curl -i -u fedoraAdmin:fedoraAdmin -X POST http://localhost:8080/rest/test/fcr:versions

 

Verify the following response: 

 

HTTP/1.1 403 Forbidden
Date: Wed, 31 Oct 2018 19:32:40 GMT
Set-Cookie: JSESSIONID=12ig4ifffyr1dfpqaqfs3vy2i;Path=/
Expires: Thu, 01 Jan 1970 00:00:00 GMT
Set-Cookie: rememberMe=deleteMe; Path=/; Max-Age=0; Expires=Tue, 30-Oct-2018 19:32:40 GMT
Link: <http://localhost:8080/static/constraints/IncorrectTripleSubjectException.rdf>; rel="http://www.w3.org/ns/ldp#constrainedBy"
Content-Type: text/plain;charset=utf-8
Content-Length: 138
Server: Jetty(9.3.25.v20180904)
http://localhost:8080/rest/test#test is not in the topic of this RDF, which is http://localhost:8080/rest/test/fcr:versions/20181031193240

The console reports the following: 

ERROR 12:32:40.291 (PersistingRdfStreamConsumer) http://localhost:8080/rest/test#test is not in the topic of this RDF, which is http://localhost:8080/rest/test/fcr:versions/20181031193240.
