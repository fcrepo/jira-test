Description

I exported my repo using the following command:

java -jar target/fcrepo-import-export-0.1.1-SNAPSHOT.jar -d ~/import-export-sprint-3/data-export-as-bag -m export -a -b -r http://localhost:8686/f4/rest -g default -G ~/import-export-sprint-3/config-files/bagit-profile.yml

The resulting importexport.yml looks like this:

mode: export
external: false
predicates: http://www.w3.org/ns/ldp#contains
overwriteTombstones: false
resource: http://localhost:8080/rest/1
bag-profile: default
bag-config: path/config.yaml
dir: /tmp/rdf
binaries: false
rdfLang: text/turtle

Notice resource, binaries, bag-config, resource, and possibly predicates are simply using default values not the ones specified by the command line.
