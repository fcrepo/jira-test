Description

With FeSL enabled, fedora.test.api.TestRISearch is failing. Queries that ask for a specific format such as "count" are rewritten to return RDF/XML.

For example, the query:
http://localhost:8080/fedora/risearch?type=triples&lang=spo&format=count&stream=on&query=*%20*%20*
always returns RDF/XML (format=Turtle, etc. is also rewritten)

Stephen Bayliss, 2011-04-28 14:07 UTC

ParameterRequestWrapper is the culprit as this rewrites the output format to RDF/XML; with the filter subsequently picking up the correct format and then re-formatting it to the originally-requested format.

The filter needs some work (ie handle different output formats correctly rather than rely on RDF/XML output).

Fixed the parameter rewriting, but leaving this issue open as a placeholder to fix the RISearch filter itself.
