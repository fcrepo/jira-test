Description

Performing a GET on an LDP-NR's ACL resource should return a 200.  Instead it returns this stacktrace (see below).  

curl -v -X PUT http://localhost:8080/rest/test2 --data-binary "test" -H "Content-Type: text/plain" -u fedoraAdmin:fedoraAdmin

(returns 201)

curl -v -X PUT  http://localhost:8080/rest/test2/fcr:acl -u fedoraAdmin:fedoraAdmin

(returns 200) 

 

curl -v -X GET  http://localhost:8080/rest/test2/fcr:acl -u fedoraAdmin:fedoraAdmin
