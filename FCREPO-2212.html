Description

The fcrepo-camel integration tests currently load Fedora via spring configuration. This means that any dependencies between the two projects must align, which is a bad thing. Notably, the jena version used by fcrepo-camel must be the same jena version as is used by the fedora testing infrastructure. There are other such dependency collisions, and by moving the testing apparatus into the maven-jetty plugin, this will all go away.
