Description

Curl the headers on any /fcr:versions uri and you'll notice that there are no link headers as I would expect.

Link: <http://www.w3.org/ns/ldp#Resource>;rel="type"
Link: <http://www.w3.org/ns/ldp#RDFSource>;rel="type"

To reproduce:

1. Create a resource and then add a version to that resource.
2. curl -v -X HEAD -i http://localhost:8080/rest/your-resource/fcr:versions
3. verify there are no links returned.
