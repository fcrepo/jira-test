Description

As a follow on to https://jira.duraspace.org/browse/FCREPO-2732 the "self" link should include range information so that the resulting link should look as follows: 
<http://localhost:8080/rest/resource/fcr:versions>
; rel="self";type="application/link-format"
; from="Tue, 20 Jun 2000 18:02:59 GMT"
; until="Wed, 09 Apr 2008 20:30:51 GMT",

These extra parameters are specified in https://tools.ietf.org/html/rfc7089#section-5.1.1

See: https://github.com/dbernstein/fcrepo4/blob/7cb27f4912e0c9f08c5f074f25fa5658964b18a8/fcrepo-http-api/src/main/java/org/fcrepo/http/api/FedoraVersioning.java#L277
