Description

The task https://jira.duraspace.org/browse/FCREPO-2671 will remove the pairtree node creation by default. However we need a way to restore the old pairtree generating behavior for those folks who depend on it. The task then is to define a system property ( e.g. fcrepo.pairtree.generate) that when set to true will restore pairtree generation on new nodes.
