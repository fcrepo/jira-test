Description

This memory leak results in the OcflPersistentSessionManager.sessionMap continuing to grow and never getting garbage collected.

The issue was discovered by analyzing the heap-dump as follows:
$ sudo -u tomcat jmap -dump:format=b,file=heap.bin <tomcat-pid>
$ ./ParseHeapDump.sh heap.bin org.eclipse.mat.api:suspects

The ParseHeapDump / MemoryAnalyzer utility can be downloaded from: https://www.eclipse.org/mat/downloads.php
