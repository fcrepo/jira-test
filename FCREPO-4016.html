FCREPO-4016 Remove OSGI references in fcrepo projects

Description

Since fcrepo no longer does anything related to OSGI, we should remove all the OSGI references from the code base. These are basically just properties in pom.xml files at this point, like:

  <properties>
    <!-- OSGi -->
    <osgi.import.packages>
      *
    </osgi.import.packages>
    <osgi.export.packages>
      org.fcrepo.auth.webac;version=${project.version}
    </osgi.export.packages>
  </properties>

In fcrepo-camel there is still some karaf configuration.

fcrepo-camel-toolbox still has two OSGI blueprint files

fcrepo-service-activemq/src/main/resources/OSGI-INF/blueprint/blueprint.xml
fcrepo-service-camel/src/test/resources/OSGI-INF/blueprint/blueprint-test.xml

I don’t think we still need any of that though since all the OSGI dependencies have been removed.
