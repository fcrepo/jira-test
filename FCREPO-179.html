FCREPO-179 mail.jar is missing from 3.0B1. Causes REST uploads to fail

Description

One jar file from the REST branch didn't make it into the (3.0B1) trunk. Without this jar, multipart/mime posts (uploading binary files) fails.

Also, I looked in junit.fedora.test.api.TestRESTAPI.java and found that the testAddDatastream() method only attempts to create an "X" datastream by posting some XML. It doesn't attempt to create an "M" datastream by uploading a file. That's how this error slipped under our radar.

The test method should create both an "X" datastream and an "M" datastream.

The missing jar file (in SVN Browse): http://fedora-commons.svn.sourceforge.net/viewvc/fedora-commons/fedora-rest/trunk/lib/jersey/mail.jar
