Description

As noted in FCREPO-790 Closed , FeSL's fedora-users.xml authentication implementation reads this file for every request to the repository. This file should not have to be re-read and parsed for every request – the info it contains should be cached in some way for performance. For example, a reasonable out-of-box behavior would be to refresh from the file if it has been > 60 seconds since the last request.
