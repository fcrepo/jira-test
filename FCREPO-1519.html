Description

This task is to create a Camel component that writes repository updates to disk to satisfy the need for a human-readable backup. This should be part of the https://github.com/fcrepo4-exts/fcrepo-camel-toolbox repository along with other Camel components.

It would be ideal if such a module were configurable to allow users to define if the RDF and/or the binary resources should be persisted to disk.

This was implemented with the fcrepo-message-consumer as documented here:
https://wiki.duraspace.org/display/FEDORA4x/RdfPersistenceIndexer
