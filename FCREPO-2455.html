Description

This task is to improve the import/export documentation to be more verbose about what it expects the contents of a directory to be imported to look like, and what model the resources needed to adhere to. Or at least some pointers to existing documentation on that topic.

For example:
—
The Fedora 4 Import/Export Utility is designed to export data from, and import data to, Fedora 4 for uses such as:
Migrating or synchronizing data from one repository to another
Exporting data for backup or preservation
Note: The Import/Export Utility does not perform any data mapping or transformation — it can be used to import new data into Fedora, but the data would need to conform to Fedora's requirements.
—
..also include a link to where one can find the description of "Fedora's requirements"
