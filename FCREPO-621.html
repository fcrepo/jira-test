FCREPO-621 Move to Java 6+ (Java 5 no longer supported)

Description

Fedora already works with Java 6, but we are considering discontinuing support for Java 5 for several reasons:

1) As of Nov 3, 2009, J2SE 5 has reached its End Of Service Life (EOSL). This means there will be no more public updates to Sun's J2SE 5.
2) Finding and installing Java 5 on the various operating systems is becoming increasingly difficult.
3) Java 6 has several API and annotation improvements we'd like to be able to take advantage of in the source code. (For example, IOException now has a constructor that accepts a Throable cause, and @Override can now apply to interface method implementations)

For now, this would also reduce the number of different configurations we'd need to test prior to release, thus shortening the release cycle.

In early January 2010, the committers agreed that this is the direction we want to go, but we should first poll our users to see what, if any, problems this might create for them.

Upon deciding to move to Java 6, the following changes should be made immediately:

A) Change the pom to compile to java 6 bytecode (and thus require a Java 6 JDK)
B) Remove the JDBC3/4 code-rewriting hack in the build
C) Modify the CI tests to run using Java 6

Chris Wilper, 2010-01-11 19:44 UTC

I sent out a survey to the fedora-users list in early January.

http://www.surveymonkey.com/s/DLRSFF5

This survey was open for a week. Here are the final results:

31 people took the survey.

Q1: Which of the following apply to you?

24 (77%) use Fedora in production
28 (90%) develop software that uses the SOAP/REST apis.
16 (52%) develop software that uses Fedora's Java interfaces.
3 (10%) are Fedora committers

Q2: Which app server(s) do you deploy with?

17 (55%) deploy with the bundled version of Tomcat
9 deploy with a non-bundled Tomcat 6.x (1 of those said they were moving toward JBoss)
5 deploy with a non-bundled Tomcat 5.5
4 deploy with a non-bundled Tomcat but did not specify a version

Q3: Which version of Java do you run Fedora with?

12 (39%) said Java 5
25 (81%) said Java 6

Q4: Do you foresee a problem if future versions of Fedora require Java 6?

30 (97%) said no
1 (3%) said yes, "My App Server is not Java 6 compatible", but this person also said they were only deploying with the bundled version of Tomcat (which is Java 6 compatible), and declined to provide contact information.
