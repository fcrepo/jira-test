Description

Reported by Graeme West
http://fedora-commons.1317035.n2.nabble.com/Large-datastream-ingest-issue-Bad-request-unable-to-fulfill-REST-API-request-java-lang-NumberFormatE-td5094256.htm

Ingesting a file larger than 2GB fails with java.lang.NumberFormatException.

The source of this is in RestUtil -
rContent.size = Integer.parseInt(lengthHeaders.get(0));

This should be long rather than int (along with inner class RequestContent size field and related methods).

Just to note for others' benefit Steve's quick fix against trunk:

org.fcrepo.server.rest.RestUtil.:

Line 108 - change Integer.ParseInt to Long.parseLong
Line 119 - change the type of size from int to long
line 138 - change the return type of method getSize() from int to long
