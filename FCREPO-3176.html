Description

The beyond the repository grant has developed a BagIt Profile which needs to be supported in the import export tool.

  • The Fedora Import/Export tool needs to be able to generate an export package that is a BagIt Bag that conforms to the BTR BagIt Profile
  • After performing an export into the BTR format and removing the objects contained in that export from the Fedora repository, the Fedora Import/Export tool is able to re-ingest the contents of the bag such that the original repository contents are restored.
  • Tests are in place which demonstrate both export and import of repository content using the BTR BagIt Profile.
  • Documentation for the Import/Export tool is updated based on changes made.
