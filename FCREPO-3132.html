Description

Suggestions for improving the usability of the migration-utils tool:

  1. Change "working-dir" option to "target-dir" or "output-dir". Working-dir could imply temporary/staging space, but it's the actual OCFL output that goes into working-dir.
  2. Add "Choices" information to the help output for --layout. Currently, it lists the default value, but doesn't specify what the other options are.
  3. For the help output of --limit, it says that the default is "-1". Might be helpful to add a comment saying that "-1" means no limit (process all content).
