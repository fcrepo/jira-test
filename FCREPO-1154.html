Description

As reported on the mailing list (http://comments.gmane.org/gmane.comp.cms.fedora-commons.devel/2540), selecting the legacy-fs store still results in akubra-fs being used.

Removing $FEDORA_HOME/server/config/spring/akubra-llstore.xml before first start is a workaround, but Fedora should respect the original install option.
