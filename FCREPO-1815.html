Description

We need a shared java client library for Fedora 4. It will be a good start even if it just includes:

1. Best practices for HttpClient creation
2. The basic semantics of typical Fedora 4 requests

For a first pass, just extract the FcrepoClient (and dependencies) from fcrepo-camel and rig up an integration test framework.
