Description

Many web servers support gzip compression of resources via the header: Accept-Encoding: gzip, deflate

This is a ticket to track the implementation of this, either via a container-level configuration recipe or by implementing a Jersey filter: https://jersey.java.net/documentation/latest/filters-and-interceptors.html

Closing as out of scope. This is easy to implement in a servlet container or a reverse proxy. For example, here is a possible Nginx configuration:

gzip on;
gzip_types text/javascript text/turtle application/json application/ld+json application/rdf+xml application/n-triples;
gzip_proxied no-cache auth;
