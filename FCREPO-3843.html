Description

When migrating objects from fedora 3 to 6, some fields used to have certain characters encoded for xml (e.g. a label may have had " for quotations). The migration to Fedora 6 has moved these to n-triples and these characters are now written using escape characters. The validation tool should unescape these when doing comparisons in order to avoid false negatives.
