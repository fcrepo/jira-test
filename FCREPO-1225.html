FCREPO-1225 Missing <security-role/>s cause startup to fail

TypeBug
StatusClosed
ResolutionCannot Reproduce
PriorityCritical
ReporterMark H. Wood
Created2014-08-27 00:18 UTC
Updated2014-09-12 22:11 UTC
Resolved2014-09-12 22:11 UTC
Affects versionsFedora 4.0.0

Environment

Gentoo Linux; Tomcat 7.0.42 from distro; fcrepo-webapp-4.0.0-beta-02-auth.war

Description

web.xml is missing <security-role/>s for fedoraUser and fedoraAdmin. This causes startup to fail:

Aug 26, 2014 1:13:32 PM org.apache.catalina.startup.ContextConfig validateSecurityRoles
INFO: WARNING: Security role name fedoraUser used in an <auth-constraint> without being defined in a <security-role>
Aug 26, 2014 1:13:32 PM org.apache.catalina.startup.ContextConfig validateSecurityRoles
INFO: WARNING: Security role name fedoraAdmin used in an <auth-constraint> without being defined in a <security-role>
Aug 26, 2014 1:13:36 PM org.apache.catalina.core.StandardContext startInternal
SEVERE: Error listenerStart
Aug 26, 2014 1:13:36 PM org.apache.catalina.core.StandardContext startInternal
SEVERE: Context [/fedora4] startup failed due to previous errors

Adding them allows startup to proceed to the next, unrelated failure ( FCREPO-1224 Closed ).
