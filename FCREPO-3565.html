Description

InvalidResourceIdentifierExceptions can occur if the path is invalid (ie. empty path segments), but also for a variety of reasons. Now if the initial response to evaluating a FedoraId is a exception you get a quiet 400 Bad Request from WebACFilter.

If the initial parsing is fine you might still get a 400 on later iterations, but those (having moved past the WebACFilter will include the message.
