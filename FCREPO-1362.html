Description

Steps to reproduce:

  • Create containers: /test, /test/res1, /test/res2
  • Add property to /test: INSERT { <> myns:rel </test/res1>, </test/res2> }

    WHERE {}

  • Verify that multi-valued property is set in /test referring to both resources
  • Delete either /test/res1 or /test/res2

Result: myns:rel does not appear in /test any more; both relationships are deleted
Expected: only the relationship with the deleted node should be deleted
