Description

Setup:

  • Download dataset: https://github.com/fcrepo4-labs/fcrepo-sample-dataset/blob/master/plantpatents/plants.tar.gz
  • Start up an empty F4
  • Upload the sample dataset:
    > curl -i -XPOST --data-binary /path/to/1473315261896-0 localhost:8080/rest/fcr:restore
  • Export the repository:
    > java -jar fcrepo-import-export-driver-0.0.1-SNAPSHOT.jar -b /tmp/bin -m export -d /tmp/rdf -r http://localhost:8080/rest/
