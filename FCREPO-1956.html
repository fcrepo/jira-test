Description

The JMeter tests being created to gauge Fedora performance and scaling capability [1] need to be run to be useful. To provide the greatest value, these tests need to be run repeatedly, in the same environment, as changes to Fedora are made, as this will allow for greater insight into how changes to the system affect performance and scale metrics.

This task is to automate the execution of the JMeter tests using Amazon Web Services as the consistent environment. This will allow anyone to be able to run these tests. Using AWS also provides the option to hook these tests into an automated build/test environment (Jenkins, Travis CI, etc), however that work is not a part of this task.

[1] https://wiki.duraspace.org/display/FF/Performance+and+Scalability+Test+Plans
