Description

This task is to ensure that requests to `some/binary/fcr:metadata` returns a more complete description of the associated binary.
Much of the content found in the `.fcrepo/binary.json` file would be appropriate to return, including:
"filename"
"mimeType"
"createdDate"
"createdBy"
"lastModifiedDate"
"lastModifiedBy"
"contentSize"
"digests"
