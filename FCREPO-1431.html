Former user, 2015-04-24 17:32 UTC

The phase 2 audit system fulfills the write portion of the audit requirements: events are created, contain the required info, persist when the referenced nodes are deleted. External events can also be posted to the audit container. Setup is documented in https://wiki.duraspace.org/display/FF/Using+Internal+Audit+Phase+II

The read requirements are fulfilled by the phase 1 audit system (which can be used in conjunction with the phase 2).

See FCREPO-1495 Closed for comprehensive documentation covering how to use both audit systems together.
