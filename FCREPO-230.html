FCREPO-230 CMA disseminations ignore Service Definitions

Affects versionsFedora 3.0, Fedora 3.2

Description

Executing a dissemination requires specifying an object, an SDef, and a method name. In reality, the implementation ignores the SDef, and exposes all methods defined in the SDep, regardless of what the SDef says. Thus, a user can execute methods defined in an SDep that are not part of the public interface of an object
