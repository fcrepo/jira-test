Description

This task is to enable support for import of a hierarchy of resources that have been exported with the use of a user-provided membership predicate.

For example, it is unclear how to reimport the export of:
java -jar fcrepo-import-export-0.1.0.jar -b -a -p http://pcdm.org/models#hasMember -d data -m export -r http://localhost:8080/f4/rest/collection0

See: https://wiki.duraspace.org/display/FF/Sprint+3+Feedback+-+A+Woods
