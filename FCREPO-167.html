Description

BatchModifyParser was modeled after an earlier version of METSDODeserializer parser which has since been updated and streamlined. BatchModifyParser does not currently reflect these same updates.

It is desirable to update BatchModifyParser to reflect similar changes made to other parsers in regards to handling of in-line xml content and namespace handling for consistency.
