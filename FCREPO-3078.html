Description

The task is to rework the @PATCH operation in FedoraLdp using the all new ResourceFactory.  The OCFLPersistentStorageSession is currently handling the update operation for RDF source.  However the kernel service org.fcrepo.kernel.impl.services.UpdatePropertiesServiceImpl will need to be implemented.  When complete, the appropriate integration tests in FedoraLdpIT will  be turned back on and will pass.

Namely:  

FedoraLdpIT.testEmptyPatch()

FedoraLdpIT.testUpdateObjectGraph()

FedoraLdpIT.testDeleteMultipleMultiValuedProperties

FedoraLdpIT.testPatchBinary()

FedoraLdpIT.testPatchBinaryDescriptionWithBinaryProperties()

FedoraLdpIT.testPatchBinaryNameAndType()
