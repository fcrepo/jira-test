FCREPO-3213 SHA-512 support for Fedora 5

TypeStory
StatusOpen
PriorityMinor
ReporterMichael Ritter
Created2020-02-13 21:47 UTC
Updated2021-09-17 17:42 UTC

Description

As part of the work for the Import Export Utility, the BeyondTheRepository bag profile has been added which supports the SHA-512 digest algorithm.

In order to fully support the profile, the Import Export Utility should be able to pass SHA-512 digests when PUTing resources in Fedora, which it currently cannot do.
