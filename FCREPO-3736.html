Description

Currently the template directory is referenced by its source directory rather than the classpath. As a result we get a FileNotFound error when running the tool outside of the git project root.

The problem is here: HtmlReportHandler.java line 65:

           config.setDirectoryForTemplateLoading(new File("src/main/resources/templates"));

The templates must be referenced by there classpath location.
