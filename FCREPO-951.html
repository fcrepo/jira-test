Description

The REST API does not have the equivalent of API-M getDatastreams. Instead it is necessary to list datastreams using the /objects/pid/datastreams endpoint and then iterate each of the datastreams.

Add getDatastreams to the REST API.

For discussion:

  • should this be a different endpoint to the /objects/pid/datastereams endpoint?
  • or should we add a URL parameter on the same endpoint?
  • need to consider any AuthZ implications (as listDatastreams is API-A and getDatastreams is API-M)
