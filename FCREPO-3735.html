FCREPO-3735 Make the rebuild run asynchronously

Description

The task here is to make the rebuild operation outside of the web application initialization flow so that users can start up Fedora and query the API without having to wait for the rebuild operation to complete.

This change would allow metrics collection to proceed while the rebuild is underway since the /fcrepo/prometheus endpoint would be immediately available.

Since Fedora is not usable until the reindexing is complete and modifications to the application state could break things, we would want to prevent all access to the rest api - ie all endpoints matching /rest/* - until the initialization process is complete.

One way to do this would be to add a servlet filter to the top of the chain that checks whether the repository initializer is complete, rejecting all requests until it is.
