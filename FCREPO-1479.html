Description

When deploying camel-toolbox applications (such as the audit service) in OSGi, it would be nice to have a feature.xml file so that the bundle can be installed and managed directly from the karaf shell:

$ feature:install audit-triplestore

Rather than compiling and manually installing it.

Unknown, 2015-05-08 13:47 UTC

I have tested this on both karaf 3.0.2 and 3.0.3

Version 3.0.3 requires an additional step in order to install camel and activemq:

In $KARAF_HOME/etc/jre.properties, change this line (for the appropriate jre version)

javax.annotation;version="1.0", \

To at least (version 1.2 is also fine):

javax.annotation;version="1.1", \

Then, in the karaf shell (for any 3.x version):

$> feature:repo-add mvn:org.fcrepo.camel/fcrepo-camel-toolbox/4.1.2-SNAPSHOT/xml/features
$> feature:install fcrepo-audit-triplestore
$> feature:install fcrepo-indexing-triplestore
$> feature:install fcrepo-indexing-solr
