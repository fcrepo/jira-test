FCREPO-3996 site-maven-plugin is not maintained (Github Pages Documentation Deployment)

Description

We use the GitHub developers site-maven-plugin to deploy documentation at release time to Github Pages via a gh-pages branch within the repo. This plugin is taking a long time to run and eventually fails with a 502, presumably due to a timeout talking to the GitHub servers. The plugin is no longer maintained and the GH repo is archived. There is a workaround for replicating this deployment methodology described at https://wiki.bitplan.com/index.php/Multi-Module_Maven_with_github_pages
