FCREPO-3290 Repository root only exists in mutable head

Description

Fedora automatically creates a repository root object on startup if one does not exist. If auto-versioning is not enabled, this root object will only exist in the mutable HEAD. Since the root is immutable, it should probably be committed when it's created.
