Description

The task here is to implement support for the WANT-DIGEST header specified in the API.

API Reference: https://fedora.info/2018/11/22/spec/#http-get-ldpnr

When complete the following failing API Test Suite Tests should succeed.

3.2.3-A-1     Testing for supported digest: md5 . GET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]  
3.2.3-A-2     Testing for supported digest: sha . GET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]  
3.2.3-A-3     Testing for supported digest: sha-256 . GET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]  
3.2.3-B     Testing for two supported digests with no weights GET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]  
3.2.3-C     Testing for two supported digests with different weightsGET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]  
3.2.3-D     Testing for two supported digests with different weights q=0.3,q=0 GET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]  
3.2.3-E     Testing for one supported digest and one unsupported digest.GET requests to any LDP-NR must correctly respond to the Want-Digest header defined in [RFC3230]
