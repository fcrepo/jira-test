Description

This task is to enable the creation of an ACL that protects the default transform system space.
To reproduce:

  1. Create a resource
    curl -i -uadmin1:password3 -XPUT localhost:8080/rest/collection
  2. Perform a transform so that the system space is auto-created:
    curl -i -uadmin1:password3 localhost:8080/rest/collection/fcr:transform/default
  3. Create an ACL
    curl -i -uadmin1:password3 -XPUT localhost:8080/rest/acl
  4. Create an Authorization
    curl -i -uadmin1:password3 -XPUT -H"Content-Type: text/turtle" --data-binary @auth-sys.ttl localhost:8080/rest/acl/auth
    • BOOM: failure - 400 "Only referenceable nodes may be the value of reference properties"
