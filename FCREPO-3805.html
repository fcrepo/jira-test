FCREPO-3805 Replace Maven Shade plugin with other packaging mechanism

TypeImprovement
StatusOpen
PriorityLow
ReporterRalf Claussnitzer
Created2022-02-04 08:56 UTC
Updated2022-02-05 14:03 UTC
Componentsfcrepo-camel-toolbox

Description

Maven Shade plugin for packaging classes on the class path into a single uberjar has some problems. Results may vary and lead to obscure class path issues. It generates Maven build warnings and might break Java 9 module descriptors for some libraries in the future. Also generating uberjars is not common anymore in containerized applications.

Options

  • Switch to https://docs.spring.io/spring-boot/docs/current-SNAPSHOT/reference/htmlsingle/#build-tool-plugins.maven
  • Use https://docs.spring.io/spring-boot/docs/current-SNAPSHOT/reference/htmlsingle/#executable-jar
  • Don't generate an uberjar at all
