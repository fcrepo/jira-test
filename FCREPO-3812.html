FCREPO-3812 fcrepo-migration-validator: Add flag for reporting error details only

Fix versionsfcrepo-migration-validator-1.2.0

Description

The migration validator generate lots of little files when performing validations for both successful and failed validation tests. This can result in an overly verbose report not to mention a huge number of files on disk. The task here is to add a flag that tells the validator to count successful validations, but not include the details in the reports so that users can focus on the errors. This flag should significantly speed up the report generation phase.
