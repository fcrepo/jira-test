FCREPO-3961 Fedora in Tomcat hangs when ocfl-root permission is denied

TypeBug
StatusReceived
PriorityHigh
ReporterDemian Katz
Created2024-11-21 17:33 UTC
Updated2024-11-21 17:36 UTC

Environment

Ubuntu 22.04 ; Java 11.0.25 ; Tomcat 9.0.97 ; Fedora 6.5.1-RC

Description

When testing the 6.5.1-RC, I discovered that in my test environment, Tomcat gets into a stuck state if Fedora does not have read/write access to the OCFL root.

I previously used the one-click .jar for testing, so this is my first attempt to set up Tomcat in my test environment. Thus, I doubt the problem is specifically tied to 6.5.1-RC; I just haven’t tried this with earlier releases.

Tomcat is set up by sym-linking the Fedora .war file as webapps/ROOT.war inside my Tomcat installation. I’ve also made the necessary adjustments to conf/tomcat-users.xml.

See attached catalina.out file for details on my environment and the point at which the log stops being updated. During this time, if I try to access Tomcat from a web browser, the connection hangs until it times out. If I fix the permission issues and restart Tomcat, everything starts up correctly and responds as normal.

This is not a critical issue for me, but since it might cause confusion/inconvenience for others, I thought it might be worth investigating.

Happy to share any additional details that might be enlightening!
