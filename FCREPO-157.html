Description

GSearch: add untokenizedFields property to lucene index.properties files.

Currently, the untokenizedFields property is created at initialization time, based on 10 index documents, and used at query time to select analyzer. Adding the property with a list of all untokenized fields will ensure that they all select the appropriate analyzer.
Proposed by Leire Urcelay.
