FCREPO-2884 Adding type memento:Memento causes resources to disappear

Description

Providing a "rdf:type memento:Memento" appears to cause a resource to become unfindable. Creating a resource with the it returns a 404, and attempts to create a resource without the property at the same location also return a 404. Updating a resource with the rdf:type causes it to return a 404 thereafter. No error shows up in the server log.

 

 

curl -ufedoraAdmin:fedoraAdmin -i -XPUT -H"Content-Type: text/turtle" http://localhost:8080/rest/boom_test
# Status: 201

echo "INSERT { <> <http://www.w3.org/1999/02/22-rdf-syntax-ns#type> <http://mementoweb.org/ns#Memento> } WHERE { }" | curl -ufedoraAdmin:fedoraAdmin --data-binary "@-" -i -XPATCH -H"Content-Type: application/sparql-update" http://localhost:8080/rest/boom_test
# Status: 204

curl -ufedoraAdmin:fedoraAdmin -i http://localhost:8080/rest/boom_test
# Status: 404


echo "<> <http://www.w3.org/1999/02/22-rdf-syntax-ns#type> <http://mementoweb.org/ns#Memento> ." | curl -ufedoraAdmin:fedoraAdmin --data-binary "@-" -i -XPUT -H"Content-Type: text/turtle" http://localhost:8080/rest/boom_test2
# Status: 404

curl -ufedoraAdmin:fedoraAdmin -i http://localhost:8080/rest/boom_test2
# Status: 404

echo "<> <http://purl.org/dc/terms/title> 'some title' ." | curl -ufedoraAdmin:fedoraAdmin --data-binary "@-" -i -XPUT -H"Content-Type: text/turtle" http://localhost:8080/rest/boom_test2
# Status: 404

echo "<> <http://purl.org/dc/terms/title> 'some title' ." | curl -ufedoraAdmin:fedoraAdmin --data-binary "@-" -i -XPUT -H"Content-Type: text/turtle" http://localhost:8080/rest/boom_test3
# Status: 201
