Description

Currently, Fedora 6 treats the value of the Slug header as an un-encoded string. However, per the spec, it should be treated as a url encoded value.

https://fedora.info/2018/11/22/spec/#http-post
https://www.w3.org/TR/ldp/#h-ldpc-post-slug
https://tools.ietf.org/html/rfc5023#section-9.7

echo "hello world" | curl -ufedoraAdmin:fedoraAdmin http://localhost:8080/rest/ -H'Link: <http://www.w3.org/ns/ldp#NonRDFSource>; rel="type"' -H"Slug: %C3%A4bc3" --data-binary @- -XPOST -v

Should create the resource "äbc3", but it actually creates the resource "%C3%A4bc3"
