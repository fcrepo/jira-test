FCREPO-3605 Add a version property to the resource headers

Description

The resource headers should have a `version` property that indicates the version of the headers. Fedora could add, remove, or change the format of resource headers in the future, and the version indicates how historic resource header files should be interpreted. For now, the version should be `1`.
