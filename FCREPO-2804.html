Description

This ticket relies on https://jira.duraspace.org/browse/FCREPO-2803.

This ticket is to modify the event Fedora outputs for a resource (A) when another resource points to it. Currently resource A would get an Update event, even though it has not changed.

There are several already defined types for ActivityStreams

https://www.w3.org/TR/activitystreams-vocabulary

Perhaps the Relationship would be most appropriate?

https://www.w3.org/TR/activitystreams-vocabulary/#dfn-relationship
