Description

This task is to prune the following unnecessary properties:

  • fcrepo-mint ** remove fcrepo.version property
  • fcrepo-transform ** remove fcrepo.version property and fcrepo-jcr-bom
  • fcrepo-audit ** remove fcrepo.mint.version, and fcrepo.version
  • fcrepo-webapp-plus ** remove audit.version and transform.version, update fcrepo.version

Unknown, 2016-02-19 14:45 UTC

I am not clear on the intent of this ticket. As I understood, by decoupling project versions, these very properties are of utmost importance and should not be removed.

Andrew Woods, 2016-02-19 23:27 UTC

@acoburn, the decoupling of project versions is great. However, the version properties are problematic when it comes time to release any given artifact. The maven release plugin does not work well with the properties... additionally, it is very easy to bulk update versions of dependencies via other maven plugins.

The short story is, factoring the dependency version numbers into properties has put the projects mentioned in this ticket in incorrect states at release time.

Andrew Woods, 2016-02-19 23:46 UTC

One point of clarification that may be helpful, is that the projects listed in this ticket are in fcrepo4-exts and are intended to be coupled with the core codebase version.

  • fcrepo-mint, fcrepo-transform, fcrepo-audit, and fcrepo-webapp-plus
    ..should all track with the current version of fcrepo4 because they get deployed in fcrepo-webapp-plus with each release of fcrepo4 and need to be compatible.
