Description

This task is to create a script that implement a script that creates a structure of resources in F4 and associated webac ACLs to help feature stakeholders verify the webac functionality.

The script should build out the documented stakeholder use cases as described in this email:
https://groups.google.com/d/msg/fedora-community/_zMOf-KTG6c/PX8MHPMGAgAJ

As a starting point, this project can be updated (if appropriate):
https://github.com/fcrepo4-labs/fcrepo-sample-dataset
