FCREPO-3008 Enforce rule on accessTo and acl:default objects

TypeImprovement
StatusOpen
PriorityMinor
ReporterDanny Bernstein
Created2019-06-06 19:21 UTC
Updated2024-01-11 18:32 UTC

Description

Enforce rule on accessTo and acl:default objects: ie values must = ACL’s container.

If an ACL contains an authorization with an acl:default or acl:accessTo value that refers to a resource other than the ACL's container resource, a 400 should be returned with an explanation stating that acl:default and acl:accessTo must = ACL's container resource
