This task is a follow-on to:
https://jira.duraspace.org/browse/FCREPO-1640

Specifically, see comment:
https://github.com/fcrepo4/fcrepo4/pull/869#issuecomment-129077939

  • Create a binary resource in the HTML UI
    • http://localhost:8080/rest/image
  • Create a version of that resource
    curl -i -XPOST -H"slug: v0" http://localhost:8080/rest/image/fcr:versions
  • GET the triples for the versioned resource
    curl -i http://localhost:8080/rest/image/fcr:versions/v0/fcr:metadata
    • Notice triples have subject of <resource>/fcr:metadata instead of <resource>
