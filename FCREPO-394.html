Description

In an effort to reduce the learning curve associated with developing in the fedora repository baseline by adopting a standardized application source structure and leveraging community plug-ins, this suggested improvement is to migrate from the existing ANT build framework to Maven2.

This task includes:
:restructuring the source tree(s)
:moving dependency management into a pom.xml
:associating plug-in for eclipse .classpath/.project generation
:migrating test suites to Maven2 framework
:...
