Description

The REST API is currently built as a stand-alone JAR which is included as a library in the Fedora repository trunk. The code in the REST API, however, is only useful as part of Fedora, it does not stand on its own. Because of this, there is no particular benefit to having the code live in its own project, and including it as part of trunk would make maintenance simpler.

This task is to move the code from the Fedora REST API into trunk and update the build to function correctly. One portion of the build that needs consideration is when a new WADL is constructed.
