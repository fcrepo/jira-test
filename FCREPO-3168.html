Currently 

curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/test1 -v -H "Content-Type: text/turtle" -X PUT --data ""

succeeds however the empty OCFL file is missing.  It should result in a zero length file on disk. Also please note that 

`curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest -v -H "Content-Type: text/turtle" -X POST --data ""`

should behave similarly. 

 

Integration test coverage should be added.
