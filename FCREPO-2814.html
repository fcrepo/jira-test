FCREPO-2814 Section 3.9 Advertise External Content option for all resources

Description

Currently the OPTIONS request only returns the header advertising external content if you request it on an object that is a binary resource. 

This ticket is to make sure that containers advertise that external content can be created on the server, when an OPTIONS request is made.
