DELETE

{ <> dc:title ?title }

WHERE { }

You get a successful response, but the title remains.

The behavior you see here is expected, given the SPARQL query you list. That is, the SPARQL query listed here will not delete the triple. Instead, I suspect you mean either of these queries:

DELETE WHERE

{ <> dc:title ?title }

or

DELETE

{ <> dc:title ?title }

WHERE

{ <> dc:title ?title }

Both of those queries will remove the title, whether it contains a "/" or not.
