Description

The rebuild process is now parallelized and should perform better than the single threaded approach.  However,  we have not verified this.  The task here is to test the rebuild of a repository with a significant number of resources of different types.  As a starting point we might try: 

   a repo with 10 thousand basic container objects      

   a repo with 10 thousand containers objects,  each of which includes  10 binaries

   The same as previous but doubling the number of containers to 20,000.
