FCREPO-803 Xslt import/include other datastreams from the same object

Depends onFCREPO-706 Datastream bindings for methods passing as URL use old-style LITE API

Description

Use case: dissiminatrions through different xslt's which are all datastreams of one "xslt object". Some of the xslt's import and/or include others.

At present, the only reliable way to do this is e.g. <xsl:import="/fedora/get/aux:xslt/XSLT2"/>.
A better and more robust solution would be something like <xsl:import="$THIS$/XSLT2"/> or just <xsl:import="XSLT2"/>.
(The first solution is used for the Schema extension of DS-COMPOSITE, the second actually worked in Fedora3.0 but not in 3.4)
