Description

The current id mapping strategy runs up against costly-to-fix shortcomings in the fedora 4 architecture.

Create a simpler mapping that just:
1. assigns each f3 pid a new path in Fedora 4 using the default PIDs minted by fedora 4
2. persists that mapping somewhere for use when that pid is later referenced
