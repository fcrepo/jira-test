Description

fedora-rebuild should take two exclusive arguments, 1) list of directories and 2) list of pids. In the case of the list of directories, fedora-rebuild would rebuild in depth-first order.

For example, fedora-rebuild.sh -d /opt/fedora/data/objectStore/2011/10 /opt/fedora/data/objectStore/2011/11 would recursively rebuild all of the objects found in those two directories.

Alternatively, fedora-rebuild.sh -p demo:123 demo:abc would rebuild the two objects specified.

Rationale: For a large repository, rebuild takes hours, if not days, during which system is unavailable. In a disaster-recovery scenario, we'd like to be able to get back online with at least the "most important" objects rebuilt as soon as possible.

This also allows for selective recovery in the case of isolated inconsistencies that are detected.

Finally, this mechanism would allow for parallel rebuild processes to further speed the rebuild time.
