Description

Currently, blank nodes are created under:
/.well-known/genid/

{uuid}

Since performance of the repository suffers when a single container has more than a few thousand children, the current approach of storing all blank nodes directly under the above parent is problematic.
This issue is to ensure that blank nodes do not introduce a performance penalty by instead creating an auto-generated hierarchy under the above path, or by some other means.
