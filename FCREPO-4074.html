FCREPO-4074 Expose when a resource has uncommitted changes

TypeImprovement
StatusReceived
PriorityHigh
ReporterBen Pennell
Created2026-03-12 16:16 UTC
Updated2026-03-12 18:36 UTC

Description

In an repository with autoversioning turned off, there is not currently a way to tell that a resource has uncommitted changes (mutable head versions). It would be helpful for fedora to expose that a resource is uncommitted via a header or a server generated triple. This feature would be unused in autoversioned repositories.

We will need to research if ocfl-java has this as a readily retrievable piece of metadata about an object, which would be a prerequisite for this ticket. If it is available, it would need to be communicated up through the stack as a fedora header, but only if autoversioning is off.
