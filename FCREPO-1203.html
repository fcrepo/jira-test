FCREPO-1203 Authorization fails for APIM access via IPv6

TypeBug
StatusClosed
ResolutionWon't Fix
PriorityMinor
Reporterjgm106@psu.edu
Created2013-10-16 23:54 UTC
Updated2015-01-16 20:59 UTC
Resolved2015-01-16 20:59 UTC
Affects versionsFedora 3.7

Environment

FedoraOS 19. Tomcat 7. Java 1.7. FedoraCommons 3.7

Description

On upgrade from 3.5.0 to 3.7.0, I discovered that IPv6 authorization now fails from systems defined in deny-apim-if-not-localhost.xml.

Steps to reproduce:
1. Fresh install of a Fedora3.7 webpp.
2. copy over the working Fedora3.5 data directory.
3. Rebuilt the Resource Index and SQL database via the fedora-rebuild.sh script.
4. start up the Fedora3.7 webapp.
5. access a datastream profile via IPv4 and it works.
6. access the same datastream profile via IPv6 and it fails.
