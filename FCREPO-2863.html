FCREPO-2863 acl:agentClass foaf:Agent and acl:AuthenticatedAgent are not respected

Description

In a resource's ACL, when an acl:agentClass is set to foaf:Agent or acl:AuthenticatedAgent, the Fedora implementation should grant access to all users (https://github.com/solid/web-access-control-spec#public-access-all-agents) or all authenticated users, respectively.

Currently both foaf:Agent and acl:AuthenticatedAgent is ignored.

Test 5.0-D and 5.0-E in the CTS should pass once this issue is resolved.
