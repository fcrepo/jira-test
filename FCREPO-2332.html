Description

The -b flag is now a boolean, and the -d flag is the path to both the binaries (assuming -b is True) and rdf. The verfication tool's parsing of the config file therefore needs to be updated.

The config file can have the following values:

-b (optional): presence means True
-m (required): "import" or "export"
-d (required): path to resources on disk
-r (required): url of parent resource to export or location to import to
-l (optional): rdf dialect (defaults to turtle); also determines the extension used for rdf resources (formerly set by -x flag)

[-h and -u options will not be recorded in the config -- I'm just assuming this is so for -u, which would otherwise be a security hole]
