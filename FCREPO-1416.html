Description

This task is to ensure that "omitting" server-managed triples (SMT) behaves as expected under the following circumstances:
1) Create an RDF Source with client-provided triples, then request that resource (omitting SMTs) and ensure that only the client-provided triples are in the response.
2) Add an rdf:type to the RDF Source, and ensure that it is included in the response that omits SMTs.
3) Ensure server-managed triples can not be updated (i.e. repository namespace).

Note: To omit server-managed triples on GET requests, include the following request header:

Prefer: return=representation; omit="http://fedora.info/definitions/v4/repository#ServerManaged"
