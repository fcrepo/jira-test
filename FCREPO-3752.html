FCREPO-3752 Altering the external content URL does not update the binary metadata's last-modified date.

Description

If you PUT over-top an external binary with a new URL it updates the last-modified timestamp for the actual binary. It also updates the premis:hasSize triple on the associated nonRdfSourceDescription object. But it does not update the timestamp for that same nonRdfSourceDescription, which means the last-modified header and triple remains unchanged.
