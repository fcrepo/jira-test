Description

The fedora admin UI contains references to a number of versioning related actions that are not implemented in version 6 due to restrictions in OCFL. These are:

  • action_revert
  • action_remove_version
  • action_enable_version

Previously these were buttons on the versioning page, but at no longer shown. We should remove the references to these and the UI actions that were invoked by them.
