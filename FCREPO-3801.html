Description

The task here is to create a REST endpoint to serve as a placeholder for stats retrieval operations.

All stats calls should live under /<context>/rest/fcr:stats

A placeholder should return the stats summary : /<context>/rest/fcr:stats
The summary should return a json map.

{
  "all": {
    "resource_count": 22
  },
  "binaries": {
    "resource_count": 12,
    "byte_count": 199
  },
  "mime_types": [
    {
      "resource_count": 7,
      "byte_count": 119,
      "mime_type": "audio/mp4"
    },
    {
      "resource_count": 5,
      "byte_count": 80,
      "mime_type": "text/plain"
    }
  ]
}
