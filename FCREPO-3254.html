This task is to create a new "FedoraID" class that replaces the various instances in the code base where a String is used to represent a Fedora resource's identifier.
This class will encapsulate logic related to Fedora identifiers, such as:

  • internal ID
  • external ID
  • with suffix
  • without suffix
  • is memento
    etc...
