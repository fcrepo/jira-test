FCREPO-3208 Import use available BagIt manifests

Description

When importing BagIt bags, the import export utility will attempt to read only a sha1 manifest from a Bag. Many profiles no longer require sha1 as a required digest, and can write bags which do not have a sha1 manifest. The import portion of the utility should use the manifest of the highest priority algorithm from the BagIt Profile.
