FCREPO-3639 foxml-file migrations - delete it after migration

TypeImprovement
StatusOpen
PriorityMinor
Reporterben_cail
Created2021-02-17 21:29 UTC
Updated2021-02-19 13:51 UTC
Componentsmigration-utils

Description

If the --foxml-file option is passed in, the whole FOXML file can be migrated, instead of the object & datastream property files. So, an object's active files after migration might be: FOXML, image.tif, video.mov. However, FOXML isn't an actual active content file of the object (it's not in the datastream list of Fedora3). We want the FOXML there in the object history if needed, but we don't want it to show up as an active file in the object. So, we propose migrating the FOXML, but then at the end of the object migration, adding a new version that deletes the FOXML file.
