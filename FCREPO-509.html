FCREPO-509 REST API does not properly handle ingests with FOXML that does not contain a PID

Description

POSTing FOXML without a PID but with the pid included as part of the request gives an error that the PID is malformed

Tried doing the following using Firefox Poster:

POST to http://localhost:8080/fedora/objects/newpid:foo

with FOXML as request data (note that no PID is defined):

<?xml version="1.0" encoding="UTF-8"?>
<foxml:digitalObject VERSION="1.1" xmlns:foxml="info:fedora/fedora-system:def/foxml#" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="info:fedora/fedora-system:def/foxml# http://www.fedora.info/definitions/1/0/foxml1-1.xsd">
<foxml:objectProperties>
<foxml:property NAME="info:fedora/fedora-system:def/model#state" VALUE="Active"/>
<foxml:property NAME="info:fedora/fedora-system:def/model#label" VALUE="Label"/>
</foxml:objectProperties>
</foxml:digitalObject>

Response:

fedora.server.errors.GeneralException: Ingest failed:
...
Caused by: fedora.common.FaultException: Malformed PID: PID delimiter ( is missing.
at fedora.common.PID.getInstance(PID.java:77)
at fedora.server.validation.ValidationUtility.validateReservedDatastreams(ValidationUtility.java:81)
...

What should happen in this case is that the PID provided as part of the REST request should be used as the object's PID upon ingest.
