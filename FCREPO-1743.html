Environment

Windows 7, 64-bit, Tomcat 8

Description

Ingesting a few thousand objects creates (or rather keeps creating) stack traces, with the message "Could not create random access file."

Please see the attached stack trace file.

This seems to be related to a LevelDB driver issue from Infinispan Java driver for LevelDB (leveldbjni):

https://github.com/fusesource/leveldbjni/issues/28

The items do keep on getting ingested even after this error happens (and one can still make HTTP calls to retrieve container properties, etc.), but visiting the application home page results in the same stack trace.

This apparent bug might have implications for admins who want to run Fcrepo on a Windows machine.
