Description

When inheriting from fcrepo-parent in maven, the SCM section is incorrect. What happens is a project's artifactId is appended to the scm connection value, so during mvn release:perform the incorrect value is used.

The solution is to not inherit the scm values in maven. This affects fcrepo4, fcrepo-karaf and probably others, too.
