Description

According to the spec:   https://fcrepo.github.io/fcrepo-specification/#ldpic

mplementations must allow the ldp:insertedContentRelation property to be set via the content RDF on container creation, or otherwise default to an implementation defined value. Implementations should use the default property value ldp:MemberSubject.

Currently we are not "default[ing] to an implementation defined value".  When you create a indirect container without an insertedContentRelation predictate,  none is added by default.  This ticket will be complete when ldp:insertedContentRelation is added when no insertedContentRelation triple is specified in the body. The default value should be

<> ldp:insertedContentRelation ldp:MemberSubject

as specified.
