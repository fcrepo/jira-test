Description

A LDP-RS that describes a LDP-NR advertises several HTTP methods as allowable that are, in fact, not allowable:

curl -i localhost:8080/fcrepo/rest/a/binary/fcr:metadata

Allow: MOVE,COPY,DELETE,POST,HEAD,GET,PUT,PATCH,OPTIONS

Clearly, POST is not allowed.
