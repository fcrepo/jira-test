FCREPO-832 proai oaiprovider character encoding exception when using default encoding other than UTF-8

Description

1) Fedora contains DC metadata with greek characters
2) Platform default encoding is not UTF-8

Exceptions are thrown in proai - see http://comments.gmane.org/gmane.comp.cms.fedora-commons.user/6026

The OAIProvider contains some code that uses the default encoding when converting to bytes to characters, rather than using UTF-8 (ie assuming that Fedora content is UTF-8) - see FedoraOAIDriver.java line 275). This is causing issues when a default encoding other than UTF-8 is used.

Sample file to provoke the issue attached.

Work-around is to supply -Dfile.encoding=utf-8 to the JVM (eg add this to CATALINA_OPTS)
