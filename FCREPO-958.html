FCREPO-958 Allow configuration of Messaging datastores with no messageTypes specified

Description

The messageTypes parameter of data store configurations specifies what types of API-M message (access, update) the datastore will receive.

However it is not possible to omit this (or specify ""): an exception is thrown on initialisation, as the String.split returns an array of a single zero-length string if it is specified as "" and NPE if the parameter is omitted.

It would be useful to configure datastores that do not receive API-M messages for custom messaging implementations - eg use messaging.send(destination, message) to send a new kind of message to the new destination (datastore); without the datastore also receiving the existing API-M messages.
