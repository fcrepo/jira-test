FCREPO-738 The REST api create xml return values by hand

Description

There is a class DefaultSerializer, in the REST api. It's job is to convert fedora datastructures to xml and html return values for the REST api. It does this by initializing a stringbuffer and appending strings as it parse the datastructure. This procedure works, but should be improved to some sort of automatic conversion or generation.
