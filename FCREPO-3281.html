Description

The infrastructure to ensure that integration tests are able to run while the port 8080 is in use appears to have been broken in the fcrepo-http-api module.

The following Maven plugin is used to avoid this issue:
https://github.com/fcrepo4/fcrepo4/blob/master/pom.xml#L543-L563

..in combination with:
https://github.com/fcrepo4/fcrepo4/blob/master/pom.xml#L520-L533

To reproduce:

  • Start tomcat on port 8080
  • Run 'mvn clean install' on the fcrepo project
    • BOOM! - build fails on fcrepo-http-api integration tests

Using "git bisect", the following commit appears to have introduced the breakage:
https://github.com/fcrepo4/fcrepo4/commit/90e8f4df99fa43c1bec888154f22245c00ed01d8
