FCREPO-2543 PutBuilder returns wrong type for preferLenient

Description

The preferLenient method on PutBuilder incorrectly returns BodyRequestBuilder instead of PutBuilder. The result of this is that you generally have to have preferLenient as the last method call when using the fluent API because it changes classes or requires unnecessary casting.
