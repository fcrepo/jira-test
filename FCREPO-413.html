Description

As of Fedora 3.0, "extPropertyType" is no longer used in Fedora. However, it was not removed from the FOXML schema. It's confusing that it's still in the schema because it's not readable/writable in any other way via Fedora's APIs. It is effectively ignored (and likely even dropped on deserialization).

Note that this change would make some formerly valid FOXML 1.1 objects invalid. So it's important to consider the effects of revising the schema. For example, should the FOXML format be changed to 1.2? Or 1.1.1? What about the format URI accepted for ingest? Fun...
