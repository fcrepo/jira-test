Description

This feature allows you to specify which fields you wish to display in your search output.

By default, fedora_id, created, and modified dates should be displayed. If  ?fields=* is specified in the querystring, show all available fields.

Otherwise,  specify the fields desired in the search results using a comma delimited list.  For example,  

?fields=fedora_id,modified

will return fedora_id and modified date.
