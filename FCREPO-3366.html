FCREPO-3366 Allow user to specify desired digest algorithm during export

Description

In the import-export-utility certain BagIt bag profiles will cause the export portion of the utility to use all available digest algorithms. This is because the Exporter attempts to determine the algorithms to use by reading the profile's Manifests-Required and Manifests-Allowed, so in the event the Manifests-Required is not specified all the Manifests-Allowed will be used.

To help with this, it would be good to have an additional command line argument to allow a user to specify which digest algorithm they would like the Exporter to use. The algorithm passed should be checked against both the Manifests-Required and Manifests-Available.
