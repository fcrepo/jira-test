Description

The current constrainedBy document mentions three interaction models: BasicContainer, DirectContainer, and IndirectContainer.  It also contains verbiage about how the software goes about determining the default interaction model (based on content-type).

Reading the nascent Fedora spec, I see two additional interaction models mentioned: ldp:NonRDFSource and memento:OriginalResource  . 

Shouldn't these be added?
