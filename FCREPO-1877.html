Description

After depositing the attached LDPath document to '/fedora:system/fedora:transform/fedora:ldpath/fedora-tx/fedora:Container', invoking this transform on a typical Fedora resource produces output like:
[

{"rdfsLabel":["BUGS"],"rdfsComment":[],"fedoraLastModified":[1453880188507],"fedoraDateCreated":[1453880188507]}

]

Note that the xsd:dateTime fields are transformed to longs.

Elliot Metsger, 2016-01-27 18:47 UTC

This is unexpected, and in my estimation, incorrect behavior because xsd:dateTime can represent a time before the epoch.

It causes problems, because after transforming a resource for the purpose of indexing, solr may expect to index a dateTime field type and receives a long which is unexpected.
