Description

The Java client should be able to parse Link headers with three or more parts, such as the Link from a newly-created binary to its description, which has the form:

Link: <http://localhost:8080/rest/file1/fcr:metadata>; rel="describedby"; anchor="http://localhost:8080/rest/file1"
