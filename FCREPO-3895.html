FCREPO-3895 Expose "effective ACL" functionality via API

Description

Fedora has an internal mechanism for determining the effective ACL for a given resource, walking up the hierarchy if the resource itself doesn't have one. It would be useful to expose this functionality via the API, such that the effective ACL can be fetched with a single call. A use case would be a front-end application that displays some access information about a given resource to the user, e.g. whether or not it is publicly accessible, accessible to any authenticated user, or restricted to certain users.
