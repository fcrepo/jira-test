Description

The headers returned from RDF Sources, and particularly Containers, have a few minor issues:

  • [ ] Content-Length is 0 on a HEAD, and should be the number of bytes of the representation if you had done a GET instead.
  • [ ] application/ld+json is missing from Accept-Post for containers
  • [ ] The Vary header is missing, even though the resources will content negotiate on at least Accept and Prefer
