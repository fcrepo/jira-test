Description

This task is to replicate and resolve the issue identified by the test steps detailed in the following comments:
https://jira.duraspace.org/browse/FCREPO-2055?focusedCommentId=50536&page=com.atlassian.jira.plugin.system.issuetabpanels:comment-tabpanel#comment-50536

Under certain circumstances, the HTML UI responds with: "SyntaxError: Unexpected end of JSON input" when browsing through HTML resources.

The issue appears to be related to the fact that HEAD operations respond with application/ld+json that is unparseable... which is not surprising, since HEAD should have an empty body.
