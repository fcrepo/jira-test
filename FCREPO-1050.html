Description

Currently, the Eclipse settings attempt to line arguments up by column when multiple lines are used in a method call. This results in excessive newlines and confuses Eclipse's built-in code formatter. This change moves to the more tried-and-true style of indenting additional lines by eight characters, which is less confusing to the automatic code formatter.

See related fcrepo-dev thread: http://fedora-commons.1317035.n2.nabble.com/fcrepo-dev-Code-style-arg-indent-wonkiness-amp-proposal-tc6982790.html
