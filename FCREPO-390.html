Comments (1)

Bill Branan, 2008-12-19 22:45 UTC

The mediaType is not always provided when calling modifyDatastream in the REST API, but it was always being dereferenced. Updated to check mediaType for null prior to using it as a mimeType value.

Also added tests to TestRESTAPI to make sure modifyDatastream works with a simple label update on a managed datastream and a location update on an external datastream.
