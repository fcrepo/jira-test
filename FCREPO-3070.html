FCREPO-3070 Creating external binary with bad URI and digest blows up

TypeBug
StatusOpen
PriorityMinor
ReporterBen Pennell
Created2019-09-24 17:49 UTC
Updated2022-06-30 15:32 UTC
Affects versionsFedora 5.1.0

Description

This was tested using fcrepo-webapp-5.1.0-jetty-console.jar

 

Creating an external binary from a url that does not exist/is not resolvable by Fedora should work. The following request without a digest will succeed, which is expected:

curl -i -H"Link: <https://global.unc.edu/files/2019/09/DSC_1230-325x250NOTFOUND.jpg>; rel=\"http://fedora.info/definitions/fcrepo#ExternalContent\"; handling=\"proxy\"; type=\"image/tiff\"" -XPUT -ufedoraAdmin:fedoraAdmin http://localhost:8080/rest/test_proxy_local_file

But if you add a digest in it fails with a 500 status and a large stack trace:
