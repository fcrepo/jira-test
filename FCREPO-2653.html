Description

TimeMaps have a specific URI of fedora:timemap, but we address them via the /fcr:versions URI.

ie. a GET returns triples
<http://localhost:8080/rest/versionableObject/fedora:timemap> a fedora:Resource

this should be
<http://localhost:8080/rest/versionableObject/fcr:versions> a fedora:Resource

This task builds on the work of FCREPO-2623 Closed to create a converter to change this URI.
