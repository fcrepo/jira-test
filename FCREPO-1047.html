Description

Auto-checksumming is configured (autoChecksum = true, checksumAlgorithm = MD5) but when I ingest object via xml with datastream content but no contentDigest included in the foxml, I get a "DISABLED" / "none" checksum instead of the automatic, default checksum that I should be getting.

frank asseg, 2012-01-24 21:17 UTC

the problem seems to stem from FOXMLDODeserializer which sets checksumtype to "DISABLED" when instantantiating new datastreams in FOXMLDODeserializer.startElement():408

408: m_dsChecksumType = Datastream.CHECKSUMTYPE_DISABLED;
409: m_dsChecksum = Datastream.CHECKSUM_NONE;
410: } else if (localName.equals("contentDigest")) {
411: m_dsChecksumType = grab(a, FOXML.uri, "TYPE");
412: m_dsChecksum = grab(a, FOXML.uri, "DIGEST");

It seems to me the right approach to fix this is to change FOXMLDODeserializer to use Datastream.getDefaultChecksum() rather than Datastream.Datastream.CHECKSUMTYPE_DISABLED; The problem seems to be gone for me with this one line fix.

We need to make sure though that this problem does not exist in the different serializers for e.g. METS, which i haven't checked yet...
