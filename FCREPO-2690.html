Description

Revealed when solving FCREPO-2681 Closed

The URL of the Timemap is incorrect. It displays as

<http://localhost:8080/rest//fcr:versions>

This is because here (https://github.com/fcrepo4/fcrepo4/blob/memento-versioning/fcrepo-http-commons/src/main/java/org/fcrepo/http/commons/api/rdf/HttpResourceConverter.java#L263) the getContainer from the timemap returns the container holding the binary. We need the binary itself.

I'm not sure the easiest way to get that.
