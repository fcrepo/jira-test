FCREPO-1037 Results format for TQL subqueries - add support for TQL XML

Description

Results formats are supposed to be nested (according to the Mulgara docs) where there are subqueries (ie results of one query nested within another results set). This doesn't seem to be the case, eg:

select $dcidentifier
subquery (
select $s $o
from <#ri>
where $s <info:fedora/fedora-system:def/model#state> $o
)
from <#ri>
where $s <http://purl.org/dc/elements/1.1/identifier> $dcidentifier
