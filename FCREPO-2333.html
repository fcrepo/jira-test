Description

There are a few places in the fcrepo-camel-toolbox where components rely on JMS headers such as org.fcrepo.jms.baseUrl or org.fcrepo.jms.identifier. The code should be refactored so that a non-JMS-based message broker could be used.

This particularly affects the serialization tool and the ldpath tool, but some other components will need minor adjustments, too.
