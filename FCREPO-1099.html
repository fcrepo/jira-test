FCREPO-1099 install.properties dependency filenames should be generated by Maven

Description

fcrepo-server/src/main/resources/properties/resources/install.properties contains entries such as

install.jdbc.mysql = mysql-connector-java-5.1.20.jar
install.jdbc.derby = derby-10.8.2.2.jar

Rather than hardcoding the dependency filenames, they should be tokens (e.g. $mysql) that are replaced with the actual value during the Maven build.

This would prevent install.properties getting out of sync every time the dependencies are updated.

noting options that don't work:

maven-resources-plugin resource filtering doesn't seem to resolve dependency names ( also see http://jira.codehaus.org/browse/MRESOURCES-118 )

maven-replacer-plugin (com.google.code.maven-replacer-plugin) doesn't seem to have a way to resolve dependency names (e.g. $

{org.fcrepo:foo}

)

maven-antrun-plugin seems the closest: $

{asm:asm:jar}

or $

{maven.dependency.asm.asm.jar}

gives an absolute path to the dependency, but we only want the filename
