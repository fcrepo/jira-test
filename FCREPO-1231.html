Glen Robson, 2014-10-27 01:06 UTC

I setup two Fedora instances with legacyfs and Journaling to keep them in sync. When I ingested an object with a managed datastream the layout on the file system is as follows:

Directory layout:

/usr/local/fedora/data/datastreams/2014/1018/20/48 - primary
/usr/local/fedora/data/datastreams/2014/1018/20/53 - secondary

Object dir:

/usr/local/fedora/data/objects/2014/1003/23/34/llgc-id_1 - primary
/usr/local/fedora/data/objects/2014/1003/23/39/llgc-id_1 - secondary

i.e. the directory and file layout is different between the primary and secondary. Does this break the Repository Equivalence rule:

https://wiki.duraspace.org/display/FEDORA37/Journaling#Journaling-intro-equiv

It may not be a big issue but if you are only backing up the secondary (this may be the case if you can't do a hot backup on the primary) then you can't restore the primary database as the paths would be different on the secondary. I can't think of many other situations where this would be a problem.

Glen Robson, 2014-10-27 01:07 UTC
