Description

This can lead to the operating system running out of file handles. Reported by Janna Wemekamp on the fcrepo-user list. More information and reproduce: http://fedora-commons.1317035.n2.nabble.com/fcrepo-user-FedoraCommons-3-4-with-Akubra-Low-Level-Storage-Java-crash-in-REST-API-s-getNextPID-td5480759.html

This problem does not occur when the old AuthN (non-FeSL) is used, so if using fedora-users.xml with Fedora 3.4, it is recommended to answer "false" to "Enable FeSL AuthN?" at install time.
