With the removal of fcrepo-transform Solr indexing was unavailable.

This was fixed with https://github.com/fcrepo4-exts/fcrepo-camel-toolbox/pull/110

Once https://github.com/fcrepo4-exts/fcrepo4-vagrant-base-box/pull/6 is merged, we can once again use Solr indexing in vagrant.

But we need to use the correct version of fcrepo-camel-toolbox and install/configure fcrepo-camel-ldpath.
