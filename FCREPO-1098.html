Hi Frank,

Does "SPO" show up under the "Triples" tab? The "Tuples" tab is expected to not contain anything, as there are no "Tuple" query languages that are supported when you use MPTStore with Postgresql. However, "SPO" (a very basic "Triple" query language) is supported, and should show up under the Triples tab. So this might not be a bug. Please close if you can confirm.
