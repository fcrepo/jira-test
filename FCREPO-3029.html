Description

The task at hand is to address the following warnings in the fcrepo-auth-webac module.

The fix will likely entail replacing any references to the deprecated method "anyObject()" with "any()".

Once this issue is resolved when you build the module using this command

mvn clean install -pl fcrepo-auth-webac

the following warning should no longer appear in the output:
