Description

This is a ticket to enforce ACL controls on ACL resources for non-admin agents. This has two parts: the first is to implement the acl:Control mode, which controls read/write access to ACLs. The second part is to have a file-based backstop (expressed in ACL rdf) for ACLs that don't contain (and whose parents don't contain) the acl:accessControl property.
