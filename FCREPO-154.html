Description

GSearch: Adding parameters to indexing, requested by FIZ Karlsruhe (Matthias Razum and Michael Hoppe) for the eSciDoc project.

Proposed solution:

Add params to indexing in format:

...&indexDocXslt=[xslt-name][(paramname1=value1[,paramname2=value2[,...]])]

Use the parameters at indexing time by putting xsl:param statement in the indexing xslt stylesheet, like this:

<xsl:param name="someparamname" select="defaultvalue"/>

This was implemented in June 2007 and delivered to FIZ. It was satisfactory.

The feature shall be included in next GSearch version.
