Description

This task is to bring the default Root WebACL into alignment with the non-normative example in the Fedora API Specification, namely:

  • Change from default of no access, to default of read-only

See:
Change: https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-http-api/src/main/resources/root-authorization.ttl
..to include:
```
acl:mode acl:Read .
```
