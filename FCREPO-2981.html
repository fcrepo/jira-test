Description

This tool will live along side fcrepo-import-export for the initial phase.  It will be a commandline tool that is intended to migrate an export of one version of Fedora  (starting with 4.7.x) to a more recent version so that it can be imported accordingly.  The task here would be to set up the commandline interface with minimum set of parameters and possibly stub out the known transformations including:

  1. transforming versions
  2. transforming webacs
  3. removing obsolete triples
