Chris Wilper, 2009-12-14 16:56 UTC

After making several changes (now committed to trunk, to be included with Fedora 3.3 release) I was able to get this to work with SQL Server Express 2008 (WinXP/Java6/jTDS JDBC Driver v1.2.4)

The Fedora installer doesn't currently support this option, so it must be configured manually. Here's how I got it working:

1) Install and configure SQL Server 2008 Express:
a) For "sa" (the default admin user), use "fedoraAdmin1!" as the password.
b) In the Sql Server Configuration Manager, under Network Configuration:
i) Enable TCP/IP
ii) Specify 1433 as the port for IPAll
c) Restart the database

2) Download the jTDS JDBC Driver from http://jtds.sourceforge.net/

3) Run the Fedora installer and select "oracle" (yes, oracle) as the install option.

Specify:
JDBC Driver Path: (the path to the jTDS jar you downloaded)
JDBC Driver Class: net.sourceforge.jtds.jdbc.Driver
JDBC URL: jdbc:jtds:sqlserver://localhost:1433
DB Username: sa
DB Password: fedoraAdmin1!

4) After the installer has run, but before starting Fedora, modify
$FEDORA_HOME/server/config/fedora.fcfg

a) Change the backslash_is_escape parameter to "false"
b) Change all occurances of localOraclePool to localMSSQLPool
c) Within the datastore element with id "localMSSQLPool":
i) change the validationQuery value to "select 1"
ii) remove the connection.SetBigStringTryClob parameter

5) Start Fedora for the first time
