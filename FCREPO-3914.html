FCREPO-3914 Bump ActiveMQ in fcrepo-camel-toolkit to a non-exploited version

Description

Whilst the camel toolkit does not run the exploited ActiveMQ server components, and does not listen on port 61616 for Exploitable OpenWire messages, it does package ActiveMQ libraries which are noted as exploited (https://nvd.nist.gov/vuln/detail/CVE-2023-46604 ) . It would make sense to bump the library to a patched version in order to not upset security scans or package audits.

5.16.0-6 is currently packaged. I propose a bump to 5.16.7 in the first case to stay within the major version
