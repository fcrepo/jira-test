FCREPO-3614 Add memento-created field to the resource headers

Description

When a memento is manually created,  currently the last updated date on the resource headers json file is being updated.  This is done because OCFL requires some change to the contents of an object in order to add a new version.  However one side effect is that when you retrieve the body of two identical versions ( such as a head version and a memento based on that head version) the lastUpdated triples will differ is not good since the resource was not updated.   

The solution could to simple add a field such as "memento-created-date" to the resource headers that captures the change required by OCFL but does not change the body of memento source it is based on.
