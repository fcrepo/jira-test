Description

This task is to add OWL reasoning to the Fuseki installation on fcrepo4-vagrant.
The immediate driving use case is to allow fcrepo-indexing-triplestore to "omit" "http://www.w3.org/ns/ldp#PreferContainment" (i.e. ldp:contains) triples but still be able to infer the same relationships via:

INSERT

{ fedora:hasParent owl:inverseOf ldp:contains . }

WHERE {}

These Fuseki updates will likely occur in fcrepo4-vagrant-base-box:
https://github.com/fcrepo4-exts/fcrepo4-vagrant-base-box

The completion of this ticket should also include rolling back:
https://github.com/fcrepo4-exts/fcrepo4-vagrant/pull/41
