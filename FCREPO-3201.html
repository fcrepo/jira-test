Description

When writing a binary to OCFL, pass along a checksum of the default OCFL digest algorithm if one is present in order to perform a transmission fixity check between fedora and OCFL. This will likely need to happen when committing the changes in the current fedora persistence session to OCFL

Comments (4)

Ben Pennell, 2020-06-01 18:26 UTC

OcflObjectUpdater.addFileFixty should be used to provide a digest to the ocfl client. If the file was provided to fedora with the same digest algorithm as is used by the ocfl object being updated, then fedora should provide this digest to the client for transmission verification.

At the moment, the client does not expose which digest algorithm is being used for an ocfl object. Peter Winckles intends to add support for this soon
