Description

This work is still coming together, but with include major improvements for Fedora's AuthN and AuthZ components.

Futher details can be found here: http://fedora-commons.org/confluence/x/h4Ov

FESL should eventually replace the default AuthN/AuthZ functionality built in to Fedora. If there's a need for people to migrate policies, there should be a period of overlap (where the "old way" and "new way" work)...hopefully this can be the case for Fedora 3.3
