FCREPO-2673 Disable Access to PairTree resources by default

TypeNew Feature
StatusOpen
PriorityMinor
ReporterDanny Bernstein
Created2018-02-09 17:21 UTC
Updated2021-09-17 17:42 UTC
Componentsf4-core

Description

HEAD and GET on pairtree resources currently return a 200 response and non-pairtree ldp:contains children.

In order to discourage the use of pairtree nodes by default return a 405 on a HEAD or GET call to a pairtree node.

If a client depends on retrieving child resources via a pairtree node, a system parameter will allow for the user to re-enable the older behavior.
