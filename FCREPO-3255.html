Description

This task is to document various details surrounding the newly implemented containment index (https://jira.lyrasis.org/browse/FCREPO-3164).

The documentation should include description of:

  • what the containment index is used for
  • what are the know limitations (e.g. URL lengths)
  • how to configure different backing databases
  • how to rebuild the containment index (or when it is auto-rebuilt)

Documentation will likely belong in the "Administrators Guide":
https://wiki.lyrasis.org/display/FEDORA6x/Administrator+Guide

..and possibly in the "Application Configuration" section (for setting up databases):
https://wiki.lyrasis.org/display/FEDORA6x/Application+Configuration
