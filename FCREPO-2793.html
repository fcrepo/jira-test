Description

In fcrepo 4.x the response for a binary description would return a describedby property referencing the fcr:metadata

iana:describedby        <http://localhost:8080/rest/binary/fcr:metadata>

Currently on master it is instead returning:

iana:describes        <http://localhost:8080/rest/binary>

This is caused by the refactoring of NonRdfSourceDescription to be the description of the binary, instead of FedoraBinaryImpl providing the description as its triples.

Need to updated

https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-kernel-modeshape/src/main/java/org/fcrepo/kernel/modeshape/rdf/impl/ContentRdfContext.java#L56

to add a describedby link instead.
