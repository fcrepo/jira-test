Description

If you try to import the Fedora projects into IntelliJ, you get a number of unresolvable classes. This is because they are generated by axistools, but the output directory is not where IntelliJ expects it to be.

These modifications to the Maven projects alter the location of the generated classes, so that IntelliJ can find them. All references across modules (ie. for assemblies) have been adjusted to remain consistent.
