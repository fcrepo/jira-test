Description

I'm running a VM with Fedora Commons 3.4.2 and Mulgara 2.1.4 . I want to use the latest functionality of Mulgara, which is now at 2.1.13.
What I did was:

  • renamed mulgara-core-2.1.4.jar to mulgara-core-2.1.4.jar.backup
  • deployed the latest files to the lib folder ( /usr/local/fedora/tomcat/webapps/fedora/WEB-INF/lib )
  • restarted Fedora (tomcat)

After that I saw that the Fedora java processes were running but I couldn't access Fedora.

Has anyone tried this before? Any tips or ideas?

Chris Wilper, 2012-02-16 20:11 UTC

Hi Danny,

We don't recommend you try to upgrade the embedded Mulgara due to dependency issues and changes outside of our control, but if you want to stay up to date with the latest version, you configure Fedora to use an external Mulgara. See this document:

https://wiki.duraspace.org/display/FEDORA35/Resource+Index#ResourceIndex-RemoteMulgaraDatastoreConfiguration

Same instructions for 3.4.x. We're also working on making this configuration option more apparent to folks when they first install Fedora.
