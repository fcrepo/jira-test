Fedora's WSDL does not declare faults. As a consequence, when going against the SOAP interfaces, this causes a generic fault to be thrown when errors occur.

Better would be to use WSDL faults, which map to SOAP faults, which can include error codes, which clients can interpret. There are many references online that detail how to do this. For starters, google(wsdl faults best practice)
