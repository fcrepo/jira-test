Description

There is a <prerequisite> block in the fcrepo-parent pom file.

During build you get a warning
[WARNING] The project org.fcrepo:fcrepo-parent:pom:6.0.0-SNAPSHOT uses prerequisites which is only intended for maven-plugin projects but not for non maven-plugin projects. For such purposes you should use the maven-enforcer-plugin. See https://maven.apache.org/enforcer/enforcer-rules/requireMavenVersion.html
As such and because we have the maven-enforcer-plugin in the main pom file, this can be removed.
