FCREPO-624 For consistency, use info:fcrepo, not info:fedora

TypeStory
StatusClosed
ResolutionWon't Fix
PriorityMinor
ReporterChris Wilper
Created2010-01-12 16:29 UTC
Updated2011-10-18 22:58 UTC

Componentslegacy - Fedora

Description

On the Jan 5 '10 committer call, Asger pointed out that Kare mentioned this when talking about consistent naming...the info:fedora URIs would ideally be info:fcrepo.

We need to consider the impact of doing this and decide if the consistency is worth the cost.

[ Impact ]

1) Need to register a new info: prefix with the NISO info URI registry
2) Need to decide how to deprecate "info:fedora"...just drop it, or support both for some period of time?
3) Existing RDF queries would need to change

Comments (3)

Stephen Bayliss, 2010-04-11 18:40 UTC

Impact (3) needs careful consideration - this could potentially affect a lot of external code written against Fedora using the resource index; we'd need to ensure the justification is good enough if we're expecting people to modify existing code.

eddie, 2010-05-04 16:26 UTC

I'm doubtful the pros could possibly outweigh the cons on undertaking this change. There's so much potential breakage as well as end-user confusion and the further pain for clients working against a mix of repos before and after this change.

Chris Wilper, 2010-05-04 16:33 UTC

Consensus on 6/4/10 committer call: Impact of changing this would be too high to justify the benefit (consistency).
