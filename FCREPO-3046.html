Description

This task will involve renaming the FedoraSession to FedoraTransaction, defining the interfaces (specified [here|https://wiki.duraspace.org/pages/viewpage.action?pageId=133366058]) and creating an implementation.  Start with an in-memory transaction state store.  It would also be good to check prior art with respect to Spring's transactional framework(s) to see if it makes sense for us to use established patterns.
