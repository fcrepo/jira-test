FCREPO-3536 Fedora ID length limit

TypeImprovement
StatusOpen
PriorityMinor
ReporterAndrew Woods
Created2020-11-18 19:03 UTC
Updated2024-01-11 21:37 UTC

Description

Currently, the size of the Fedora ID column configured for MySQL, MariaDB and PostgreSQL is based on a least-common-denominator approach rooted in MySQL's the table/index limitation. Empirically, the limit for the Fedora ID varchar column has been seen to be 503 characters.

  • https://dev.mysql.com/doc/refman/8.0/en/innodb-limits.html

This task is to explore potential technical solutions for expanding the current limit of 503 characters. Ideally, the size limit on Fedora IDs would be informed by actual community use cases.
