FCREPO-864 Tomcat6 wont start as a service on Win-2008-r2

Environment

Win-2008-r2 which is 64-bit, VMware workstation

Description

Did a fresh install on a new system, for evaluation purposes. Tomcat starts well when launched interactively (startup.bat). But registering Tomcat6.exe as a service (by service.bat), it refuses to start, and a system error event 7042 is logged, along with the fuzzy message: "The Apache Tomcat 6 service terminated with service-specific error The operation completed successfully.."

It turned out that the Tomcat binaries (tomcat6.exe, tomcat6w.exe) were 32-bit. Appearently, Win-2008-r2 doesn't like this in the windows service context. Replacing them by 64-bit binaries found elsewhere (apache-tomcat-6.0.29-windows-x64.zip), the service starts properly, but I didn't check it thoroughly, as i'm really a novice in this domain.
