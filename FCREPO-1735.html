Description

This task is to replace the existing RBACL option in fcrepo4-vagrant to pull in a snapshot version of fcrepo-module-auth-webac instead.

This is the configuration element that can remain the same:
https://github.com/fcrepo4-labs/fcrepo4-vagrant/blob/master/install_scripts/config#L18

These two sections should pull in webac instead of rbacl:
https://github.com/fcrepo4-labs/fcrepo4-vagrant/blob/master/install_scripts/fedora4.sh#L13-L18

The default admin username and password (fedoraAdmin:secret3) should be configured into the fcrepo-camel-toolbox install, such as:
https://github.com/fcrepo4-labs/fcrepo4-vagrant/blob/master/install_scripts/fedora_camel_toolbox.sh#L17

...in order for Solr indexing to work as detailed here:
https://github.com/fcrepo4-exts/fcrepo-camel-toolbox/tree/master/fcrepo-indexing-solr#configuration
