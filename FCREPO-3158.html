FCREPO-3158 Convert internal to external binaries

TypeImprovement
StatusOpen
PriorityMinor
ReporterBen Pennell
Created2019-12-18 13:30 UTC
Updated2021-07-07 17:07 UTC
Affects versionsFedora 6.0.0
Labelsfcrepo-6.1.0

Description

Fedora needs to be able to handle the case where a non-rdf resource was created as an internal binary, but is subsequently changed to an external binary. This was supported in previous version.

This will most likely impact the persister for updating non-rdf resources, and require removal of the internal binary file from the head version of its containing OCFL object.
