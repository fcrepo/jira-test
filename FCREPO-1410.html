FCREPO-1410 Enforce trailing a '/' on LDPC URIs

Description

The LDP specification recommends using a trailing slash in the URIs of containers:
http://www.w3.org/TR/ldp-bp/#include-a-trailing-slash-in-container-uris

This task is to:
1) confirm with the F4 committer team that this is a recommendation that we want to enforce
2) investigate the impact of enforcing this recommendation
3) implement it

It seems to me that since it's only a recommendation it shouldn't be enforced. Perhaps produce a warning when a PUT is made.

ModeShape treats both cases as the same. That is, creating 'test/' when 'test' exists results in an exception. (This is assuming that no path manipulation, e.g., truncating, is done somewhere in the stack).

On a side note, the PATCH request (via FedoraLDP) does not recognize the trailing slash. DELETE works ok.
