This is because the RELS-INT contains RDF and really should be applied to the appropriate resource. By mimicing what we're doing with RELS-EXT, I'm running into an issue where we're trying to apply RDF properties to the old fedora 3 pid, and not the new path in fedora 4.

<rdf:Description rdf:about="info:fedora/islandora:6/JP2"><width>4081</width><height>5132</height></rdf:Description>

This is what's tossing in the monkey wrench.

I'll see if I can take advantage of our ID mapper to try and resolve the appropriate resource.
