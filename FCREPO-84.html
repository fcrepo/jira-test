Description

Fedora's existing module framework needs revisiting. While the existing framework allows for some degree of extensibility by replacing existing modules, there's no easy way to add a completely new module without modifying server code (e.g. Server, DefaultManagement, or DefaultDOManager).

On April 16th, 2009, the committers discussed and agreed to move toward using Spring Dynamic Modules (OSGi) for Fedora's future module plugin framework.
