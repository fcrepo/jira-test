Description

This issue is to address the dependency that the demo-objects, and hence the unit tests, have on externally hosted content. This makes the builds vulnerable to the availability of other systems.

Note: The reason this issue has higher priority is because with the current demo-objects, not all ConfigB tests pass (fedora.test.api.TestXACMLPolicies) since demo:31 refers to an item not currently available (http://www.fedora-commons.org/demo/misc/batikBatik.svg).
