Description

To reproduce:

1. fire up fcrep4:

java -Dfcrepo.dynamic.jms.port=61717 -Dfcrepo.dynamic.stomp.port=61713 -jar fcrepo-webapp-4.8.0-SNAPSHOT-jetty-console-a07a1a46.jar --port 8686 --headless --contextPath /f4

2. Create a container and add a binary. (test/binary1)

3. create a version (v1)

4. create a second version (v2)

5. Do an export:
(commit 7f0d76)
java -jar target/fcrepo-import-export-0.1.1-SNAPSHOT.jar -d ~/import-export-sprint-3/data-export-versioned-binaries -a -m export -r http://localhost:8686/f4/rest -b -V

6. Verify that the importer outputs the following error:

ERROR 15:17:27.170 (ImportExportDriver) Error performing import/export: Export operation failed: unexpected status 500 for http://localhost:8686/f4/rest/fcr:versions

Fcrepo4 puts out the following:

ERROR 15:17:27.165 (WildcardExceptionMapper) Exception intercepted by WildcardExceptionMapper: 1
