Description

This task is to create a Vagrant setup that can be used in F4 one-day trainings, like the upcoming training in D.C.
https://wiki.duraspace.org/display/FF/Training+-+DC+Area+Fedora+User+Group+Meeting%3A+31+March+-+1+April+2015

Ideally, this Vagrant setup would include:

  • Tomcat7
  • Fedora4
  • Solr
  • Fuseki

https://github.com/Islandora-Labs/islandora/blob/7.x-2.x/install/Vagrantfile
