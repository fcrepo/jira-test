FCREPO-3680 Don't iterate through all foxml files once a batch of pids is complete

Updated2021-04-16 18:25 UTC

Description

One way to run the migration-utils is to give it lists of pids to migrate in batches. However, when it has the list of pids to migrate, it seems to iterate through all the foxml files in the repo, and just migrates objects that have a pid in the pid list.

This works, but it means there can be long gaps of migration-utils logging nothing and just cycling through all the objects it doesn't need to migrate.

One simple change that would help would be to check for whether the pid list of fully migrated, and if so, to quit the migration. That way you at least wouldn't have a long gap at the end of the run.

I'm not sure how to change migration-utils from needing to iterate through all the objects until it finds all the pids in the list.
