FCREPO-749 The ownerId object property is added automatically with no value when not supplied during FOXML ingest.

Environment

Fedora 3.3, com.yourmediashelf.fedora.client 0.1.2, REST API

Description

When using the REST API via the MediaShelf Fedora client, the ownerId object property is created even though it is not in the supplied FOXML. It is given the value of an empty string. It would expect either to default to the login credential or not be added automatically. I have not tested yet from the command line or other clients to isolate the problem.
