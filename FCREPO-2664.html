FCREPO-2664 Narayana needs properties or tries to use user.home

Fix versionsFedora 5.0.0, Fedora 4.7.5

Description

Depending the system configuration, trying to deploy the new 4.7.5 to a tomcat container can cause a NullPointerException.

This is because Narayana reads the objectStore directory from a jbossts-properties.xml file or uses user.home by default.

If your Tomcat user doesn't have a home directory or doesn't have write persmission this results in an error.
