Description

At the moment, DC datastreams are only migrated as resources. It would be useful to have some (or all) of the DC elements mapped to RDF properties, in addition to migrating the resource. This functionality seems to have been removed for the Fedora 6 version of migration-utils, even though the custom-mapping.properties file is still in the current codebase https://github.com/fcrepo-exts/migration-utils/blob/main/src/main/resources/custom-mapping.properties

Our use case would be to expose a Handle persistent identifier, which we have in dc:identifier, but in principle most of the DC elements are relevant in an LDP context.
