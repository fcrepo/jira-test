Description

env-server.sh relies on Fedora being installed in a 'webapps' directory:

set WEBINF="%CATALINA_HOME%\webapps%WEBAPP_NAME%\WEB-INF"

when it's installed separately from Tomcat (to allow easier upgrades), e.g.

/WWW/domain.name/fedora

the rebuild fails to run.
