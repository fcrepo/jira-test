This task is to update fcrepo4 logic to filter out what is exposed to the user as "fedora:mimeType".

Currently, after running the following steps, "fedora:mimeType" still exists:

  • Start a 4.2.0 fcrepo and add a binary resource
  • Run the fcrepo4-upgrade-utility over that repository
  • Start master branch of fcrepo => see fedora:mimeType still exists
