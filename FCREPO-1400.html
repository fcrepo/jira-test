FCREPO-1400 Webapp container elements are inconsistent with bootstrap best practices

Description

In Bootstrap, the container element applies a left and right padding and restricts the width to a defined max. This element should be used as a inner wrapper for content to avoid unnecessary padding that could cause undesired horizontal scrolling and breaks in the UI.

The fix is to create wrapping elements and give the container class to the inner element. This will allow the header to span 100% of the page as expected, while the content is wrapped in a confined container.
