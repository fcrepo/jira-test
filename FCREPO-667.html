FCREPO-667 Parsing of dates may fail with non-US system locales

Description

When using a different system locale than en_US the parsing of dates containing short weekdays may fail if the particular locale does not recognize the name of the weekday.

Given the date string: "Thu, 01 Jan 1970 00:00:00 GMT", the pattern "EEE, dd MMMM yyyyy HH:mm:ss z" and the system locale de_DE.UTF-8 (export LC_ALL="de_DE.UTF-8"), the parser will throw an exception. The correct date string for this locale would be "Do, 01 Jan 1970 00:00:00 GMT". The same may apply to month short names.
The affected class is org.fcrepo.server.utilities.DateUtility. Also, when running the integration tests with configA the test testParseDate() in org.fcrepo.server.utilities.TestDateUtility fails.

The suggested fix is to use the en_US locale when initializing SimpleDateFormat.
