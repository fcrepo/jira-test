FCREPO-4029 Make truncating indexes optional

Description

In fedora 6, if the fcrepo-home directory isn’t present, the application assumes that it is a new install and proceeds to truncate the tables in the database and starts indexing even if the fcrepo.rebuild.on.start property is false.

For safety reasons, it would be good for fedora to check if the database is empty before doing this. If it is, then fedora can continue with reindexing as if it were a new install. If the database is not empty, then at a minimum we should not truncate the tables unless the user has supplied a flag to permit it. Whether or not indexing would occur at this point is not yet determined.
