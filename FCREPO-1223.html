FCREPO-1223 Default configuration for Postgres backend inappropriate for Postgres 9 defaults

Description

See http://www.postgresql.org/docs/current/static/runtime-config-compatible.html#GUC-STANDARD-CONFORMING-STRINGS

PostgreSQL 9.1 now "treat[s] backslashes literally, as specified in the SQL standard." This makes the default value of:
<param name="backslashIsEscape" value="true"/>

for the ILowLevelStore module in fcfg inappropriate.
