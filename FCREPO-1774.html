FCREPO-1774 API to return Fedora version number

Description

Fedora 3 provided an API method ('describe') which would return the Fedora software version number (among other things). As near as I can tell, Fedora 4 only reports the version number in HTML (on the top level /fcrepo page). It would be good to be able to get the version number via an API call as in Fedora 3.

A. Soroka, 2016-05-12 15:41 UTC

Hey, Jim Coble! We have discussed this ticket a bit on today's tech call. We think we could do this without too much trouble, but we wanted to check with you to understand the need a bit better. Are you trying to negotiate capabilities with your Fedora instances? Are you trying to understand whether a given interaction can successfully begin or complete?

As you've probably noticed, we want to push folks as much as possible towards a REST HATEOS style of interaction, which implies discovering capabilities as part of HTTP interactions. So we want to make sure that you have a way to do what you need to do that doesn't depend on anything as fragile as parsing build numbers or the like.
