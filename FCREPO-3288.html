Description

When deleting a subpath or tree of items we should also check for ACLs for each deleted resource and if they exist remove them as well.

Open question: If you delete an item that previously had view restrictions are those restrictions now removed and the tombstone is visible to all? Or should the ACL continue until such time as the resource is purged? (ie. DELETE resource/fcr:tombstone)
