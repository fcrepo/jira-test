FCREPO-742 REST endpoint purgeRelationship does not indicate if the relationship was purged

Description

The current implementation of the purgeRelationship REST endpoint does not indicate if a relation was actually purged. It returns "204 no content" in all cases. It should however return whether the operation succeeded or not (as supported by the respective APIM method).

eddie, 2010-07-26 06:44 UTC

fixed in r8715 (now returns a 200 status code w/ response body of "true" or "false" depending on whether or not the purge succeeded).
