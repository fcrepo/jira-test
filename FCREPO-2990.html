Description

The configuration option to provide fedora with a namespace registry (fcrepo.namespace.registry) should be listed here:

https://wiki.duraspace.org/display/FEDORA5x/Application+Configuration

Which should also link out to the more detailed description of namespace registries here:

https://wiki.duraspace.org/display/FEDORA5x/Best+Practices+-+RDF+Namespaces

This second document also needs to be updated to remove language stating that fedora automatically registers new namespaces.

It may be helpful to list in one of these documents that there is a default namespace registry file used, which is located at https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-webapp/src/main/resources/namespaces.yml
