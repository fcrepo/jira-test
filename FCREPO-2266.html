FCREPO-2266 application/xml is not a valid RDF serialization

Description

In various places in the Jax-RS code, it appears that application/xml is a valid output format. This, however, is not true. application/xml is not a valid RDF serialization (application/rdf+xml is a valid serialization), and so the code should remove references to application/xml.
