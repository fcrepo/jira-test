Description

Based on a discussion BillB, ChrisW, TimD, Asger, and others had at OR09:

Move toward having a war file for Fedora that doesn' t need to be modified.

1) Make AuthN stuff plug in via an always-configured servlet filter that delegates to what's configured
2) Don't use Tomcat for SSL (recommend Apache for this)
3) Make "fedora home" conventionally at /fedora (and don't include it in the war by default)

There was also some discussion that needs to be further rationalized re: running multiple Fedoras in one Tomcat. A couple ways to go:

a) require that people edit the war file in these cases (to point to a different fedora.fcfg)
b) have a convention where it's stored in /fedora/config/fedora-context.fcfg

Looking at this again, I like a) because it seems to be needed anyway if people need to install in a dir that isn't /fedora (e.g. /usr/local, or whatever convention their sysadmin uses)
