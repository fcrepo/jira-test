Description

We wanted to set up Fedora and SSL, and ran with some issues. 

 

After setting up SSL in Apache (80 redirection to 443, works as a proxy), and Tomcat using 8080, Fedora would return 404 errors on the GUI when browsing the repository. With CURL it worked well, but it doesnt translate (apparently) the URL to https.

 

Details might be found on the next thread on slack:
