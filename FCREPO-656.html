FCREPO-656 Support for indexing "arbitrary" RDF datastreams in the resource index

Depends onFCREPO-652 Restructure resource index as a set of named graphs

Description

Currently RDF datastreams that are indexed in the resource index (RELS-EXT, RELS-INT) must have either a Fedora object or datastream as the subject. If the resource index is restructured as a set of named graphs this restriction could be removed, allowing richer RDF metadata to be propagated to the resource index.

See http://fedora-commons.org/confluence/display/DEV/Supporting+the+Semantic+Web+and+Linked+Data

Isn't it the case that we would require here not just named graphs, but Mulgara-style views over named graphs? Without that affordance, it would seem very difficult to query over the "full" graph.

Stephen Bayliss, 2011-11-16 21:20 UTC

Yes we would certainly need a mechanism for querying the full RI graph as-a-whole, and Mulgara views are a route for doing that. Some while ago I did some performance testing on this - single graph vs view over a number of graphs and the numbers were not good.

One could potentially use the SPARQL route of querying GRAPH ?g

{ ?s ?p ?o }

- I haven't tested that.

My view is that the Fedora RI should stay as it is (or even in the future be moved out of Fedora). Although being able to handle things described in this ticket would certainly be of value there's a whole host of other things that could also be of value in a semweb context. Consider entailment, and managing that, or other forms of reasoning. Or entity recognition from full-text and adding that to the RI. There's a point where we'd be in danger of developing something where a solution already exists, and my view is that the effort would be better spent on integration with tools built for the job.

A. Soroka, 2011-11-16 21:54 UTC

I really wish we had some kind of actual data on who uses the RI and to what level of sophistication. The inability to use subjects other than Fedora objects and datastreams has been a hindrance to me in the past, but I have no way of knowing if that is a common experience or very rare. It seems to me that to make a good decision about this present issue (as well as FCREPO-652 Closed ) we need to know something about people are actually using the RI and how they want to, but I confess, I don't know how to learn that.
