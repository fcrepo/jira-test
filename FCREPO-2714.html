Description

This task is to remove the duplicate headers found when performing a GET request on binary resources.
To reproduce:

  • Create a binary resource (http://localhost:8080/rest/image)
  • curl -i localhost:8080/rest/image -o image.out

Inspect image.out for duplicated headers:

  • ETag
  • Last-Modified
