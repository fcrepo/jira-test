Description

This task is to remove the accordion for each "Historic Version" listed on the /fcr:versions page for a resource.
Currently, there is a `+` that opens an empty accordion panel.

To reproduce in the HTML UI:

  • create a resource
  • create a version of the resource
  • view the mementos
  • Observe the empty accordion panel for the newly created memento.
