Description

On fcrepo-webapp-plus, when running:
mvn clean install -Paudit

Regardless of which profile(s) the project is built with, the sanity should test to run successfully.

This ticket will be resolved with the following four commands complete successfully:
mvn clean install
mvn clean install -Prbacl
mvn clean install -Pxacml
mvn clean install -Paudit
