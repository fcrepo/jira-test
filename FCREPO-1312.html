My initial thought is to completely remove the RdfStream class, replacing it with a StreamUtils class consisting of static functions that return instances of Stream<Triple>. I also have defined a Collector for toModel.

The other component to this will be to create an Enumeration in kernel-api that defines a set of "contexts". Unknown, 2016-02-14 22:37 UTC

See: https://github.com/fcrepo4/fcrepo4/pull/962

This is a very large PR, which includes shifting a number of classes from the kernel-api into the kernel-modeshape module. It does not replace all instances of Iterators in the kernel-api, only those that were necessary to accomplish the task of reimplementing the RDF generation framework. This also eliminates many of the HTTP modules' dependencies on the modeshape module. Those that remain can be handled through injection and/or simple refactoring, but they were beyond the scope of this ticket.

The default implementation of RdfStream is in the same package as the interface (org.fcrepo.kernel.api.rdf). If there is a better location for that, now would be a good time to make that recommendation.
