Description

This is the example where we want a method to take a
set of datastreams as input. We want there to be a
single datastreams binding key for the set such
as "PHOTOS" and then a list of image/gifs can be
associated with this key. Right now we can associate a
single datastream ID with a binding key.

We need to develop a set of use cases to better characterize this item. On the one hand this may be a kind of agility for BMECH bindings which permits variable numbers, kinds, or types in calling parameters. Especially for types this is consistent with the CMDA notion of models. This may also work for cardinality where a BMECH is bound to a variable number of similar parameters (like having one chapter of a book in each datastream - the number of chapters vary between books).
