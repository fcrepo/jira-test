Description

Fcrepo4-vagrant indexes content to Solr and Fuseki. It uses the default configuration of fcrepo-solr-indexing and fcrepo-triplestore-indexing.
https://github.com/fcrepo4-exts/fcrepo-camel-toolbox/tree/master/fcrepo-indexing-solr#configuration

When performing automated testing for Fedora using the fcrepo-tests the fast addition and removal causes fcrepo-XXX-indexing fails to retrieve the resource (because is it deleted) but it will retry each item a total of 10 times.

This ticket is to reduce this number to 1 inside of fcrepo4-vagrant. This is purely a configuration change and does not affect any of the components (fcrepo4 or fcrepo-camel-toolbox).
