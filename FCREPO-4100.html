FCREPO-4100 Allow overriding fcrepo file size header when creating external binaries

Description

At present fedora supports setting premis:hasSize in an attempt to allow external binaries where fedora either cannot or should not retrieve the external content in order to determine the size of the file. This allowance is problematic and produces unexpected outcomes, and is not scoped to external binaries.

In order to scope this allowance exclusively to external binaries, we should introduce a "size" parameter to the ExternalContent Link header supplied during creation/update. Custom params should be allowed by the spec, and we in fact already require one custom param, “handling”. Here is an example with the new size param:

curl -i -H"Link: <file:///local/file/storage/wonderful.tiff>; rel=\"http://fedora.info/definitions/fcrepo#ExternalContent\\"; handling=\"proxy\"; type=\"image/tiff\"; size=\"6551596\"" -XPUT -ufedoraAdmin:fedoraAdmin http://localhost:8080/rest/test_proxy

We would set the fcrepo size header for the binary from this value. That is used to set Content-Size and premis:hasSize/premis3:size in responses. If its not supplied, then the size would be set with existing behaviors.

This may be considered a new feature, and as such would target a minor release.
