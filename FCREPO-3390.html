Description

It appears that the import/export test infrastructure conflicts with the default Fedora ports (8080, 61616).

To see the error, start Fedora in Tomcat (as with the one-click Jetty-run).
Then build the import/export tool (mvn clean install)... see test failures.

One difference with the import/export tooling from other Fedora projects is that it uses "cargo". The core Fedora project has test configuration that selects random ports instead of the defaults. I would be happy to discuss the example of Fedora's configuration if that would be helpful.
