Description

Our FOXML and METS schemas need to be versioned for Fedora 3.0.

Output of this feature:
1) Two new sets of schemas (foxml and mets, xsd and schematron for each)

  • Each schema, where it makes sense, should NOT allow the use of disseminators.
  • Where possible, a schema version number should be asserted in the FOXML (or METS?) itself. This is to support out-of-context use of METS or FOXML files (where looking at the instance indicates what version of the format they are in)
