FCREPO-3906 FCREPO uses json-ld-1.0 processing mode but silently accepts json-ld-1.1 directives

TypeDocumentation
StatusOpen
PriorityMinor
ReporterQuinn Hart
AssigneeThomas Bernhart
Created2023-10-01 15:42 UTC
Updated2024-01-31 17:31 UTC
Componentscore
Affects versionsFedora 6.4.0

Description

FCREPO uses the json-ld-1.0 processing mode, but it will silently accept version 1.1 which it doesn’t process. This can lead to users getting different data out from they thought they put in.

Adding “@version": 1.1 to the concept does stop processing

An upgrade to json-ld version 1.1 would be a nice improvement, better documentation in the API specs might alert users.

Here’s an example that can cause developers days for confusion 🙂 

{
  "@context": {
    "@vocab": "http://vivoweb.org/ontology/core#",
    "vcard": "http://www.w3.org/2006/vcard/ns#",
    "person": "http://ucdavis.edu/person/",
    "hasName": {
      "@id": "vcard:hasName",
      "@type": "@id",
      "@context": {
        "family": {
          "@id": "vcard:familyName"
        }
      }
    }
  },
  "@id": "person:quinn",
  "hasName": {
    "@id": "person:quinn#name",
    "family": "Hart"
  }
}
