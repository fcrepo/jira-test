Description

The task here is to gather the requirements for and design a stats collection service for Fedora.

At a minimum the service should periodically poll the /fcr:stats endpoint and save the results (probably to the database)

The API should support:

  1. turning on the service
  2. specifying the polling period in minutes, hours, days, month
  3. Retrieving the results between dates

The HTML UI should support:

  1. turning on the service
  2. specifying the polling period in minutes, hours, days, month
  3. Retrieving the results between dates
  4. When retrieving the results, the user should have the opportunity to opt in to sharing stats data with the Fedora Organization. The HTML javascript client must be able to post the downloaded file to along with any identifying information (Organization, contact info) to a Fedora Organization controlled endpoint.
