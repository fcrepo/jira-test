Description

Store attributes internally in a Map<String, String[]>, thus removing a whole lot of conditional logic and behavioral inconsistency.

Create separate methods for set(String, String) and set(String, String[]) instead of accepting either in set(String, Object).

Modify getString(String) so it will return the single value (if any) that was stored under that key. If strict upward compatibility is required, it could throw a ClassCastException if more than one value is stored. More likely, it would be acceptable to either return the first such value, or to throw an IllegalStateException.

Modify method signatures to throw specific exceptions (NullPointerException, IllegalArgumentException, etc.) instead of bare Exception.

Genericize method signatures and internal variables.
