Description

Per Aaron Birkland, "it looks like fcrepo-http-commons and fcrepo-kernel-modeshape both pull in a JTA dependency: org.jboss.jbossts:jbossjta

"However, it looks really old and unmaintained – the latest release is five years old: https://mvnrepository.com/artifact/org.jboss.jbossts/jbossjta"

We should update to Modeshape's new recommended JTA, Narayana. The latest version is 5.7.0.Final.
