Description

The minimum implementation to support Indirect Containers. 

The resolution to this ticket should include resolutions to the following Fedora API Test Suite failures, or result in the creation of appropriate follow-on tickets.

  • https://fedora.info/2018/11/22/spec/#ldpic
    Implementations MUST set the indirect container's ldp:membershipResource by default when not specified on creation.
  • https://fedora.info/2018/11/22/spec/#ldpic
    Implementations SHOULD set the indirect container's ldp:membershipResource to the LDPC by default when not specified on creation.
  • https://fedora.info/2018/11/22/spec/#ldpic
    Implementations must allow the indirect container's membership predicate to be set by default to an implementation defined value.
  • https://fedora.info/2018/11/22/spec/#ldpic
    Implementations should use the default <> ldp:hasMemberRelation ldp:member
  • https://fedora.info/2018/11/22/spec/#ldpic
    Implementations must allow the ldp:insertedContentRelation property to be set by default to an implementation defined value.
  • https://fedora.info/2018/11/22/spec/#ldpic
    Implementations SHOULD allow the ldp:insertedContentRelation property to be set by default to ldp:MemberSubject.
