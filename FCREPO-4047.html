Description

When creating Binary resources then reindexing, I observed that the count of NonRdfSourceDescription and all resources at the fcr:stats endpoint was changing after a subsequent reindexing. After more testing, it appears that when adding binaries the NonRdfSourceDescription entry is generally not being added, although I did observe that when I run a bulk object creation script that the NonRdfSourceDescription count goes up about half as much as the Binary count.

To verify this issue, run mvn jetty:run -pl fcrepo-webapp on main, go to:
http://localhost:8080/rest/fcr:stats

You should see all zeros (assuming you were starting fresh). Then create a couple binaries in the UI, and visit fcr:stats again. You should now see the http://fedora.info/definitions/v4/repository#Binary count equal to the number of binaries you created, but there are no NonRdfSourceDescription entries.

Next, stop jetty, and then run it with reindexing turned on:

mvn -Dfcrepo.rebuild=true -rf fcrepo-webapp jetty:run

Now go to fcr:stats again, and there will be a NonRdfSourceDescription count equal to the number of binaries. The resource_count also will have gone up, since it includes the NonRdfSourceDescriptions
