Esmé Cowles, 2017-11-01 20:47 UTC

From https://github.com/fcrepo/fcrepo-specification/issues/235:

The F4 docs use sha1 as the digest name for SHA-1 digests. However, RFC3230 uses SHA (the value is case insensitive) and so does the IANA registry (sha256 and sha512 are also defined, there is no mention of sha1). If the Fedora API says "follow RFC3230" then I think that means using sha.
