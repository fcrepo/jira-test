Description

Several people have reported success with running Fedora under OpenJDK. As OpenJDK is the favored line of Java distros for open source operating systems (Sun's JDK is no longer available in any package repositories in later versions of Ubuntu), I think we ought to declare official support for OpenJDK with the next Fedora release. This means we should also have at least one tester using OpenJDK.

Initially, this means supporting OpenJDK 6. Later, when FCREPO-989 Closed is resolved, it can include OpenJDK 7.
