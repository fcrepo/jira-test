FCREPO-3144 Make migration-utils default log level INFO for all migration-utils classes

Description

Currently migration-utils is configured in the logback.xml file to show DEBUG output for the org.fcrepo.migration classes:

<logger name="org.fcrepo.migration" additivity="false" level="DEBUG">
 <appender-ref ref="STDOUT"/>
 </logger>

Change the level to "INFO", then verify that the level is set to DEBUG only when the utility is run with the  --debug flag.
