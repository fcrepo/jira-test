Description

The namespaces defined in the Fedora CND should be reviewed, especially test: and fedoraconfig:

In particular, the test: namespace prefix seems like an unnecessary testing artifact that is present in production deployments. Furthermore the fedoraconfig: namespace points to a non-existent URL. It may be much better to remove the test: prefix and use a non-dereferenceable namespace for fedoraconfig: (i.e. <info:fedoraconfig/>)
