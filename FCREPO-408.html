Description

The Fedora repository homepage at http://localhost:8080/fedora/ has the following content:

Apache-AXIS
Hello! Welcome to Apache-Axis.

What do you want to do today?

Administer Axis link #1
Visit the Axis Servlet link #2

Either this link should be made to work, or it should be removed entirely. Thanks!
