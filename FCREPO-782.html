Description

Because of the java package renaming, the migration tool used to upgrade 2.x repositories to 3.x does not work (see https://wiki.duraspace.org/display/FCR30/Upgrading+from+2.x).

We could either
1 just update the tool against the latest server jars, and update the references to fedora.fcfg where module etc names have changed
2 update package names in this migration tool as well
3 go the whole way and mavenise it as well.
