Per the Turtle spec, """-escaped literals can contain any characters (including line breaks, carriage returns, etc.), other than """:

http://www.w3.org/TR/turtle/#h4_turtle-literals

Former user, 2015-03-06 15:28 UTC

I did some testing of this and found that RDF/XML can successfully include values with linebreaks, e.g.:

<?xml version="1.0" encoding="UTF-8"?>
<rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#"
xmlns:dcterms="http://purl.org/dc/terms/">
<rdf:Description rdf:about="http://localhost:8080/fcrepo4/rest/foo">
<dcterms:title>Test title value

with linebreaks</dcterms:title>
</rdf:Description>
</rdf:RDF>

The output in Turtle then include the value, with """-escaping. So I don't think the issue is that Jena lacks support for """-escaping since it's using it in the output.

Former user, 2015-04-17 13:28 UTC

I think the issue here is that """-escaped literals work, but the value inside cannot end with a ". If I translate the value in that test to a curl command, I get:

curl -i -X POST -H "Content-Type: text/turtle" --data-binary "<> <http://purl.org/dc/terms/description> \"\"\"Data for:\r\nJournal: Journal of Geophysical Research: Solid Earth\r\n\r\nArticle title: \"On the Origin and Evolution of Electrical Signals During Frictional Stick-Slip in Sheared Granular Material\"\"\"\"" "http://localhost:8080/fcrepo4/rest"

This fails because it ends with four " symbols in a row. The first three are interepreted as the end of the quote, and the final " produces the error. If I add a space after the value and before the """-terminator, then it works:

curl -i -X POST -H "Content-Type: text/turtle" --data-binary "<> <http://purl.org/dc/terms/description> \"\"\"Data for:\r\nJournal: Journal of Geophysical Research: Solid Earth\r\n\r\nArticle title: \"On the Origin and Evolution of Electrical Signals During Frictional Stick-Slip in Sheared Granular Material\" \"\"\"" "http://localhost:8080/fcrepo4/rest"

It will also work if I backslash-escape the quotes:

curl -i -X POST -H "Content-Type: text/turtle" --data-binary "<> <http://purl.org/dc/terms/description> \"\"\"Data for:\r\nJournal: Journal of Geophysical Research: Solid Earth\r\n\r\nArticle title: \\\"On the Origin and Evolution of Electrical Signals During Frictional Stick-Slip in Sheared Granular Material\\\"\"\"\"" "http://localhost:8080/fcrepo4/rest"
