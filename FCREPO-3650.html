Description

At the moment, there are no restrictions on use of the "fcr:" prefix in URLs of resources on creation.

This request creates a resource named "fcr:stuff"

curl -ufedoraAdmin:fedoraAdmin -XPUT http://localhost:8080/rest/fcr:stuff -v

This is different from previous versions of fedora, and can result in creation of resources with names that overlap with reserved endpoints, like "fcr:tx". You can create http://localhost:8080/rest/hello/fcr:tx
