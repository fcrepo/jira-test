Success!

Steps:
1. a Fedora with LevelDB, create two containers and one binary
2. backup: curl -X POST "http://localhost:8080/fcrepo4/rest/fcr:backup"
3. a new Fedora server with MySQL, verify table ispn is created
4. restore: curl -X POST --data-binary "/home/ubuntu/1455291318495-0" "http://localhost:8080/fcrepo4/rest/fcr:restore"
5. Verify containers and binary file.
