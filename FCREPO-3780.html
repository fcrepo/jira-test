Description

I have pushed new object in Fedora with RDF properties:

 [^demo.rdf]

Now the fcrepo-camel-toolbox is triggered, filling Fuseki and there are all triplets from Fedora, so I can get dabar:oib over blank node like this:

SELECT * WHERE { <http://localhost:8080/fcrepo/rest/karaka3:892> dabar:author[dabar:oib ?i]  }

or

SELECT * WHERE { <http://localhost:8080/fcrepo/rest/karaka3:892> dabar:author/dabar:oib ?i  }

but the problem is in LDPath and Marmotta, Solr. I added custom paths in .ldpath custom template like this:

@prefix dabar : <http://dabar.srce.hr/standards/schema/1.0#>

title_ss = dabar:title :: xsd:string ;
author_ss = dabar:author/fn:concat(dabar:givenName," ",dabar:familyName) :: xsd:string ;
oib_ss = dabar:author/dabar:oib :: xsd:string ;

and this is indexed part of document in Solr:

{
...
  "title_ss":["title",
    "naslov"],
  "author_ss":[" "],
...
}

as you can see, direct links (titles) are indexed, but values over blank nodes aren't (family name, given name and oib).

if I add .ldpath custom path like this:

author_ss = dabar:author :: xsd:string ;

in Solr I get those blank nodes:

...
"title_ss":["title",
  "naslov"],
"author_ss":["genid-b0ea664530f8427497f148bef9aa9be2-b0",
  "genid-b0ea664530f8427497f148bef9aa9be2-b1"],
...

So my question is is it possible to get values over blank nodes with LDPath and Marmotta in fcrepo-camel-toolbox?

I've checked documentation on http://marmotta.apache.org/ldpath/language.html but there isn't any specific mention of blank nodes.
But that example for concating givenName and familyName is mentioned in documentation so i guess there is support for something like this?
