FCREPO-2359 User credentials don't work for verification tool

Description

When using the user credentials feature of the verification tool, some, but not all the requests to fedora are passing the credentials correctly. This leads to a 401 access denied failure.

The offending request appears to be in line 206 (rdflib.parse). This needs to be handled with the requests module instead in order to pass the credentials along.
