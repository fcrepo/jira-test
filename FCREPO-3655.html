Description

If you make multiple changes or create multiple versions within a second you should only get the last one for each second.

This works for RDF serializations.

> curl -ufedoraAdmin:fedoraAdmin http://localhost:8080/rest/test_version/bb4351ba-1293-4082-8a1e-aeb010be2aac/fcr:versions
 
@prefix memento: <http://mementoweb.org/ns#> .
@prefix rdf:   <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix fedora: <http://fedora.info/definitions/v4/repository#> .
@prefix ldp:   <http://www.w3.org/ns/ldp#> .
<http://localhost:8080/rest/test_version/bb4351ba-1293-4082-8a1e-aeb010be2aac/fcr:versions>
        ldp:contains           <http://localhost:8080/rest/test_version/bb4351ba-1293-4082-8a1e-aeb010be2aac/fcr:versions/20210225134305> ;
        memento:original       <http://localhost:8080/rest/test_version/bb4351ba-1293-4082-8a1e-aeb010be2aac> ;
        fedora:created         "2021-02-25T13:43:05.215950Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:lastModified    "2021-02-25T13:43:05.215950Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:createdBy       "fedoraAdmin" ;
        fedora:lastModifiedBy  "fedoraAdmin" ;
        rdf:type               ldp:Resource ;
        rdf:type               ldp:Container ;
        rdf:type               ldp:RDFSource .

But not for application/link-format
