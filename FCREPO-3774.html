Description

Note: this problem is occurring when the resources are visible without credentials to camel toolbox. Also it would be good to verify that proxy handling works as expected.

Steps to reproduce.

1. Fire up fcrepo, solr, and camel toolbox

2. create an external resource
```
curl -i -H"Link: <https://wiki.lyrasis.org/download/attachments/4980737/atl.site.logo>; rel=
"http://fedora.info/definitions/fcrepo#ExternalContent\\"; handling=\\"redirect
"; type=\\"text/plain
"" -XPUT -ufedoraAdmin:fedoraAdmin http://localhost:8080/fcrepo/rest/redirect_test
```
