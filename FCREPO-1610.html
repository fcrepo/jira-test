Description

There is a certain amount of repeated XML in Maven configurations for projects inheriting from org.fcrepo:fcrepo. These projects include:

⁃ fcrepo-build-tools
⁃ fcrepo4
⁃ fcrepo-message-consumer
⁃ fcrepo-module-auth-rbacl
⁃ fcrepo-module-auth-xacml
⁃ fcrepo-camel
⁃ ontology
⁃ fcrepo4-client
⁃ fcrepo-audit
⁃ fcrepo-camel-toolbox
⁃ fcrepo-webapp-plus
⁃ fcrepo4-release-tests
⁃ fcrepo4-oaiprovider
⁃ fcrepo4-swordserver
⁃ migration-utils

This ticket is to find all such redundancies, and move that config up into the pom in org.fcrepo:fcrepo.
