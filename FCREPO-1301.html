Description

In working towards a data migration from 2 and 3-series Fedora, developing a basic tool or framework to process for FOXML may help centralize the various efforts and provide a baseline for discussion.

This ticket is just to create a first draft of a tool that:
1. Processes FOXML1.1
2. Translates (or at least has hooks for translating) every bit o data into Fedora 4

This tool may eventually end up as a very configurable script, the core of a robust interactive migration tool or an experiment to help flush out major considerations.
