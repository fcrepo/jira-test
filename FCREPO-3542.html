FCREPO-3542 Make metrics configurable

TypeImprovement

Description

The metrics are currently configured so that they produce 1-minute metrics. This may be overkill. This should be configurable based on what the user wants.

Relevant code: https://github.com/fcrepo/fcrepo/pull/1756/files#diff-1bb0e31bcc42ee385f7808be46f185ac7fd4003fbe7c5c6418d2b4369f31f34eR58

The step interval and the Prometheus pull interval should be the same or similar. I believe that sub 1-minute intervals are necessary to produce 1-minute metrics.

Likely, we'll want to change the configuration so that it uses the default interval, which I think is 1 minute and results in 5-minute metrics, by default, and allow users to change the frequency as they see fit.
