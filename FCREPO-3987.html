FCREPO-3987 Make FOXML checksum validation optional in migration-utils

TypeNew Feature
StatusReceived
PriorityHigh
ReporterDan Field
Created2025-02-04 14:46 UTC
Updated2025-02-27 16:45 UTC
Componentsmigration-utils
Fix versionsfcrepo-migration-utils 7.0.0

Description

Currently migration-utils has an option to turn off checksum validation between FOXML and OCFL during the mapping process, however some users have experienced invalid checksums stored within their FOXML for Datastreams and these Datastreams are not currently migratable as the migration fails.

Either we could enhance the function of the existing flag to also ignore FOXML checksums or we could add an additional flag to only disable this single validation step.
