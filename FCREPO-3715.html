Description

When comparing Object metadata, the validator currently looks at all data as though they are Strings. For DateTime objects, this ends up breaking if there are differences in formatting between the Fedora 3 and Fedora 6 repositories even though the DateTimes are equal.

e.g. 

HEAD binary creation dates do no match: sourceValue=2019-07-08T18:49:12.000Z, targetValue=2019-07-08T18:49:12Z
