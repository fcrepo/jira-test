Description

Marmotta offers a Linked Data -aware backend to support LDPath that is very much more powerful than the simpler Jena Model-based backend fcrepo-transform now uses, without being significantly more difficult to deploy or use. We should switch to using it.

Unknown, 2016-08-05 14:06 UTC

Andrew Woods The interaction model is almost identical to the existing fcr:transform feature. For a resource at, say, http://localhost:8080/fcrepo/rest/resource/path, you would interact with the service like so:

curl -XGET http://localhost:4444/ldpath/resource/path?ldpath=http://example.org/myldpath

OR

curl -XPOST http://localhost:4444/ldpath/resource/path -d @myldpath.txt -H"Content-Type: text/plain"

OR (for the default transform)

curl -XGET http://localhost:4444/ldpath/resource/path

There is no facility for storing ldpath programs such as there is with fcr-transform, but if that is truly desired it would be easy to add.
