Description

As reported by Arnaud Koster from ARHS:
-----------------------------------------------------
BTW: It seems that Fedora 3.7.1 is not compatible with Oracle database. In fact, we faced a problem during the startup:
Fedora tries to execute this script:
CREATE TABLE fcrepoRebuildStatus (
rebuildDate NUMBER(20,0) NOT NULL,
complete boolean NOT NULL,
UNIQUE (rebuildDate)
);
