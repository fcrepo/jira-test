Description

Bug from https://fedora-repository.atlassian.net/browse/FCREPO-3866

Archive groups allow users to create, delete, and purge single resources and recreate them after. When querying fcr:versions on one of these resources, the server returns a http 500. The cause of this is a NPE from when Fedora is using the memento datetime as tombstones are not mementos. This should be what is happening when using the Accept-Datetime header as well to query the resource.
