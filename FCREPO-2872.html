Description

The message emitted by Fedora when a Memento is created (via POST to the LDPCv) contains invalid values for 'id' and 'isPartOf'

 

 

{
   "@context": [
       "https://www.w3.org/ns/activitystreams",
       {
           "dcterms": "http://purl.org/dc/terms/",
           "id": "@id",
           "isPartOf":
{                "@id": "dcterms:isPartOf",                "@type": "@id"            }
,
           "prov": "http://www.w3.org/ns/prov#",
           "type": "@type"
       }
   ],
   "actor": [
      
{            "id": "info:fedora/local-user#fedoraAdmin",            "type": [                "Person"            ]        }
   ],
   "id": "urn:uuid:e75677ed-ee04-47e8-8b9c-77adc6c3a1f2",
   "name": "update resource, create resource",
   "object":
{
        "id": "null/versioning/13/fedora:timemap/20180920191555",
        "isPartOf": null,
        "type": [            "http://www.w3.org/ns/ldp#Container",            "http://fedora.info/definitions/v4/repository#Resource",            "http://www.w3.org/ns/ldp#RDFSource",            "http://mementoweb.org/ns#Memento",            "http://www.w3.org/ns/ldp#BasicContainer",            "http://www.w3.org/ns/prov#Entity"        ]    }
,
   "published": "2018-09-20T19:15:55.131Z",
   "type": [
       "Update",
       "Create"
   ]
}
 

 

Also, putting aside the ‘Null’ values, if one tries to retrieve the resource at the resource path in the 'id' field (after replacing the 'null' bit), the request fails with a 404, presumably because the 'fedora:timemap' bit is erroneous.
