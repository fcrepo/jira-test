Description

Setup:

  • Download dataset: https://github.com/fcrepo4-labs/fcrepo-sample-dataset/blob/master/lubm/LUBM.tar.gz
  • Start up an empty F4
  • Upload the sample dataset:
    > curl -i -XPOST --data-binary /path/to/LUBMbackup localhost:8080/rest/fcr:restore
  • Export the repository:
    > java -jar fcrepo-import-export-driver-0.0.1-SNAPSHOT.jar -b /tmp/bin -m export -d /tmp/rdf -r http://localhost:8080/rest/
  • Start up an empty F4
  • Import the exported content:
    > java -jar fcrepo-import-export-driver-0.0.1-SNAPSHOT.jar -b /tmp/bin -m import -d /tmp/rdf -r http://localhost:8080/rest/ | tee import.out

! Notice output log for "fedora:lastModified" constraints:
WARN 10:47:46.284 (Importer) Error while importing /tmp/awoods/test/x/rdf/rest/Department14.University0.edu/AssociateProfessor6.ttl (500): javax.jcr.nodetype.ConstraintViolationException: Cannot find a definition for the property named 'fedora:lastModified' on the node at '/Department14.University0.edu/AssociateProfessor6' with primary type 'nt:folder' and mixin types: [ldp:Container,ldp:RDFSource,fedora:Pairtree]

Comments (4)

Esmé Cowles, 2016-09-09 17:32 UTC

I think the `fedora:Pairtree` part is the important part here: my theory is that creating `/Department14.University0.edu/AssociateProfessor6/Publication1` creates a PairTree node at `/Department14.University0.edu/AssociateProfessor6` which then causes trouble when we try to update that node's properties.

Maybe sorting the files on disk to make sure the files at a given level are processed before the directories would fix this.

Andrew Woods, 2016-09-09 17:42 UTC

Esmé Cowles, seems related to Michael Durbin's comments on: https://jira.duraspace.org/browse/FCREPO-2195

Michael Durbin, 2016-09-09 18:04 UTC

Indeed... one in the same.

The trouble is, since we can export from any point, we don't know if non-exported parent (ancestor) nodes are real nodes or not. Perhaps we should force the exporter to include the RDF for any ancestor nodes of exported nodes and then import all the nodes in a breadth-first fashion (or at least guarantee to import parents before children).
