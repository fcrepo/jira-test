Description

The document describing WebAC discusses the use of acl:agentClass for making access decisions based on a graph of user/group agents. This ticket will track the implementation of support for this where these agentClass graphs are defined as in-domain resources in fedora. The code should be written in such a way that it would be easy to access remote RDF graphs, should that use case arise.
