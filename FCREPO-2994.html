FCREPO-2994 Add Support for X-If-State-Token on PATCH

Description

An HTTP PATCH request that includes an X-If-State-Token header must be rejected with a 412 (Precondition Failed) response if the implementation supports state tokens, but the client-supplied value does not match the resource's current state token.

  cf: https://fcrepo.github.io/fcrepo-specification/#state-tokens
