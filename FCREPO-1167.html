A. Soroka, 2012-11-16 00:57 UTC

Basically, it's the RDF notion of a datatype with which we're concerned:

http://www.w3.org/TR/rdf-primer/#typedliterals

Remember, the relationships in a Fedora repository are RDF. Fedora has no special notion of its own, but it should make available the XML Schema built-in datatypes for convenient use, as per:

http://www.w3.org/TR/swbp-xsch-datatypes/

You'll want to look at:

http://www.w3.org/TR/xmlschema-2/#built-in-datatypes

for a discussion of the XSD built-in types and what their URIs are. I think that Fedora by default allows the use of the prefix xs: for convenience, so you might try xs:string, but you might have to use the full unabbreviated URI http://www.w3.org/2001/XMLSchema#string.

Let me know if that helps. You'll want to take this to the users' email list so anyone else having this problem can benefit from what you learn, because I'm going to close this issue (since it's not actually a problem with Fedora).
