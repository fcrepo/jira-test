FCREPO-4037 Missing User-Agent header causes NullPointerException on PUTs

Environment

Ubuntu Linux

Description

If you send a PUT to Fedora 6 and you don’t set the User-Agent header, it will generate a NullPointerException when trying to emit events (even if fcrepo.jms.enabled=false).

The actual PUT succeeds which is good, but it fills your logs full of noise at the very least.

Of course, you can fix this by just making sure your ingestion code is sending a User-Agent header, but I figure this is still a bug.

(Note: If you’re using cURL via PHP, it defaults to not sending any User-Agent header. I think most libraries will usually set some kind of a default, which is why I hadn’t encountered this with ingestion via other languages like Java and Perl.)
