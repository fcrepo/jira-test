Description

Documentation [1] states wrong configuration path for activemq.xml file.

Instead of $FEDORA_HOME/server/config an customized broker configuration file should go to $FEDORA_HOME/server/config/spring to be picked up at Spring context start up.

[1] https://wiki.duraspace.org/display/FEDORA37/Messaging
