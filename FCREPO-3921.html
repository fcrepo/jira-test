Description

One-click needs to be launched via running it with the command java -jar path/to/fcrepo-webapp-6.5.0-RC-1-jetty-console.jar but not by "one-clicking" the .jar file, which runs but continues to have the "503 Service Unavailable" error.

Josh’s assumption is that the issue with that is that the java launcher that is triggered by clicking the .jar file is still pointing to an older Java.
