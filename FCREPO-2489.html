Joshua Allan Westgard, 2017-05-25 15:23 UTC

I suspect this relates to the changes in https://github.com/fcrepo4-labs/fcrepo-import-export-verify/commit/bfd6fa1d809002236850c402be6ac7317ea2397f

The refactored fedoraResource class in this commit assigns a 'type' property, but not 'ldp_type'.

Joshua Allan Westgard, 2017-05-26 16:09 UTC

This commit partially fixes this issue, but not completely: https://github.com/fcrepo4-labs/fcrepo-import-export-verify/pull/38/commits/8d84e61fc9253b6c71532da54f52c00186b9ba48

To fix this properly I think we need two things:

  1. we need to document the contract of import-export and precisely what its config options represent for the various scenarios
  2. we probably need to refactor the two main resource classes (fedoraResource and localResource) so that all possible errors are handled appropriately
