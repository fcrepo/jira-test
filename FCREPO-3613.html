FCREPO-3613 F5 -> F6 Migration does not properly handle spaces in RDF

TypeBug
StatusClosed
ResolutionFixed
PriorityCritical
ReporterPeter Winckles
AssigneeJared Whiklo
Created2021-01-27 14:01 UTC
Updated2021-03-04 16:44 UTC
Resolved2021-02-07 21:31 UTC
Componentsf4-migration
Affects versionsFedora 6.0.0
Fix versionsFedora 6.0.0
ParentFCREPO-3142 Modeshape out, OCFL In.

Description

Daniel Lamb reported that he cannot access resources that contain spaces after migrating to F6. This is because the migration code is missing the logic that was recently added to F6 to url encode internal ids when they are inserted into RDF.

Additionally, we should verify that spaces are not a problem for F3 migrations as well.
