if (terms.indexOf("'") != -1)

{ throw new QueryParseException("Query cannot contain the ' character."); }

which suggests that using single quotes is a no-no.

frank asseg, 2012-08-24 18:06 UTC

As discussed yesterday in the committer meeting this should not be a problem since fedora switched to using PreparedStatements.
PreparedStatement is used in FieldSearchResultSQLImpl.java but single quotes were escaped with a backslash instead of a second single quote, which lead to a invalid query.
source: http://www.postgresql.org/docs/current/static/sql-syntax-lexical.html#SQL-SYNTAX-CONSTANTS
Note: although link goes to postgresql doc using a second single quote to escape single quotes is ANSI sql.
