Description

The following functionality used to be supported:
$ mvn clean install -pl fcrepo-webapp -Pone-click
$ java -jar fcrepo-webapp/target/fcrepo-webapp-4.8.0-SNAPSHOT-jetty-console.jar --headless

Likely as a result of the following commit, this functionality is no longer supported:
https://github.com/fcrepo4/fcrepo4/commit/b00873e7d47ecf9f266e3628fcb9270e35edcc9c
(https://jira.duraspace.org/browse/FCREPO-2393)

It is now required for the user to provide a "-Dfcrepo.modeshape.configuration=..." configuration.

This task is to re-enable the default "classpath:/config/file-simple/repository.json" configuration for the one-click-run.
