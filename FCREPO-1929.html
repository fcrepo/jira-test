FCREPO-1929 A GET request with Prefer=minimal should return all user-persisted information of relevance

Affects versionsFedora 4.5.0

Description

Currently, a GET request to an RDF resource with Prefer=minimal returns only triples with the subject that is the exact URI of the resource. Instead, it is more logical and useful to return those triples, and all triples that have subjects that are hash-URIs on the URI of the resource or blank nodes that were created by action against the resource. In short, the user should get back all user-managed triples (as the complement of server-managed triples).
