Is related toFCREPO-2098 If-Match headers not properly evaluated for LDP-RSs
Is related toFCREPO-2122 LDP If-Match guidance is incompatible with the HTTP spec

Description

HTTP spec says that strong eTags should be based on the byte-for-byte serialization of the response that's sent, and LDP wants to use it for checking if the state has changed. We currently use strong e-tags, but not correctly (it doesn't change with different serializations) - we should just be able to prepend "W/".
