Jared Whiklo, 2021-01-13 22:04 UTC

That is the whole thing with "relaxed" mode. The server normally won't let you set a server managed triple (like createdBy or createdTime). But when the server is in "relaxed" mode it should allow that.

It is possible the test is not actually getting the server into "relaxed" mode at all.

Normally you'd just add -Dfcrepo.properties.management=relaxed to the JAVA_OPTS. You may need to ensure that is happening.
