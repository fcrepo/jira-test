Description

Chris Wilper, 2009-03-01 17:52 UTC

Fixed. Solution was to close when it is known that there are no more results (when resultCount for the current page is less than maxResultsPerPage). Patch was not applied because while it works in most cases, it would prematurely close in cases where maxResultsPerPage is given as 1 and more than one result is available.

FieldSearchSQLImplIntegrationTest now checks for this; it will fail if the pool is exhausted after several (more than poolsize) one-result searches are performed back-to-back.
