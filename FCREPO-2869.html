Description

Taking the exact "Memento-datetime" and using that as the "Accept-datetime" value results in a 302 response to an earlier Memento.

 

Note the URI in the first request and the Memento-datetime value.  When using that value in the second request (to the Timegate), note that the Location URI is not the same as the URI in the first request, but to an earlier version.  The third request demonstrates that incrementing the Accept-datetime value by one second will result in the expected URI.
