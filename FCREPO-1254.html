FCREPO-1254 Make fcrepo-camel easier to deploy to OSGi containers

Fix versionsFedora 4.1.0

Environment

Karaf 3.0 and other OSGi containers

Description

fcrepo-camel uses jena classes for handling RDF in the org.fcrepo.camel.processor classes. Those should be swapped out for the corresponding clerezza libraries (http://clerezza.apache.org/), which wrap jena-core in an OSGi-safe way. It is possible to deploy fcrepo-camel without the change, but it would be significantly easier if its dependency chain was fully OSGi compliant – which would make the pom.xml configuration much cleaner.
