FCREPO-3005 GET and PUT on resource/fcr:metadata/fcr:acl and resource/fcr:versions/fcr:acl return 400

TypeBug
StatusOpen
PriorityMajor
ReporterDanny Bernstein
AssigneeDanny Bernstein
Created2019-06-06 19:01 UTC
Updated2024-01-11 18:38 UTC
Componentsf4-core, webac
Affects versionsFedora 5.0.2

Description

GET on test/fcr:metadata/fcr:acl on a binary resource fails with a 400.  So does test/fcr:versions/fcr:acl return 400.  

These endpoints should return 404 since they do not exist. 

 

 

#To reproduce: 
#Create a binary resource:
curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/test -X PUT  -H "Content-Type:text/plain" -d "test"
#Get the metadata: 
curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/test/fcr:metadata -i
#See the "acl" link? No try to get it and verify the 400
curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/test/fcr:metadata/fcr:acl -i  
#Same with versions endpoint:
curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/test/fcr:versions/fcr:acl -i      
curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/test/fcr:metadata/fcr:versions/fcr:acl -i   
#Same is true for container/fcr:versions/fcr:acl
#Same is true for PUTs on the above acl resources.
