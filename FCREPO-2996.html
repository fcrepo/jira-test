Description

Currently you can delete just the description from a binary. But once it is gone you can't recreate it.

See https://gist.github.com/whikloj/22747a594194da6072c8c1fd745760ea for demonstration.

Questions:

Should you be able to delete the description?

If yes, then how do we re-create it?

If no, then what is the response?

Andrew Woods, 2019-05-03 22:02 UTC

I believe the previous behavior was that if you deleted an Non-RDF-Description, the Binary was also deleted. Likewise, if you deleted a Binary, the Non-RDF-Description was also deleted.
I would suggest we disallow the deletion of Non-RDF-Descriptions, since they are auto-created, and are in a sense "server-managed".
"405 Method Not Allowed" seems apprpriate.
