Description

ingestObject was supposedly deprecated since 2.2 (perhaps earlier, but I don't recall) in favor of ingest.

If it's going to be dropped, dropping it for 3.0b2 or final seems appropriate.

Also, the Management interface still defines adminPing, which doesn't exist in the API-M WSDL. This seems like another candidate for removal unless there's a reason for the inconsistency.
