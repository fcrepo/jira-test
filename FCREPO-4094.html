FCREPO-4094 Add support for XSLT 3.0 to fcrepo-camel-toolbox solr indexing

Description

camel toolbox only ships with support for XSLT 1.0 which is ancient by modern standards. Requests have come in for more modern support for 2 and 3.

The Solr indexer applies the transform via Camel's plain XSLT component — SolrRouter.java:170 does {{toD("xslt:$

{header.CamelIndexingTransformation}

")}}, and the project depends on camel-xslt (pom.xml:161).

That component delegates to the JDK's built-in JAXP TransformerFactory (the Xalan-derived XSLTC processor bundled with the JVM), which implements only XSLT 1.0 / XPath 1.0. Saxon is nowhere on the classpath, so there's no XSLT 2.0/3.0 support.

If you wanted 2.0/3.0 support, the standard route would be swapping in camel-xslt-saxon and using xslt-saxon: URIs — Saxon-HE would give you XSLT 3.0. That's worth keeping in mind for the Camel 4 upgrade too, since the component split (camel-xslt vs camel-xslt-saxon) carries over there unchanged.
