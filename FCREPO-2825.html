Description

At present, there is no way for a client to read the default repository ACL.  While there is a default rot ACL defined in the code, it does not seem to be exposed to clients via http.  This default ACL should be accessible at the resource found by following the acl link relation of the repository root resource.

https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-auth-webac/src/main/resources/root-authorization.ttl
