Description

When I PUT this RDF:

"\n<> a <http://pcdm.org/models#Object>,\n     <http://projecthydra.org/works/models#Work>;\n   <http://purl.org/dc/terms/title> \"Presidential Address: Rethinking the Comparative and the International\";\n   <http://id.loc.gov/vocabulary/relators/dpt> \"batchuser@example.com\";\n   <http://purl.org/dc/elements/1.1/contributor> \"Carnoy, Martin\",\n     \"Comparative Education Review\";\n   <http://purl.org/dc/elements/1.1/description> \"\"\"\"It is both a great honor and a great responsibility to address the Comparative and International Education Society (CIES) on the occasion of its fiftieth anniversary. A great honor, of course, because of the symbolism associated with such an event. The great responsibility comes from the richness and depth of past presidential addresses and the weight of living up to their standards. The theme of our meeting this year in Hawaii is \"\"Rethinking the Comparative.\"\"  It might well have been \"\"Rethinking the Comparative and the International,\"\"  for both elements of our name bear reexamination in a world and in national societies that are changing rapidly and profoundly. We need to ask ourselves, after 50 years, what it is that makes comparative and international education unique and what the CIES, as an intellectual community, contributes to understanding how the world works and to human progress.\r \"\"\"\";\n   <http://purl.org/dc/elements/1.1/subject> \"-- comparative education\",\n     \"-- international education\";\n   <http://purl.org/dc/terms/created> \"2006\";\n   <http://purl.org/dc/terms/dateSubmitted> \"2016-05-23T21:41:30.761946+00:00\"^^<http://www.w3.org/2001/XMLSchema#dateTime>;\n   <http://purl.org/dc/terms/modified> \"2016-05-23T21:41:30.766416+00:00\"^^<http://www.w3.org/2001/XMLSchema#dateTime>;\n   <http://purl.org/dc/terms/type> \"text\";\n   <http://www.w3.org/ns/auth/acl#accessControl> <http://127.0.0.1:8986/rest/test/16/62/08/58/16620858-37a1-4da0-ae04-c906e0db4871>;\n   <info:fedora/fedora-system:def/model#hasModel> \"GenericWork\" .\n"

Fcrepo returns a 400: "RDF was not parsable: [line: 9, col: 1 ] Broken token (newline): ;"

The problem seems related to the \r in the description field. When I remove that it works.

Source data: https://purl.stanford.edu/wm346hj8366.xml The description field has a quote in it, thus the quadruple quote.

Danny Bernstein, 2016-09-26 19:05 UTC

Justin - forget it, I figured it out. So this is still a problem post recent Jena 3.1 updates. Incidentally, having a \n character in the value field also triggers the problem. The issue can be reproduced by issuing the following commands against rev ba835 (Sept 23):

1. create a new node.
2. create a sparql update file with a carriage return and/or new line in the description field :

PREFIX dc: <http://purl.org/dc/elements/1.1/>
INSERT

{ <> dc:description "Important Academic Research Paper" . }

3. execute this:

curl -v -X PATCH -H "Content-Type: application/sparql-update" --data-binary "@file-name-herel" http://localhost:8080/rest/path/to/node

NB: The jira is not displaying the line break after the word "Research".

Danny Bernstein, 2016-09-26 19:34 UTC

Actually this appears to be fixed.

By changing the sparql file to:
PREFIX dc: <http://purl.org/dc/elements/1.1/>
INSERT

{ <> dc:description "Important Academic \r Research Paper" . }

The PATCH request returns a 204.

When retrieving the node's metadata, the value for description is not escaped, I believe as we would expect.

Perhaps not a bug? Either it was fixed in the Jena update or the request was not properly escaped.
