Description

The framework for handling multiple resources within a transaction is in place but has not been extensively tested.  There are integration tests that should be added that confirm the following features work: 

  1. Update multiple archival groups within a single transaction.  Confirm that the changes are visible within the transaction but not without. 
  2. Confirm commit after multiple updates (in separate requests) works.
  3. Confirm that rollback returns all the resources and the related indices to their prior state.
  4. Create tickets for any bugs discovered.
