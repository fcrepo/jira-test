Description

At present, the modeshape internal types (primaryType, mixinType) are part of the (server managed) FedoraResourceImpl::getTriples response. These triples are then filtered out in the HTTP layer so they do not appear in client responses. These internal types are currently used by the HTTP layer to determine the correct Template to use. Once FCREPO-1934 Closed is resolved, this will no longer be necessary, and the triples should not be generated in the first place. This applies especially to org.fcrepo.kernel.modeshape.rdf.impl.RdfTypeContext and org.fcrepo.kernel.modeshape.FedoraResourceImpl::getTypes
