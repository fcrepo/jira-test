Description

fedora.server.management.ManagementModule does not implement the ManagementDelegate interface. Thus, specifying it as the management delegate causes an exception and aborts startup.

Also:
documentation example uses fedora.server.management.DefaultManagement as the management delegate. It seems to be obsolete for this purpose (as this class is now used directly by ManagementModule). Documentation should be updated.
