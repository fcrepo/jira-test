FCREPO-999 Ability to specify FeSL caching options in config instead of environment variable

Is related toFCREPO-1053 Remove PEP_NOCACHE environment variable configuration for disabling FeSL policy results caching

Description

FeSL's XACML caches policy evaluation results, so that policies are not re-evaluated for repeated access to the same resource etc.

This is currently configurable - the caching can be disabled by setting PEP_NOCACHE=true as an environment variable.

This should instead be an option in a config file, FeSL should not depend on environment variables.

Added to 3.6 (minor config change; existing config will still be recognised)

Stephen Bayliss, 2012-01-24 15:20 UTC

Config now via system property:
fedora.fesl.pep_nocache=true

This will override PEP_NOCACHE environment variable if it is set.

If the system property is not set, then the PEP_NOCACHE environment variable will still be used (ie existing installations will work as before).

The PEP_NOCACHE environment variable configuration should be removed in a post-3.6 release, FCREPO-1053 Closed raised for this
