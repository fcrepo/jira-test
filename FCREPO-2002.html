Description

This task is to use YourKit (or the like) to monitor Fedora's memory consumption and associated performance slowdown. It has been noted during York University scalability tests, that after loading ~2.5million resources, Fedora became effectively too slow for use.
https://wiki.duraspace.org/display/FF/York+University+Results+-+Test+4

However, after restarting Fedora's Tomcat, ingests were resumed at the initial response rates.
