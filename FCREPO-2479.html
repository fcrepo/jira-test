FCREPO-2479 Generated relationships from indirect containers not returned when retrieving versions

Description

When performing a GET request against a resource with generated relationships (pcdm:hasMember for example) resulting from an indirect container containing proxies to another resource, the relationships are returned.

However, if you create a version of that same resource and then retrieve the versioned copy, the generated relationships are not returned.

To replicate the issue, see the instructions in this repo:
https://github.com/bbpennel/fcrepo-indirect-version-test/
