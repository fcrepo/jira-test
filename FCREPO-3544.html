Ralf Claussnitzer, 2020-12-01 14:41 UTC

Seems to be a user error. I started the migration with: 

--source-type=legacy

instead of 

--source-type=akubra

against Fedora 3.8.1.
When using the Akubra source type everything is fine. Just some OCFL hash errors on objects with fixity problems.

Side note: I noticed a directory ".run" which is created in the project root when executing the migration in IntelliJ. This should probably be mentioned in the .gitignore file.
