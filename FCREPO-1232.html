Glen Robson, 2014-10-27 01:53 UTC

It appears the journal is written to after the change to Fedora has completed. This means if a critical follower is down then one request is lost before the primary is changed to read only. Steps to reproduce:

stop RMIJournal reciever on secondary.
ingest one object - this will succeed
ingest second object - this will fail with "org.fcrepo.server.errors.InvalidStateException: Server is in Read-Only mode, pursuant to a Journaling error."

Once you have got in this state you need to stop the primary copy the full journal from the primary to the secondary and remove the part journal on the secondary. As long as you have the LocalDirectoryTransport this is easy to do.
