Description

Currently when you a reference from a resource A to resource B. Resource B gets an Update event generated.

This is even though resource B has not actually been updated.

This ticket is to look through the current master branch and figure out how that event is generated and see if we could modify the output in some way.

Findings are as follows

So when you link two resources in Fedora, Modeshape does modify the targeted resource.

When I `POST`ed a new resource with the RDF

<> <http://example/link> </rest/aa5f43e1-1067-4fa2-8941-2cdaaa00c785> .

There are 3 resources modified, the Root node (as a new child is added), the newly created node, and the referenced Node.

the event that is emitted for the referenced node is

Property changed at /aa5f43e1-1067-4fa2-8941-2cdaaa00c785/jcr:lastModified by fedoraAdmin

As this event is caused by Modeshape the easiest solution is to remove events when they only affect lastModified.
