Description

From https://github.com/fcrepo/fcrepo/issues/2040

TL;DR

I have configured my session timeout for a long time and when long running client dies I don’t know the transaction ID to roll it back. When another user tries to edit it, I just see a 409 Conflict and I would like to see the transaction ID so I can roll it back.

This ticket is to:

  1. Ensure the transaction ID is included in messages in the log
  2. Add a configuration parameter to enable displaying the transaction ID to the end users, with a default of being disabled.
  3. If the new configuration parameter is enabled, add the transaction ID to the outgoing 409 response body.
