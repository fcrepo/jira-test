Description

When returning RDF to clients, the complete list of namespace prefixes known to the server is included. It would save a lot of lines in the response to only include the namespace prefixes that are being used.

Note:

This doesn't appear to be something jena provides. It may require some work to inspect the stream to compare what namespaces are present versus what namespaces are being provided. I believe that would happen in the two blocks here:
https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-http-commons/src/main/java/org/fcrepo/http/commons/responses/RdfStreamStreamingOutput.java#L126-L147
