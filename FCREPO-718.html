Description

Code for managing temp and uploaded files is somewhat distributed through the codebase, it would be better to have this in a single unit of code - a temp file management class (with an interface) to manage creating, reading and cleaning up temporary files.

Examples:

DefaultManagement - creates and reads uploaded files, including time-based expiry of these files
DatastreamManagedContent - creates and reads uploaded files through DefaultManagement (thus requires authorization for the API-M methods)
FOXMLDODeserializer creates temp files (for inline binary managed content) (and other Deserializers)
DefaultDOManager deletes temp files (managed inline binary content)
