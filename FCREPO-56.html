When running an itql query like so:

select $tpackage $relDate
from <#ri>
where $tpackage
<http://localhost:8880/NCCS/ontologies/relationships#isDistributedBy>
<info:fedora/test:target1>
and $tpackage
<http://localhost:8880/NCCS/ontologies/relationships#hasReleaseDate> $relDate
and $relDate <http://tucana.org/tucana#gt> '12' in <#xsd>

... it only works if the datatype of #hasReleaseDate is defined as xsd:double
(not int) in RELS-EXT. This may be a bug in the version of Kowari we're
currently using (1.0.5). In the mean time, if people need to do numeric
comparisons, they can use xsd:double rather than int.
