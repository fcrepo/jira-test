FCREPO-4062 Upgrade-util allow OCFL commit message to be overridden

TypeImprovement
StatusReceived

Description

Currently the upgrade-util adds "message": "Generated by Fedora 4/5 to Fedora 6 migration" to every inventory file during a fedora 6/7 upgrade. The message may be confusing for users migrating to fedora 7. We should add an extra flag to the utility to allow a custom message be passed in.
