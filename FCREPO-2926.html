Description

This task is to add properties in the HTML UI for individual Mementos.

For example, when viewing an individual Memento in the HTML UI (e.g. resource/fcr:versions/20181031170755), the following properties are currently empty, but should have values:

  • "Created at"
  • and "by"
  • "Last Modified at"
  • and "by"
  • "Children" (currently always shows "0", despite the number of actual children... or maybe remove this element?)

Also, in the "Properties" panel, no values are shown. Instead, the property values are seen under "Other Resources"... which seems incorrect.

To reproduce in the HTML UI:

  • create a resource
  • create a child of the initial resource
  • create a version of the initial resource
  • view the individual mementos of the initial resource

Observe the missing properties as detailed above.
