Description

The JMS module should not emit events related to creating audit nodes for internal audit events. Add a way to suppress these events, ideally in a way that is configurable and not tightly coupled to the audit implementation.

Former user, 2015-04-15 14:56 UTC

I'm working on an EventFilter that will allow users to specify a list of mixins to suppress events about. This should be a pretty easy extension of the existing DefaultFilter, and allow for a variety of use cases where you might want to disable certain kinds of events.

Former user, 2015-04-15 17:33 UTC

https://github.com/fcrepo4/fcrepo4/pull/769

This adds a new EventFilter implementation that suppresses events on nodes with any of a given set of mixins. To use this in a running repository, you'd need to configure it in https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-webapp/src/main/resources/spring/eventing.xml, replacing the existing DefaultFilter bean with something like:

<bean name="fedoraEventFilter" class="org.fcrepo.kernel.impl.observer.SuppressByMixinFilter"/>
<constructor-arg>
<value>audit:ExternalEvent</value>
<value>audit:InternalEvent</value>
</constructor-arg>
</bean>

I assume that should go in fcrepo-webapp-plus somewhere.
