Description

This task is to add a reference in Fedora vocabularies that indicates the URLs of:

  • current version
  • previous version
  • supported Fedora version

The vocabularies to be updated are:

  • http://fedora.info/definitions/v4/repository
  • http://fedora.info/definitions/v4/indexing
  • http://fedora.info/definitions/v4/oai-pmh

Former user, 2015-02-06 17:34 UTC

I think the best properties for this are owl:versionInfo to record the current version and owl:priorVersion to link to the previous version, e.g.:

<owl:priorVersion rdf:resource="http://fedora.info/definitions/v4/2014/11/27/repository#"/>
<owl:versionInfo>v4/2015/02/04</owl:versionInfo>

There's more info at http://www.w3.org/TR/2004/REC-owl-guide-20040210/#OntologyHeaders and http://www.w3.org/TR/owl-ref/#Ontology-def
