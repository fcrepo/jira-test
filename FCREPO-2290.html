Description

Starting with camel 2.18, there is a new module called camel-test-karaf, which contains the CamelKarafTestSupport class: https://github.com/apache/camel/blob/master/components/camel-test-karaf/src/main/java/org/apache/camel/test/karaf/CamelKarafTestSupport.java

Using this, we should be able to dramatically simplify the current integration tests with pax-exam.
