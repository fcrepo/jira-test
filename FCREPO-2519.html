Description

An IndirectContainer can be created using a server-managed predicate as the ldp:hasMemberRelation value. This will generate potentially invalid triples.

For example, this gist demonstrates generating bogus fedora:lastModified triples with an IndirectContainer:

https://gist.github.com/escowles/29ab8f71ce39072ca12deb2ec11c4bd2
