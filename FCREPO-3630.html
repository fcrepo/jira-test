FCREPO-3630 Allow versioning behavior to be specified per object

TypeImprovement
StatusOpen
PriorityHigh
ReporterBen Pennell
Created2021-02-12 17:30 UTC
Updated2021-12-15 19:55 UTC

Description

At present, autoversioning can only be specified as a repository-wide option. We should allow clients to override this default setting on a per object basis, specifying that the object should use autoversioning or use on-demand versioning.

For AGs, the setting would only be allowed on the AG itself, not for the resources it contains. Any atomic resource should be able to have this option set. If reasonable, it should be possible change this setting after the object is created.

It would be appropriate to keep this option as a header for the resource.

This is similar to how versioning could be enabled per datastream in Fedora 3.
