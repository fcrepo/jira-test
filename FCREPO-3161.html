FCREPO-3161 REST API should translate internal fedora Identifiers to external http resources by default

Description

Currently the REST API returns internal fedora identifiers in the RDF response bodies rather than HTTP URIs. 

The task here is to ensure that the identifiers are translated to external identifiers by default.  The user should be able to optionally expose the internal idenfiers in the RDF output if desired.
