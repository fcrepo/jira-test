FCREPO-2805 AWS Based Checksums

TypeNew Feature
StatusClosed

Resolved2019-04-26 17:24 UTC
Fix versionsFedora 5.0.0

Description

Current Fedora out of the box comes with SHA1 checksums, which is the only one that AWS s3 won't do (you can query S3 directly for MD5 or SHA256 ( https://aws.amazon.com/premiumsupport/knowledge-center/data-integrity-s3/ ).  It would be nice with the fixity endpoint in 5 if that when working with external files, Fedora was smart enough to automatically use something other than SHA1 and run checksums on external files (on the case of non S3 file systems, retrieving the file and calculating a checksum and in the case of S3 just hitting S3 to get the sum).
