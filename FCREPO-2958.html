Jared Whiklo, 2019-09-12 13:33 UTC

So here are the things I discovered while working this.

  1. You need to set the maven-compiler-plugin target argument as a property, so you can change it from 1.8 to 11 when you switch your compiler.
  2. You need to make sure that mvn is using the correct java home (more of a problem in a multi-java setup than in Travis)
  3. You need to disable the javadoc run for the non-1.8 execution as it wants to link to the 1.8 api docs and you are using the 11 api docs. There might be a way around this but I couldn't find it.
