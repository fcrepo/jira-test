Description

The pom specifies a fcrepo.version which a release candidate (5.1.0-RC-2) rather than the release itself (seen in github as 5.1.0). This is preventing the import-export tool from running tests/building as the download-maven-plugin attempts to fetch the fcrepo-webapp on a resource which no longer exists.
