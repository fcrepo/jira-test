FCREPO-2932 406 returned when Accept-Datetime header is present when GETting Memento

Description

According the memento spec, the Accept-Datetime may be present when performing a GET on a memento: 

The inclusion of the "Accept-Datetime" header in this request is not needed but will typically occur as the user agent is in datetime negotiation mode.

Fedora is returning a 406.  Instead the Accept-Datetime header should be ignored and the memento resource should be returned with a 200.
