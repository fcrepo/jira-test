Description

System property fedora.fesl.pep_nocache added in 3.6; as Fedora should have no dependencies on environment variables this should be removed in a future release.

This is a placeholder issue to remove the (deprecated) use of environment variable PEP_NOCACHE=true in a future release.

See ContextHandlerImpl#init() for where this is currently used.
