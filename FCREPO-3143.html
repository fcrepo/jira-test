Description

Fix migration-utils command line argument processing to 1) make the fixed argument values lowercase; and 2) update the help output to show the lowercase argument values.

 

Example:  change the source-type list of values from AKUBRA|LEGACY|EXPORT to akubra|legacy|export;  change layout values FLAT|PAIRTREE|TRUNCATED to flat|pairtree|truncated.
