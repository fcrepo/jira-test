FCREPO-2498 PUT-to-update requests should include If-Unmodified-Since header

Description

When we create placeholder resources, and then later update them with PUT, we should include the If-Unmodified-Since header to prevent accidentally overwriting any other changes that might happen in the meantime.

Note, as discussed in FCREPO-2478 Closed , the LDP spec recommends using the If-Match header. However, the non-fixed nature of RDF makes it impractical to use strong ETags (which are required by If-Match), so If-Unmodified-Since is the alternative.
