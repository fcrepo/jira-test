Description

The GitHub actions workflow “Build Main Branch” seems to build Docker images in the deploy job, but never pushes them to Docker Hub.

The last execution of the workflow from 2026-04-08 (https://github.com/fcrepo/fcrepo/actions/runs/24147566494/job/70470612272) shows the following warning in the step “Deploy Docker Image”:

WARNING: No output specified with docker-container driver. Build result will only remain in the build cache. To push result image into registry use --push or to load image into docker use --load

Analysis: The script build-and-push-to-dockerhub.sh from fcrepo-exts/fcrepo-docker used to build the Docker image, only pushes the Image to Docker Hub, when the command line flag --push as been specified. This flag is currently missing in the workflow.
