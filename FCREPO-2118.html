FCREPO-2118 Ambiguous fcr:versions element in version containers

Description

Create a container structure like this
/rest/project/inner1/inner2/inner3

  • Create a version V1 for /rest/project
  • Create a version V2 for /rest/project/inner1
  • Create a version V3 for /rest/project/inner1/inner2
  • Create a version V4 for /rest/project/inner1/inner2/inner3

Now traverse the fcr:versions path from /rest/project/fcr:versions/V1
You will notice like this
ldp: contains
http://fedoradev0.icpsr.umich.edu:8097/fedora/rest/project/inner1/fcr:versions

Here this is ambiguous because it is unclear which version of inner1 is participating in this version if /inner2 had multiple versions. In fact in this instance V1 was created first so it should be all children listed as-is.
