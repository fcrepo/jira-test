Description

In order to add BagIt bags to MetaArchive, we will create an MetaArchive BagIt Profile for fcrepo-import-export.

Definition of done is

  • Exporting resource(s) that conform to the MetaArchive BagIt profile
  • Documentation outlined on this document: https://docs.google.com/document/d/1yWfM9qHCUjT4FMLKX5cwCAPUVUTa9jvsldjmd7kbWfQ/edit#

N.B. There might be some useful resources/utilities here: https://github.com/MetaArchive
