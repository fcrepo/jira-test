Andrew Woods, 2016-11-16 16:02 UTC

Based on your gist, it appears that you are using the "FileSystemBinaryStore", likely from a configuration such as:

-Dfcrepo.modeshape.configuration=classpath:config/minimal-default/repository.json

The first thing I would suggest it to instead use a MySQL or PostgreSQL backend object store.
See 4.6: https://wiki.duraspace.org/display/FEDORA46/Configuring+JDBC+Object+Store
or 4.7: https://wiki.duraspace.org/display/FEDORA47/Configuring+JDBC+Object+Store

Secondly, if this is a new repository, I would highly suggest you start with Fedora 4.7.0.

Additionally, can you describe the nature of the "bulk import"? Do you have control over the number of concurrent import clients?
