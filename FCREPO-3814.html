FCREPO-3814 Allow the integrated deployment of an ActiveMQ webconsole

TypeNew Feature
StatusOpen
PriorityMedium
ReporterCédric Viaccoz
Created2022-03-23 08:42 UTC
Updated2022-03-31 14:37 UTC

Description

ActiveMQ has been designed with the possibility to deploy an[ integrated webconsole|https://activemq.apache.org/web-console] to monitor queues and topics through a web UI, and send special management events to those, such as purge messages through a simple click. This is a quite convenient tool to check the progress of indexation and overall to manage ActiveMQ. As the ActiveMQ instance of Fedora does not come bundled with a webconsole, it currently requires a separate instance of ActiveMQ and its webconsole to be “connected” through a RMI server port to monitor Fedora’s queues and topics.

I think it would make sense to allow the deployment of such a webconsole directly through Fedora, maybe on the user side it could be enabled through a configuration property. It is quite a handy tool, and it is a bit conter-productive to deploy a separate ActiveMQ instance just to get that UI working with Fedora.
