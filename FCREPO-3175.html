FCREPO-3175 CreateResourceService needs to return either a FedoraResource or its identifier to the HTTP layer to generate a response

Description

Currently once a resource is created, especially via POST, the newly generated resource and identifier is NOT returned to the HTTP layer to be returned as part of the response.

This ticket is to fix the CreateResourceService to return either the identifier or the resource back to the HTTP layer.
