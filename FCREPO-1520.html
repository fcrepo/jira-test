FCREPO-1520 Camel persist to DuraCloud

Description

This task is to create a Camel component that persists updated repository resources (RDF and binaries) to DuraCloud via the DuraCloud REST API.

Similar modules already exist here:
https://github.com/fcrepo4-labs/fcrepo-camel-toolbox

Comments (3)

Bill Branan, 2015-05-06 14:57 UTC

As this action requires that calls be made to DuraCloud, it may be simplest to define a property in Fedora which captures the base DuraCloud URL (e.g. "https://institution.duracloud.org/durastore/fedora-backup-space/"). This could be phrased as the "backup-base-url" if there is an interest in making this available generically. The base URL would then be combined with the object ID to create the completed URL used to push content to DuraCloud. This same pattern could then also be followed when requesting content from DuraCloud in a restore scenario.

Valid credentials, for a DuraCloud user with write permissions on the selected space, will be necessary as well.

Bill Branan, 2015-05-06 15:05 UTC

DuraCloud REST API documentation: https://wiki.duraspace.org/display/DURACLOUDDOC/DuraCloud+REST+API

The specific call that is most relevant here is the store content request: https://wiki.duraspace.org/display/DURACLOUDDOC/DuraCloud+REST+API#DuraCloudRESTAPI-StoreContent
