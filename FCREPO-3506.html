FCREPO-3506 OOM on GET of root with many child containers

TypeBug
StatusOpen
PriorityMedium
ReporterAndrew Woods
Created2020-10-29 16:32 UTC
Updated2024-01-11 21:37 UTC

Description

This bug can be seen when performing a GET request on the repository root, when there are many direct child containers of the root.

This issue was identified by using the HTML UI to make the GET request, and there were ~10M child containers of the root.

See attached stacktrace (oom-get-root.txt) from error scenario.
