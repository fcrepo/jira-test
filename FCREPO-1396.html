Description

See:

  • https://groups.google.com/d/msg/fedora-tech/LBnvq7Z8ZuE/hf67h9wEIeAJ and
  • http://www.w3.org/TR/ldp/#h-ldpc-post-createrdf

This task is to make it clear that F4 does not yet support the creation of LDPR (vs. LDPC) RDF Source resources that are not containers.

The following request should result in a "501 Not Implemented" response code:
curl -i -X POST -H "Link: <http://www.w3.org/ns/ldp#Resource>;rel=\"type\"" http://localhost:8080/rest/
