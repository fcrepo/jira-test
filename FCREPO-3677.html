Description

This validation needs to be performed only on  F3 managed (type "M") datastreams   ((ie not inline XML).

Compare the F6 checksum (as reported by OCFL)  with the corresponding checksum of the F3 datastream version.  The F3 checksum  will need to be generated from the file on disk.

In addition,  we want to allow users to optionally skip this checksum validating step (as it may be resource/time intensive).
