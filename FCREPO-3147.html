FCREPO-3147 Change migration-utils createVersionSnapshot output to show version-id of 'ignored' for OCFL migrations

Description

When migrating a Fedora 3 object to OCFL using migration-utils, the following INFO log message is displayed:

INFO 16:02:08.754 (OCFLFedora4Client) createVersionSnapshot: 1711.dl:TESTMIGRATEOBJ, version-id: foo

As OCFL manages its own versions, the word "foo" is a simple placeholder.  This should be changed to "ignored" for clarity's sake, when migrating an object to OCFL.
