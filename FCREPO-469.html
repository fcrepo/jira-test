Andrew Woods, 2009-04-03 22:43 UTC

The installation options will now be set as follows when running "quick" install:

FEDORA_SERVERHOST = localhost
APIA_AUTH_REQUIRED = false
SSL_AVAILABLE = true
APIA_SSL_REQUIRED = false
APIM_SSL_REQUIRED = true
SERVLET_ENGINE = included
TOMCAT_HOME = fedoraHome/tomcat
TOMCAT_HTTP_PORT = 8080
TOMCAT_SHUTDOWN_PORT = 8005
TOMCAT_SSL_PORT = 8443
KEYSTORE_FILE = included
DATABASE = included
DATABASE_DRIVER = included
DATABASE_USERNAME = fedoraAdmin
DATABASE_PASSWORD = fedoraAdmin
XACML_ENABLED = true
RI_ENABLED = false
REST_ENABLED = false
MESSAGING_ENABLED = false
DEPLOY_LOCAL_SERVICES = true

Note: These settings happen to provide for the ability to successfully run:
$ant junit -Dtest=fedora.test.AllSystemTestsConfigA
after installation has completed.
