Description

Currently, FedoraResource.getTypes() does not return a resource's RDF types, like the documentation suggests. These types are necessary for generating events.

As I see it, FedoraResource.getTypes() either needs to be updated to return the correct RDF types or removed/renamed. If it is not updated, then a new way to determine RDF types need to be created so that the types are accessible to the event code.
