FCREPO-4051 Spaces in resource identifier are not escaped

Description

From https://github.com/fcrepo/fcrepo/issues/2254

When a STOMP message is published, spaces in the resource name are not escaped. For example, this header:

org.fcrepo.jms.identifier:/test/City of God

And in the body:

{
  "object": {
    "id": "http://fedora.local.lan/rest/test/City of God"
  }
}

My expectation is that it would be consistent with the subject of the triples:

curl http://fedora.local.lan/rest/test/City%20of%20God
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix fedora: <http://fedora.info/definitions/v4/repository#> .
@prefix ldp: <http://www.w3.org/ns/ldp#> .
@prefix dcterms: <http://purl.org/dc/terms/> .

<http://fedora.local.lan/rest/test/City%20of%20God>
        dcterms:title          "City of God"@en-US ;
        fedora:created         "2025-08-30T02:09:18.688686832Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:lastModified    "2025-08-30T23:38:47.971555291Z"^^<http://www.w3.org/2001/XMLSchema#dateTime> ;
        fedora:createdBy       "fedoraAdmin" ;
        fedora:lastModifiedBy  "fedoraAdmin" ;
        rdf:type               ldp:BasicContainer ;
        rdf:type               ldp:Resource ;
        rdf:type               fedora:Resource ;
        rdf:type               ldp:RDFSource ;
        rdf:type               ldp:Container ;
        rdf:type               fedora:Container ;
        fedora:hasParent       <http://fedora.local.lan/rest/test> .
