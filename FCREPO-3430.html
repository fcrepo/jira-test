Description

Currently the document What are the Server Managed Triples says that there are 4 "server generated properties".

We have decided to remove the iana:describedby triple and just rely on the Link header.

This ticket is to determine if we should generate a triple for ebucore:filename automatically and add it to the user's RDF? We have been trying to avoid altering a user's RDF.

Currently in F6 all of the "server generated properties" are actually "Server Managed Properties" and cannot be changed (it is stored in the sidecar files).
