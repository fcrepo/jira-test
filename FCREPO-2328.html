Description

Importing into root of the repository works, but importing into a sub-path fails. Reasons for doing this include having a repository segmented by top-level containers (e.g. Hydra creates top-level containers for the Rails environment), or wanting to move resources to a different path in the repository when migrating.

Important to note: How to handle links to resources outside the exported/imported resource hasn't been defined. One idea was to determine what the repository base URL was and map those resources as though the entire repository was exported, but we should agree on the mapping strategy before proceeding to work on this ticket.
