Description

Replicates fcrepo-696, with the additional problem that an empty read-only context is insufficient for policy resolution. I think the solution is to add the ability to attach a context to DatastreamReferencedContent (and arguably to DatastreamManagedContent, which would have the same problem if it enforced a policy regarding the URLs it would fetch).
