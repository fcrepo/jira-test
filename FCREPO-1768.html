Description

This task is to enable the migration-utils to run in the case where the destination F4 repository has authz enabled.
This will likely include an update to fcrepo4-client to accept username/password.

To demonstrate that this issue has been resolved, run the migration-utils against the webac-enabled fcrepo4-vagrant:
https://github.com/fcrepo4-exts/fcrepo4-vagrant/releases/tag/fcrepo4-vagrant-4.3.1-SNAPSHOT-dcfug-2015-09
