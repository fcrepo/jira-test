FCREPO-1034 Support soapUI requests to Fedora web services

Description

Get 'Did not understand "MustUnderstand" header(s)' in the response when calling a Fedora web service with soapUI 4.0.1:

Request:
--------
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:typ="http://www.fedora.info/definitions/1/0/types/">
<soapenv:Header><wsse:Security soapenv:mustUnderstand="1" xmlns:wsse="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-secext-1.0.xsd"><wsu:Timestamp wsu:Id="Timestamp-75" xmlns:wsu="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-utility-1.0.xsd"><wsu:Created>2011-11-23T16:58:42Z</wsu:Created><wsu:Expires>2011-11-23T17:32:02Z</wsu:Expires></wsu:Timestamp><wsse:UsernameToken wsu:Id="UsernameToken-74" xmlns:wsu="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-utility-1.0.xsd"><wsse:Username>xxxxxxxx</wsse:Username><wsse:Password Type="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-username-token-profile-1.0#PasswordText">xxxxxxxx</wsse:Password><wsse:Nonce EncodingType="http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-soap-message-security-1.0#Base64Binary">w3uon59dmR08T14EovDj3Q==</wsse:Nonce><wsu:Created>2011-11-23T16:58:42.843Z</wsu:Created></wsse:UsernameToken></wsse:Security></soapenv:Header>
<soapenv:Body>
<typ:listDatastreams>
<pid>demo:12</pid>
<asOfDateTime/>
</typ:listDatastreams>
</soapenv:Body>
</soapenv:Envelope>

Response:
---------
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:xsd="http://www.w3.org/2001/XMLSchema" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
<soapenv:Body>
<soapenv:Fault>
<faultcode>soapenv:MustUnderstand</faultcode>
<faultstring>Did not understand "MustUnderstand" header(s):</faultstring>
<detail>
<ns1:hostname xmlns:ns1="http://xml.apache.org/axis/">domU-12-31-39-09-F6-32</ns1:hostname>
</detail>
</soapenv:Fault>
</soapenv:Body>
</soapenv:Envelope>

soapUI request format should be supported by Fedora.

Rationale:

soapUI is an easy-to-use tool to quickly create test cases for web services.
