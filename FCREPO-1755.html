Description

This task is to change the HTTP status code returned when creating a version of a resource from 204 to 201. For example:
curl -i -XPUT http://localhost:8080/fcrepo/rest/test
curl -i -XPOST -H"slug: v0" http://localhost:8080/fcrepo/rest/test/fcr:versions

...should return 201.
