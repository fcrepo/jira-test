Description

Curl the headers on any /fcr:fixity uri and you'll notice that there are no link headers as I would expect.

Link: <http://www.w3.org/ns/ldp#Resource&gt;;rel="type"
Link: <http://www.w3.org/ns/ldp#RDFSource&gt;;rel="type"

To reproduce:

1. Create a NonRdfSource resource
2. curl -v -I -i http://localhost:8080/rest/your-resource/fcr:fixity
3. verify there are no links returned.
