Description

When running the jmeter performance tests against Fedora (with any DB configuration, even H2) with 4 client threads, the stacktrace at the bottom of this description is consistently produced.

To reproduce the error:

  • Clean the environment:
    $ rm -rf fcrepo-home
    • ..clean the database, if an external DB is configured
  • Start Fedora:
    $ java -jar fcrepo-webapp/target/fcrepo-webapp-6.0.0-SNAPSHOT-jetty-console.jar --headless
    • ..or start Fedora in Tomcat, or via mvn jetty:run
  • Download the master branch of fcrepo4-jmeter (https://github.com/fcrepo4-labs/fcrepo4-jmeter)
  • Run jmeter in the following configuration, and watch Fedora log/console
    $ jmeter -Dfedora_4_context=/rest -Dcontainer_threads=4 -n -t fedora.jmx
