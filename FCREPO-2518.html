Description

When I export repo A and then import into a repo B (that is running in relaxed mode) the fedora:lastModified values of the root containers of do not match between A and B.

To reproduce:

1. In one shell run:
java -Dfcrepo.properties.management="relaxed" -Dfcrepo.dynamic.jms.port=61717 -Dfcrepo.dynamic.stomp.port=61713 -jar fcrepo-webapp-4.8.0-SNAPSHOT-jetty-console-a07a1a46.jar --port 8686 --headless --contextPath /f4

1.1. create a container named "test"
curl -X POST "http://localhost:8686/f4/rest" -H "Slug: test"

2. In a second shell run:

java -Dfcrepo.properties.management="relaxed" -Dfcrepo.dynamic.jms.port=61718 -Dfcrepo.dynamic.stomp.port=61714 -jar fcrepo-webapp-4.8.0-SNAPSHOT-jetty-console-a07a1a46.jar --port 8687 --headless --contextPath /f4

3. build fcrepo-import-export r 6b5641

4. mkdir export

5. Run the export:

java -jar fcrepo-import-export-0.1.1-SNAPSHOT.jar -d export -a -m export -r http://localhost:8686/f4/rest -b --writeConfig export-config.yml

6. Run the importer:

java -jar fcrepo-import-export-0.1.1-SNAPSHOT.jar -d export -a -m import -r http://localhost:8687/f4/rest -b --writeConfig import-config.yml -M http://localhost:8686/f4/rest,http://localhost:8687/f4/rest

7. Curl the root container on each:
curl http://localhost:8686/f4/rest;
curl http://localhost:8687/f4/rest;

8. Verify that the fedora:lastModified's for the two uri's differ.

Comments (3)

Michael Durbin, 2017-06-08 14:08 UTC

I suspect this is because the importer imports the container first, then the children.  Addition of children updates the modification date of parent resources.  A solution to this might be to rework the import code to do a first pass that creates placeholder nodes for everything that is to be imported and then work from leaf to root.  One should evaluate such a change in approach to see if it might also address the challenges associated with https://jira.duraspace.org/browse/FCREPO-2459 and for performance implications.

 

An approach that would involve less reworking would be simply to patch parents with the correct dates after all children are added when doing a lossless import.
