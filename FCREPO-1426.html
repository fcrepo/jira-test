Former user, 2015-04-15 11:31 UTC

Mohamed Mohideen Abdul Rasheed, I think this is a good start, but too tightly coupled to the kernel. Ideally, there would be no kernel changes at all for the audit service. Instead, you should follow the pattern of the JMS module and subscribe to the eventBus events that are already being generated:

https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-jms/src/main/java/org/fcrepo/jms/observer/JMSTopicPublisher.java

So I think you should create a new fcrepo-audit module and move the AuditServiceImpl.java there.

I would also like to see a System property used to enable the creation of these nodes, called fcrepo.audit.container, whose value is used instead of hard-coding /audit/.
