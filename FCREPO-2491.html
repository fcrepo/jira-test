Description

Currently defaults to ldp:contains, but needs to respect specified predicates in config.

Logic for adding this feature:
--------------------------------------
Read list of predicates from config file. When walking Fedora repository and finding children of a particular node, get the objects of all triples with the specified predicates and add them to the list of nodes to be walked.

When determining the location of a given resource (whether Fedora or local), the tool should compare the path against the repository base rather than to the full repository path (-r flag in conifiguration) since not all resources will be under the root node in terms of ldp containment when user supplied predicates are used.
