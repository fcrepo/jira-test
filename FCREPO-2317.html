FCREPO-2317 Content-Disposition filename should not include datatype URI

Description

When a binary is retrieved, a Content-Disposition header including the filename is sent. In 4.7.0, the filename now includes the datatype URI:

Content-Disposition: attachment; filename="newname.jpg ^^ http://www.w3.org/2001/XMLSchema#string"; creation-date="Sat, 19 Nov 2016 22:58:17 GMT"; modification-date="Tue, 22 Nov 2016 19:24:48 GMT"; size=277448828

This results in the browser treating the datatype URI as part of the filename. The filename should simply be a string with the datatype URI removed.

See https://github.com/fcrepo4/fcrepo4/issues/1145
