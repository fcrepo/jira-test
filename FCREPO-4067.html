fcrepo-camel hasn’t been updated since 2021, so not surprisingly it is pretty far behind on dependencies and has a number of security alerts. We should bring its dependencies as up to date as possible without requiring java 21, since for the moment it should still be usable with fcrepo 6. This includes camel updates in particular, but also junit, jena, and spring
