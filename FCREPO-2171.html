Description

There are a few issues with the HTML interface in Safari on OSX. Whenever I click the Add button to create a new container I see a blank screen with only the URL of the new container (the container does get created). If I try to provide an identifier I get the same result, except my provided identifier is not used and a new container is created using the default path minter.

Jared Whiklo, 2016-09-27 16:49 UTC

Ok, so Unknown is using strict mode with ECMA script.

But Safari < 10 only supports the const keyword if you are NOT using strict mode. This is causing the javascript to fail.

Solution are:

  • Vary ECMA script based on browser type and version
  • Disable strict mode
  • Suggest upgrading to all users of Safari version < 10, IE version < 11, Mini Opera any version, Android browser < 5
