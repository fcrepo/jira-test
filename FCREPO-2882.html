Description

The test LdpTestSuiteIT is producing large numbers of stacktraces/failures, but the failures to not cause the test to fail according to maven and junit.

The errors have been happening for quite a while, but the numbers have increased over time. Here is a successful PR build from April 2018:

https://api.travis-ci.org/v3/job/367880983/log.txt

Which shows 20 failures for IndirectContainerTest, 24 for DirectContainerTest

While in March 2017:

https://api.travis-ci.org/v3/job/211829546/log.txt

There were 3 failures for IndirectContainerTest, and 3 for DirectContainerTest

Investigate to determine if these failures are a problem, why the number is increasing. Also can determine if it would be appropriate for the test to fail the maven build or not.
