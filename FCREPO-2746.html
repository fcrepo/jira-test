Created2018-04-06 13:20 UTC

Affects versionsFedora 4.7.5

Environment

Description

When trying to use a S3 compatible storage [1] [2], in our case Ceph (Luminous), we get an exception [3].
While trying to debug the problem I set up nginx as S3 Proxy for aws (configuration below) and found out that the same error appears when using this setup [4] (I set up a local dns resolver for this).
When removing the redirect and accessing aws directly everything works fine. Tried using other S3-Proxy solutions as well.

Sending 1 byte files throws the same exception and uploading empty files creates exception [5]. If you need access to a Ceph S3 instance for testing I will provide one on our test installation.
