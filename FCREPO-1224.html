Environment

Gentoo Linux; Tomcat 7.0.42 from distro; fcrepo-webapp-4.0.0-beta-02-auth.war.

Description

WAR is missing the Woodstox STAX XML processor JARs. One sees "javax.xml.stream.FactoryConfigurationError: Provider com.ctc.wstx.stax.WstxInputFactory not found" in the Tomcat host log and the app. fails to start.

I manually downloaded woodstox-core-asl-4.2.0.jar and stax2-api-3.1.1.jar, copied them into WEB-INF/lib, and the app. was then able to start. Possibly org.codehaus.woodstox/woodstox-core-asl is missing from the declared dependencies.
