Description

When doing mvn jetty:run from the fcrepo-webapp directory, inspecting the headers for the repository root resource reveals an acl link relation that points to http://localhost:8080/rest//fcr:acl

This seems to be incorrect

Doing a GET on this resource results in a 405 (Method not allowed)

Doing a HEAD against this resource reveals no LDP headers

 

The correct ACL link is likely http://localhost:8080/rest/fcr:acl

N.B.  Due to a bug present in FCREPO-2825 Closed , the "correct" ACL link results in a 404.
