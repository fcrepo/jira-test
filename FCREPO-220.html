Description

I found this problem in config/rest XSLTs for the "demoOnLucene" demo, but it may be more widespread.

After running the ant configuration process, the XSLTs in the config/rest directory contains a demoCommon.xslt. However, the other XSLTs in that directory still "include" the original version of demoCommon.xslt in the configDemoOnLucene/rest directory. So if you try to tweak the config/rest/demoCommon.xslt file, it has no effect.
