Esmé Cowles, 2016-09-09 11:45 UTC

The external URI is retrieved by the export client and saved to disk. Since the request is redirected, then it doesn't see the original response, so the binary description with the metadata (including the mime type with the external link) is never seen or retrieved.

Andrew Woods, 2016-09-09 12:50 UTC

I wonder if disabling the client from following redirects would do the trick? Like: https://github.com/fcrepo4/fcrepo4/commit/1aeada253499b771409c92b2309d6ec11a58d7cc#diff-39785d72ffe23548cc619403f35d9028R295

Esmé Cowles, 2016-09-09 17:00 UTC
