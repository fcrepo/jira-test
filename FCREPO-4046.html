FCREPO-4046 Use servlet 6.0 to support tomcat 10

Description

Technically Tomcat 10 only supports Servlet v6.0 according to their which version page:

https://tomcat.apache.org/whichversion.html

Fedora 7 current specifies 6.1, so while Fedora 7 does appear to work in Tomcat 10, it would be safest to revert fedora 7 to depending on servlet v6.0. The risk in depending on 6.1 is that we could accidentally use a 6.1 feature and cause unexpected problems for users in Tomcat 10. The list of new features in 6.1 are here:

https://jakarta.ee/specifications/servlet/6.1/
