Description

The first part the PUT example in the documentation says to do a GET with "Content-Type" header instead of "Accept". This has been fixed in the bleeding edge page, but not the older pages.

Also in this example (and most), the docs show the returned resources in turtle (default), but the system returns `@prefix` and not `PREFIX`. Minor, but can be slightly confusing. Not sure if it's worth changing.
