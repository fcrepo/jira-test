FCREPO-2240 Pair-trees should be pair-trees

Description

When exporting and importing sample data from a default CurationConcerns application using the placeholders branch, the pair-tree nodes that ActiveFedora is creating are not getting re-imported as such.

For example, a UID in Hydra such as 11223344, becomes the path 11/22/33/44/11223344 in Fedora. Each interim node is a pair-tree with these types:

http://fedora.info/definitions/v4/repository#Pairtree
http://www.w3.org/ns/ldp#BasicContainer
http://www.w3.org/ns/ldp#Container
http://www.w3.org/ns/ldp#RDFSource

However, when the data is imported back into Fedora, these nodes now have:

http://fedora.info/definitions/v4/repository#Container
http://fedora.info/definitions/v4/repository#Resource
http://www.w3.org/ns/ldp#Container
http://www.w3.org/ns/ldp#RDFSource

They should not have repository#Container or repository#Resource.
