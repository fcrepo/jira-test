Description

The manifest-SHA.txt produced by the Bag export is not compatible with command-line shasum. When I try to validate the files in the manifest with shasum, I get the following error:

$ shasum -c manifest-SHA1.txt
shasum: manifest-SHA1.txt: no properly formatted SHA1 checksum lines found

The BagIt spec for manifest files may not be compatible with shasum, but if it is, then we should make them compatible for ease of validation.

The format in master is compatible with md5sum/shasum (see https://github.com/LibraryOfCongress/bagit-java/commit/27832c1110e3b724d55e9da622a8c3c9db1a8bf9#diff-532a7a3929918490a426c42047e7b688). So this will be resolved when we can update to a new version.

The current plan is for a 5.0 release in a few months. So I've asked if they could make an updated beta release so we can use it in our release before then.
