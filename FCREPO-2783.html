Description

An implementation of the modeshape's AuthenticationProvider interface is necessary to have non-anonymous access to Modeshape repository. Currently, the authenticationProvider was removed from the spring configuration as we are using Shrio for AuthZ. When I started the repo with this configuration, all the object interaction were considered as anonymous. The created by and last modified by user were marked as "<anonymous>" even though I has authenticated session with the container and authorized by Shiro WebACFilter. (Note: I also had to make the provider as an empty array in the repository.json to even get the anonymous mode working)

To actually record the current user as the createdBy/lasModifiedBy user, we need to create an Modeshape session with the current user's SecurityContext. Therefore, we need to update the current ServletContainerAuthenticationProvider, FedoraUserSecurityContext classes to provide the security context to Modeshape, but not do any authorization with FAD as it is already taken care of by Shiro WebACFilter.

Mohamed Mohideen Abdul Rasheed I had also started an implementation of this as a separate ShiroAuthenticationProvider class that picks up the user information from the authenticated Shiro Subject.

package org.fcrepo.auth.webac;

import java.util.Map;

import javax.jcr.Credentials;

import org.apache.http.auth.BasicUserPrincipal;
import org.apache.shiro.SecurityUtils;
import org.apache.shiro.subject.PrincipalCollection;
import org.apache.shiro.subject.Subject;
import org.modeshape.jcr.ExecutionContext;
import org.modeshape.jcr.security.AuthenticationProvider;
import org.modeshape.jcr.security.SecurityContext;


public class ShiroAuthenticationProvider implements AuthenticationProvider {

    @Override
    public ExecutionContext authenticate(Credentials credentials, String repositoryName, String workspaceName,
            ExecutionContext repositoryContext, Map<String, Object> sessionAttributes) {

        final Subject currentUser = SecurityUtils.getSubject();

        return repositoryContext.with(new ShiroSecurityContext(currentUser));
    }

    public static class ShiroSecurityContext implements SecurityContext {

        private Subject user;

        private String userName;

        public ShiroSecurityContext(final Subject user) {
            this.user = user;
            final PrincipalCollection principals = user.getPrincipals();
            final BasicUserPrincipal userPrincipal = principals.oneByType(BasicUserPrincipal.class);
            if (userPrincipal != null) {
                this.userName = userPrincipal.getName();
            } else {
                this.userName = null;
            }
        }

        @Override
        public boolean isAnonymous() {
            return !user.isAuthenticated();
        }

        @Override
        public String getUserName() {
            return userName;
        }

        @Override
        public boolean hasRole(String roleName) {
            return user.hasRole(roleName);
        }

        @Override
        public void logout() {
            // this method intentionally does nothing
        }

    }

}
