Description

The task of looking up deployments for a given CModel (which involves maintaining and persisting a map) is currently performed by DOManager. It would be cleaner and more flexible to put this functionality (which is by no means trivial) in its own module. This module would be responsible for any persistence of maps it needs, and thus would need to be able to participate in the rebuild process.
