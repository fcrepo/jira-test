Description

Specifically to address FCREPO-492 Closed - allo DC, RELS-EXT etc to be managed content.

The tool needs to migrate existing "X" datastreams to "M" to address this (we may consider making its scope more general)

The tool needs to migrate all datastream versions, and should record the change in the audit trail.

Stephen Bayliss, 2010-08-17 13:41 UTC

fedora-modify-control-group scripts in server/bin, takes parameters

  • protocol
  • user
  • password
  • pid: single pid, comma-separated list, or file:///path/to/file specifying list of pids
  • dsID: single datastream identifier or comma-separated list of datastream identifiers
  • controlGroup: desired control group (only M is accepted)
    Additional parameters:
  • addXMLHeader - add an XML declaration including the UTF-8 character set
  • reformat - reformat the XML (indenting)
  • setMIMETypeCharset - add charset=UTF-8 to the MIMEType (this will be returned in http headers when getting the datastream content)

Web service call
/management/control?action=modifyDatastreamControlGroup
with additional query parameters as above, excluding protocol, user and password
