Danny Bernstein, 2020-06-23 20:15 UTC

I just tested the "DELETE ... WHERE {}" and "DELETE DATA" queries and was able to successfully delete the triples. 

My commands: 

# create resource
  curl -u fedoraAdmin:fedoraAdmin "http://localhost:8080/rest/test1" -X PUT;
# insert triples
 curl -u fedoraAdmin:fedoraAdmin "http://localhost:8080/rest/test1" -X PATCH -H "Content-Type: application/sparql-update" --data "INSERT DATA { <http://localhost:8080/rest/test1> <http://example/> <http://localhost:8080/rest/test101>. }

# I verified it was there in the OCFL.  Then verified it was there in the response:
curl -u fedoraAdmin:fedoraAdmin "http://localhost:8080/rest/test1" 
# Then I confirmed that is was deleted via
curl -u fedoraAdmin:fedoraAdmin "http://localhost:8080/rest/test1" -X PATCH -H "Content-Type: application/sparql-update" --data "DELETE { <http://localhost:8080/rest/test1> <http://example/> <http://localhost:8080/rest/test101>. } WHERE {}"
# repeated the above but tried deleting using the DELETE DATA syntax.
 "Content-Type: application/sparql-update" --data "DELETE DATA { <http://localhost:8080/rest/test1> <http://example/> <http://localhost:8080/rest/test101>. }"
