Description

Recently updated https://wiki.duraspace.org/display/FEDORA44/Configuration+Options+Inventory mentions:

Modeshape Configurations
/config/clustered/repository.json
Default configuration with repository clustering enabled. By default, uses /config/infinispan/clustered/infinispan.xml persistence configuration.

In fact, in fcrepo4/fcrepo-configs/src/main/resources/config/clustered/repository.json the following line says otherwise:

"cacheConfiguration" : "$

{fcrepo.ispn.configuration:config/infinispan/leveldb/infinispan.xml}

",

The repository.json file should be brought into correspondence to the documentation - which correctly describes the intent to configure clustering.
