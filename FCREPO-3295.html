Description

Currently the only way to know if a given resource is a part of an AG is by looking for a

Link: <http://fedora.info/definitions/v4/repository#ArchivalGroup>;rel="type" 

header at each node in the containment hierarchy.  It would be convenient for clients to know whether a given resource is nested within an ArchivalGroup.

 

One approach would be to add a link header for AG nested resources that points to the archival group. So a GET to /my-archival-group/resourcA  for return the following header

Link: <http://localhost:8080/rest/my-archival-group>;rel="archival-group"
