FCREPO-3404 Add support for versioning resources together

Description

fcrepo-storage-ocfl should support versioning related resources together. This means that when a binary resource is written, the last modified header on its description should be touched and vice versa. Additionally, an update to an AG part should touch the last modified header of the containing AG, unless the resource is an ACL.
