Description

Clean up the ingest tidy-up code so that it only attempts to remove artefacts (objectStore, datastreamStore, registry, fieldSearch, RI) that were actually created during the failed ingest. This will allow failures in the tidy-up code to be logged as errors (currently these need to be warnings as the code doesn't know if the artefact was actually created).
