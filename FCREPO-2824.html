Description

Fedora provides a root ACL, as required by the SOLID WebAC spec:

https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-auth-webac/src/main/resources/root-authorization.ttl

 

The ACL inheritance algorithm suggests that, if the authorizations are intended to inherit, that acl:default should be present.

https://github.com/solid/web-access-control-spec#acl-inheritance-algorithm-example

 

Therefore, it seems that the root ACL should have an acl:default statement.  Please add one to the root ACL.
