Description

The Swing Admin client exhibits several failures during manual testing for the 3.6 release. This list is still being built. However, substantial parts of the tool continue to function and can provide useful operations.

  • Attempt to ingest an object whose PID already exists in Fedora. The Swing Admin Client will lock up and the only way to exit is to kill its process.
  • Most of the "Console" functions (SOAP) do not work.
