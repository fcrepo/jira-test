FCREPO-2975 NullPointerException during transaction commit

Description

Ran into this when updating our local clients. It appears that if you start a transaction, make a head request against an object, delete the object, then commit the transaction, the commit will throw a NullPointerException and fail to commit. Both the head and the delete request are necessary to trigger the issue and the HEAD request must be within the transaction.

I am able to replicate it with the following commands:

# Create object
curl -ufedoraAdmin:fedoraAdmin -XPUT http://localhost:8080/rest/txtest4

# Start tx
curl -ufedoraAdmin:fedoraAdmin -v -XPOST http://localhost:8080/rest/fcr:tx
# Grab the tx id for the rest of the requests

# Head request on binary in tx
curl -ufedoraAdmin:fedoraAdmin -I http://localhost:8080/rest/tx:37520593-01dd-4115-a4ee-8be1c7c5061f/txtest4

# Delete the binary
curl -ufedoraAdmin:fedoraAdmin -XDELETE http://localhost:8080/rest/tx:37520593-01dd-4115-a4ee-8be1c7c5061f/txtest4

# Commit the tx
curl -ufedoraAdmin:fedoraAdmin -v -XPOST http://localhost:8080/rest/tx:37520593-01dd-4115-a4ee-8be1c7c5061f/fcr:tx/fcr:commit
