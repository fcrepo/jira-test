Description

When the tomcat user (etc) does not have permission to create the server/management/uploads directory, you get a NPE with an obscure error message (stacktrace below).

I tracked the error to https://github.com/fcrepo/fcrepo/blob/master/fcrepo-server/src/main/java/org/fcrepo/server/management/ManagementModule.java#L107. The `mkdirs` command may return false when it is unable to create the directory tree (note, it also returns false if the directory already exists). I assume it should throw an exception if the upload directory doesn't exist and can't be created?
