FCREPO-2866 WebAC Filter doesn't allow PATCH when content-type has charset

Description

If you have acl:Write or acl:Append permissions you should be able to perform certain PATCH requests. But if you send your request with a Content-type with a character set.

ie. Content-type: application/sparql; charset=ISO-8859-1

It will fail.

 

> curl -i -utestuser:testpass http://localhost:8080/rest/BOX -XPATCH -H"Content-type: application/sparql-update" -d"PREFIX dc: <http://purl.org/dc/elements/1.1/> INSERT {<> dc:description \"This is awesome\" } WHERE {}"
