Description

In the HTML UI browsing to an RDFSource object's versions (http://localhost:8080/rest/apple_box/carton_of_apples/fcr:versions) results in being redirected to non-existant fcr:metadata (http://localhost:8080/rest/apple_box/carton_of_apples/fcr:versions/fcr:metadata) because the original URI does not return a Link Header (which is how we determine a RDFSource).
https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-http-api/src/main/resources/views/common.js#L96

Possibly twitchy solution is to not redirect if the URI ends in "/fcr:*"
