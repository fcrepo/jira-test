Description

Travis fails to run tests in Java 8 environment 

Peter Winckles reported:

"Any system that references Java 11 binaries must run Java 11 or greater. Projects like migration-utils that directly use Java 11 binaries must be compiled using Java 11 or greater, but they do not need to be compiled to Java 11 byte code themselves. However, even if they aren't compiled to Java 11 byte code, Java 11 is still required at run time if the OCFL library (or other Java 11 libraries) are used."

Task: Remove Java 8 tests.

Pass criteria: Travis does not throw errors with Java 8 environment
