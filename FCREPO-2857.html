Description

Container acl:Append prohibits "DELETE {} INSERT { ... }" but allows "DELETE DATA { ... }"

That is, it disallows a DELETE/INSERT statement with an empty DELETE clause, but does allow a DELETE DATA statement with a non-empty clause.

This behavior should be reversed to allow DELETE/INSERT when the DELETE clause is empty, and prohibit DELETE DATA statements entirely.
