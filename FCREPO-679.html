Chris Wilper, 2010-05-11 15:26 UTC

Matteo, That is an out-of-date video where a beta release of Fedora 3.0 was used. I've updated the title to that effect, and have pointed to the latest installation information in the description.

Which version of Fedora are you trying to install? The procedure is different now. I would recommend installing the latest version (3.3) using these instructions:

http://www.fedora-commons.org/confluence/display/FCR30/Installation+and+Configuration+Guide

This latest version should work fine in your environment, with Java 1.6. If you continue to have problems, you might also find hints as to what is wrong in the $FEDORA_HOME/server/logs/fedora.log file and/or the tomcat/logs/catalina.out file.

Also, we have a mailing list for technical questions which you may want to sign up for. Details are here:

http://www.fedora-commons.org/community/userlist
