Description

Felix reported that he could not start the latest snapshot on top of migrated content when using MySQL. He was seeing the indexing on start hang indefinitely.

The root cause of the problem was MySQL throwing deadlock exceptions, where were supposed to be retried by that application. However, the retry framework is managed by Spring and at the time the reindex runs in the lifecycle Spring had not initialized the retry framework. So, the application hung indefinitely waiting for the exceptions to be retried.
