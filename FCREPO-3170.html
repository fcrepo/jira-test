Description

Documenting this discussion

https://github.com/fcrepo4/fcrepo4/pull/1599/files#r363869358

Essentially if we want to call the request for the full URI and pass that to the HttpIdentifierConverter, then we should remove references to the externalPath and store the Fedora ID.

Otherwise we could use the existing `toDomain` on the HttpIdentifierConverter to convert the externalPath back to the full URI. But we should still store the resolved Fedora ID so we don't have to keep calculating it.
