Description

The root node previously included two properties summarizing repository content (total number of objects and total bytes stored). This code was commented out because of performance problems with federated content:

https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-kernel-modeshape/src/main/java/org/fcrepo/kernel/modeshape/rdf/impl/RootRdfContext.java#L74-L84

This ticket is for creating an external module to add this functionality, which could be included by repositories not using federation.
