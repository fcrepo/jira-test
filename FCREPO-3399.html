Description

In case sensitive operating systems, attempting to create an external binary from a local file uri will fail if there are any capital letters in the file path. For example:

curl -XPUT -H"Link: <file:///path/to/CAPS/TEST.txt>; rel=\"http://fedora.info/definitions/fcrepo#ExternalContent\"; handling=\"proxy\"; type=\"text/plain\"" http://localhost:8080/fcrepo/rest/case_sensitive

Will return:

Path did not match any allowed external content paths: file:///path/to/CAPS/TEST.txt

Even though the file exists and is within a path allowed by the fcrepo.external.content.allowed config file
