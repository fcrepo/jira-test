FCREPO-103 Installer creates one-jar doc directory

Description

When running the installer jar, a doc/ directory gets created. This is caused by the one-jar library that we use for creating self-contained executable jars. It can be fixed by omitting the main jar manifest's One-Jar-Expand attribute.
