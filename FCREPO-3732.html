Description

Resource rdf types are accessed in a variety of places such as:

1. As part of the web acl stuff
2. Search indexing
3. Membership
4. Constructing HTTP responses

(Not necessarily an exhaustive list)

The problem is the user rdf must be parsed in order to determine the rdf types, and, while the types are cached on any given resource object, they are not cached between resource objects. That is to say, multiple resource objects for the same resource do not share the cache. This matters because in each of those instances listed above a different resource object is created.

This results in wasteful disk reads that impact users with their storage on a NAS in particular. Ideally, these types should not be loaded more than once per request.
