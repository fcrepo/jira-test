Osman Din, 2015-03-27 19:09 UTC

The need for this dependency comes from our use of site-maven-plugin:

https://github.com/fcrepo4/fcrepo4/blob/master/pom.xml#L475

I've created a PR based on your patch snippet:

https://github.com/fcrepo4/fcrepo4/pull/758

(Of course, instead of the PR, an admin could alternatively upload the jar directly to a fcrepo maven repo using:

mvn deploy:deploy-file -DgroupId=org.eclipse.mylyn.github -DartifactId=org.eclipse.egit.github.core -Dversion=3.1.0.201310021548-r -Dpackaging=jar -Dfile=/path/to/file -Durl=[url] -DrepositoryId=[id]

Not user if it would need updates, though.)
