FCREPO-1109 RelationshipTuple should store Datatype URI as a java.net.URI

Description

RelationshipTuple currently stores the output of toString on the datatype URI, then re-creates the URI in more places than the String value is needed alone. It should privilege the more common use case in serialization/deserialization over the relatively rare individual relationship updates.
