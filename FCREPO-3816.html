Demian Katz, 2022-09-22 18:24 UTC

On today’s Dev call, we talked about adding a section about setting up an external ActiveMQ and forwarding messages from Fedora. One of the advantages of this is gaining access to the web console, which is currently included by default in ActiveMQ 5.x. I’m attaching an “ActiveMQ Notes.docx” file which I assembled while setting this up in my local environment for testing. It might be adaptable into an example on the wiki – feel free to use it however you like. Details on the web console are available at https://activemq.apache.org/web-console – I didn’t have to do anything extra to set that up, I just opened an SSL tunnel to port 8161 and was immediately able to log in with the default credentials. (Obviously best practice would be to change those! 🙂).
