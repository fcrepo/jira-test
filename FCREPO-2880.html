Description

This ticket depends on https://jira.duraspace.org/browse/FCREPO-2877   being completed first.

When retrieving a memento with SMTs omitted,  the results should mirror the Original Resource.

create versioned resource

curl -X POST -H "Link: <http://mementoweb.org/ns#OriginalResource>; rel=\"type\"" http://localhost:8080/rest/ -H "slug: testxyz" -u fedoraAdmin:fedoraAdmin

create memento of versioned resource

curl -i -X POST -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/testxyz/fcr:versions;

Get the original resource without SMTs

 

curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/testxyz -H "Prefer: return=representation; omit=\"http://fedora.info/definitions/v4/repository#ServerManaged\""

No triples should be returned.

Get the memento without SMTs

 curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/testxyz/fcr:versions/20181001231451 -H "Prefer: return=representation; omit=\"http://fedora.info/definitions/v4/repository#ServerManaged\""

Notice some SMTs are returned: 

 

<http://localhost:8080/rest/testxyz2>  
                            rdf:type ldp:RDFSource ; 
                            rdf:type ldp:Container ; 
                            rdf:type ldp:BasicContainer .

 

The task at hand it to ensure that the SMTs are suppressed in exactly the same way as they are in the Original Resource.
