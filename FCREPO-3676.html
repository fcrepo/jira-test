Description

The task here is to add a command line parameter for generating a TSV of the validation results (as an alternative to the HTML report).

It might nice to be able to generate both HTML and TSV in a single run.    So perhaps we add --report-formats=html,tsv .  The default will be html, but users can optionally generate one, the other or both.
