FCREPO-3181 Migration-utils: Add datastream file extensions

Fix versionsfcrepo-migration-utils-4.5.0, Fedora 6.0.0
ParentFCREPO-3142 Modeshape out, OCFL In.

Description

Migrated datastreams have no file extension. It would be nice if migrated datastreams have a file extension inferred from the MIME type; e.g. DC.xml instead of just DC, and OCR.txt instead of just OCR. This should particularly help out with in-line XML datastreams.
