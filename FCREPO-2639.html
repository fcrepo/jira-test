Description

Create a new JCR Node resource to contain the TimeMap (LDPCv).

This resource will be created when a user turns on versioning for any LDPR.
See tickets https://jira.duraspace.org/browse/FCREPO-2624 and https://jira.duraspace.org/browse/FCREPO-2625

This resource is accessible at the fcr:versions endpoint for a LDPRv (LDPR with versioning enabled).

This resource will need a new internal RDF type and be excluded from the ldp:contains relationship of its parent LDPR.
