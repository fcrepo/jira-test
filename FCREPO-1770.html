Description

Currently, there is no way to pass credentials to Fedora 4 when migrating data using migration-utils. This is a problem when demonstrating the utility using a virtual machine that has authorization enabled.

This task is to include a configuration option in migration-utils for passing in a username and password to Fedora 4 when running a migration.
