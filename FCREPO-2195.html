This is due to import ordering.

If you PUT a URI with slashes, it makes the intermediary nodes as peartree nodes once and for all.

I remember a ticket to allow this to be fixed in the repository, but I don't think it got fixed.

Esmé Cowles, 2016-09-09 17:45 UTC

I believe we can just sort the files with files before directories to fix this:

class FilesFirstComparator implements Comparator<File> {
    public int compare(final File f1, final File f2) {
        if (f1.isFile() && f2.isDirectory()) {
            return -1;
        } else if (f2.isFile() && f1.isDirectory()) {
            return 1;
        }
        return f1.compareTo(f2);
    }
}

If the files are processed first, then the directories are created before their contents, avoiding accidental PairTree creation.
