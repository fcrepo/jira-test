Description

The upload servlet management/upload is functionally part of API-M Lite, but it is not documented as such. The fix to this bug should ensure it gets documented in the WSDL as well as any human-readable docs that talk about API-M Lite in src/userdocs.

It should also ensure that appropriate TestHTTPStatusCodes tests exist (and pass) to exercise AuthN, AuthZ, and request success/failure conditions.
