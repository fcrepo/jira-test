Environment

Fedora 6.4+ with S3 storage

Description

Scenario: directly accessing content in OCFL root on disk (for initial testing as well as restoration/portability)

  • Cannot search in S3 except via known identifier
  • Have to manually calculate the hash of the Fedora ID using a specific formatting of the Fedora ID in order to navigate to the OCFL object in S3 (info:fedora/the/id/etc)
  • To simplify this, having the Fedora UI display the hash it generates for the persisted OCFL object will be very useful
