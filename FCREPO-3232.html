Description

This task is to enable the creation of a Fedora resource version/memento via the HTTP API (POST /fcr:versions).

The result of the request should be a newly created OCFL version.

It is possible/likely, that initial exploration of this task (org.fcrepo.http.api.FedoraVersioning) will reveal that a number of sub-tasks must be accomplished first.
..in which case, additional, granular, tickets should be created and worked first.

Peter Winckles, 2020-03-04 20:06 UTC

Per discussion in slack.

  • All actions within a transaction will result in the creation of a single version, if auto-versioning is enabled.
  • If auto-versioning is not enabled, the updates go in mutable-head.
  • Requests to create versions within transactions are prohibited.
  • Specifying a timestamp and POST content is no longer supported.
