This task is to resolve the unusual situation where FedoraVersioning.addVersion(..) fails.

Sometimes the update from "versionService.createVersion(..)", which adds the "mix:versionable" if necessary (line:152), is not available before the subsequent request for "resource().getBaseVersion().getFrozenNode()" is made (line:154).
