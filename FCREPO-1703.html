Description

This task is to ensure that URIs of versioned resources are exposed as their version label, not their JCR UUID.

  • Create a binary resource in the HTML UI
    • http://localhost:8080/rest/image
  • Create a version of that resource
    curl -i -XPOST -H"slug: v0" http://localhost:8080/rest/image/fcr:versions
  • Get a listing of the resources versions
    curl -i http://localhost:8080/rest/image/fcr:versions
    • Notice the UUID of the versioned resource is returned in the listing
