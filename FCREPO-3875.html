Description

Archive groups should have additional documentation created around them in order to let users know about their potential downsides in Fedora 6. Notably, versions of an object in OCFL are immutable, and purging a resource from an Archive Group results in a state where Fedora may say the resource doesn’t exist even though it still exists in OCFL.

A few notes:

  • When this ticket was created, Archival Groups could have tombstones of resources purged. This will no longer be allowed and Fedora will return a 405.
    • This is documented in the Delete vs Purge page: https://wiki.lyrasis.org/display/FEDORA6x/Delete+vs+Purge
  • I added an additional note about this to the https://wiki.lyrasis.org/display/FEDORA6x/Glossary#Glossary-ArchivalGroupag as well
  • There may be other issues to document around archival groups but this ticket was in relation to issue brought about and resolved by https://fedora-repository.atlassian.net/browse/FCREPO-3881, https://fedora-repository.atlassian.net/browse/FCREPO-3882, and https://fedora-repository.atlassian.net/browse/FCREPO-3883
