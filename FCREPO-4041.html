Description

Following on https://fedora-repository.atlassian.net/browse/FCREPO-4032 do we need to escape the _ and % symbols for simple search? Does simple search do any LIKE queries?

Comments (3)

Ben Pennell, 2025-11-05 21:06 UTC

There are three parameters in the simple search that use LIKE some of the time. Fedora id, mimetype, and rdf type. For all three fields, LIKE is only used if a {} is present in the input, otherwise an equal operator is used. In all cases, the {} is converted to a % for the sql query.

For Fedora ID and mimetype, underscores in the user input of the search form are escaped prior to running the query, while they are not for rdf type. If you happen to include both * and % in your input, then both with act as wildcards.

The behavior is a little odd, and not advertised on the simple search page, but overall I don’t think it’s likely to cause users problems since the LIKE is only activated when a {} is present in the input. We could clean things up to only allow {} operates thought for consistency, and possibly advertise it, but I don’t think it’d rise to the level of being a performance question.

Ben Pennell, 2025-11-06 16:34 UTC

We will take the approach of escaping underscores and percents in these fields, only allowing * for triggering wildcards.
