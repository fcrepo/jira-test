Description

Create subset of production-like ICPSR data in development environment. Test various import-export scenarios; e.g.,

  • export entire repository; wipe repository; import entire repository
  • export single object; delete from repository (including tombstone); import object
  • export subset of objects based on membership predicate; delete from repository (including tombstones); import objects

The following instructions may be helpful in running the import/export utility:

  1. Download the utility:
    https://github.com/fcrepo4-labs/fcrepo-import-export/releases
  1. See Readme for running the import/export utility:
    https://github.com/fcrepo4-labs/fcrepo-import-export/blob/master/README.md
  1. Have a running Fedora
    If you do not have a Fedora to test with, you may want to start up the "one-click run":
    https://wiki.duraspace.org/display/FEDORA4x/Quick+Start#QuickStart-One-ClickRun

Esmé Cowles, 2017-05-26 14:09 UTC

Harshakumar Ummerpillai, You probably need to use a more recent build of the import utility to import without binaries.  You can download a current master build from: https://s3.amazonaws.com/f4-artifacts/fcrepo-import-export-0.1.1-SNAPSHOT-0e42348f.jar

If you want to increase the logging, you can add the parameter "-Dlog.fcrepo.importexport=DEBUG".
