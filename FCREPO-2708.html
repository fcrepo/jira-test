Description

Allow creation of historical mementos of binaries using the body (when applicable), datetime and other standard headers for binary creation. This will only create a memento of the binary, not of its description.

If no content type was provided, request is rejected with 415. If no body or external content was provided, then a 0 byte binary memento is created.
