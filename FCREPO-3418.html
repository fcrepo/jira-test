FCREPO-3418 Make PathNotFoundException an uncaught exception

TypeImprovement
StatusOpen
PriorityMinor
ReporterBen Pennell
Created2020-09-10 14:50 UTC
Updated2024-01-11 21:32 UTC
Affects versionsFedora 6.1.0
Labelseasy, housekeeping

Description

Change PathNotFoundException to an uncaught exception, and delete PathNotFoundRuntimeException. In almost every case, where it is thrown it is wrapped in

try {
...
} catch (final PathNotFoundException e) {
    throw new PathNotFoundRuntimeException(e);
}
