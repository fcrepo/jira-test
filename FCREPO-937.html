Description

Flow of adding a set of triple through RI:
1. RI receives set of triples
2. RI wraps the iterator of the received set with a localizing filter
3. RI passes wrapped iterator to trippi
4. ConcurrentTripleStoreWriter iterates through all items in iterator adding to a List<Triple> of default size
5. ConcurrentTripleStoreWriter calls another public method to add the list

The TripleStoreWriter and UpdateBuffer interfaces should be changed to accept Collection<Triple>, or have methods added to accept Set<Triple>.
