With the latest release of Jena 3.1.1 (Fuseki 2.4.1), there is now support for an embedded Fuseki2 server. See http://jena.apache.org/documentation/fuseki2/fuseki-embedded.html

Rather than simply stop using the EmbeddedFusekiServer (i.e. v.1), the integration tests should be updated to use the latest FusekiEmbeddedServer (i.e. v.2).
