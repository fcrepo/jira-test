Description

As reported by Morten Grouleff on the developers mailing list (http://sourceforge.net/mailarchive/forum.php?thread_name=48FD731D.9050305%40trifork.com&forum_name=fedora-commons-developers):

"When doing concurrent ingests we have experienced the occasional ingest-error. Not that many on Linux systems. but quite a few on Windows systems. We did a bit of debugging and discovered the following temporary file naming collision issue, which is indeed easy to trigger on Windows, as the resolution of System.currentTimeMillis() is 16ms. The fix is to use the thread-safe File.createTempFile() function. "
