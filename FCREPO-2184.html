Description

This task is to ensure that RDF prefixes that are defined in PUT and POST requests as new Containers are registered within Fedora.

For example, the following request should result in the registration of both the 'pcdm' and 'bibo' prefixes.
— body.ttl
@prefix pcdm: <http://pcdm.org/models#> .
@prefix bibo: <http://purl.org/ontology/bibo/> .

<> a pcdm:Object ;
bibo:shortTitle 'Fedora4 Site Initialization Page' .
—
Request:
> curl -i -XPUT -H"Content-Type: text/turtle" --data-binary @body.ttl localhost:8080/rest/test

Note: When this ticket is completed, the following wiki page should be updated: https://wiki.duraspace.org/display/FEDORA4x/Best+Practices+-+RDF+Namespaces

Comments (1)

Peter Matthew Eichman, 2018-10-01 15:47 UTC

The desired behavior appears to be implemented. Creating resources using POST and PUT with text/turtle bodies with defined prefixes resulted in those prefixes being registered in the repository. Furthermore, the documentation for 5.x has been updated to reflect this behavior: https://wiki.duraspace.org/display/FEDORA5x/Best+Practices+-+RDF+Namespaces

Note, however, that depending in the outcome of FCREPO-2785 Closed , this may no longer be of as much concern.
