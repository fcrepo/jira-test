Description

Restore the fcr:batch REST endpoint for doing batch operations. This would be particularly helpful for reducing the number requests necessary to build complex objects, which should improve performance and concurrent editing robustness.

The last release of Fedora that had the fcr:batch functionality was 4.0.0-beta-03: https://github.com/fcrepo4/fcrepo4/blob/fcrepo-4.0.0-beta-03/fcrepo-http-api/src/main/java/org/fcrepo/http/api/FedoraBatch.java
