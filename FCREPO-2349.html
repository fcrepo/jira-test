Description

When I've set ebucore:filename directly in my ruby code, a download of an object has this URI appended to its filename. e.g. `b10410557_006.tif ^^ http---www.w3.org-2001-XMLSchema#string`

I don't see this in fedora 4.5.1; am no longer running 4.6 anywhere so I can't say whether it's there.

This appended string makes it so Mac and Windows OSes cannot choose a default application to open the file, so it's a bit of a usability issue.

Any sort of workaround would be appreciated; once I have these values in there is there something I can do to change each of them so they don't come out this way?

Alternately, workarounds as they're going in via hydra/sufia would also be appreciated; here's the code I'm using:
https://github.com/projecthydra/sufia/commit/bb3017d7ebc3ffe8ce9c5825c838faa64a050a9d
