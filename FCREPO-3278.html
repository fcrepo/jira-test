Description

I tried creating an archival group with

curl -i -ufedoraAdmin:fedoraAdmin -H"Slug: test1" -H'Link: <http://fedora.info/definitions/v4/repository#ArchivalGroup>;rel="type"' -H"Content-type: text/turtle" -XPOST http://localhost:8080/rest

and then creating a child object with

curl -i -ufedoraAdmin:fedoraAdmin -H"Slug: child1" -H"Content-type: text/turtle" -XPOST http://localhost:8080/rest/test1

Then I stopped and restarted the server and tried to delete the child object with

curl -ufedoraAdmin:fedoraAdmin -i http://localhost:8080/rest/test1/child1 -XDELETE

and got
