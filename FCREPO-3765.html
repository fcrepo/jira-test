Description

Fedora logs a message like "Rolling back storage session <guid>" when it cleans up expired sessions. This can be somewhat confusing because any read operation will create a session that will eventually be cleaned up like this. The log makes it sound like there is something wrong.

Cleaning up expired read-only sessions should not produce an INFO log.
