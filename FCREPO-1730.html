Description

The fcrepo-audit-triplestore module does not deploy correctly in karaf. This is due to upstream changes in the use of RDF parsing libraries, particularly since the resolution of https://jira.duraspace.org/browse/FCREPO-1667.

That ticket involved replacing fcrepo-camel's RDF processing facility with jena (moving away from clerezza). Doing so, however, left the fcrepo-audit-triplestore with missing transitive dependencies. This is a ticket to refactor the RDF processing to use Jena, too.
