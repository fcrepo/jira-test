Comments (3)

Michael Ritter, 2022-10-13 19:28 UTC

Looking at ocfl-java, there is a flag we can pass in for validating the inventory when reading so this should mean all we need to do is add a flag when starting Fedora for this.

My idea for implementing this was to have a separate Bean for the ReindexService so that other operations will still validate as normal. However, the SearchIndex update at the end of the reindexing can fail as it doesn’t know about any of the Reindexing specific flags. Perhaps having a way to supply the non-validating OcflRepository to the SearchIndex would make this work, though it’s a few layers deep when it gets used (SearchIndex → ResourceFactory → PersistentStorageSessionManager) so the OcflRepository would have to be passed to each.

Michael Ritter, 2022-11-14 20:39 UTC

Talking about this today we decided to have this be pretty simple instead of trying to re-enable verification after the rebuild is complete.
