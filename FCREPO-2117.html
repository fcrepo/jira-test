FCREPO-2117 Older versions are having pointers to newer versions

Affects versionsFedora 4.6.0

Description

Create a container structure like this
/rest/project/inner1/inner2/inner3

  • Create a version V1 for /rest/project/inner1/inner2/inner3
  • Create a version V2 for /rest/project/inner1/inner2
  • Create a version V3 for /rest/project/inner1
  • Create a version V4 for /rest/project
  • Create a version V5 for /rest/project/inner1/inner2/inner3

Now traverse the fcr:versions path from /project/fcr:versions/V4
You will eventually get to /rest/project/inner1/inner2/fcr:versions/V2

And if you review the contents within this path it will show
ldp: contains
http://fedoradev0.icpsr.umich.edu:8097/fedora/rest/project/inner1/inner2/inner3/fcr:versions/V5

Correct value should have been the version V1.

Benjamin Armintor, 2016-08-11 15:09 UTC

In this example there is no named version V1 of /project; that subtree only has one named version: V4.

In V4, the content of /project/inner1/inner2/inner3 is whatever the canonical content was at the time V4 was minted- not necessarily any named version of the /project/inner1/inner2/inner3 subtree. I think it is a bug to present named versions in those subtrees at all: they should simply list /project/fcr:versions/V4/inner1/inner2/inner3
