FCREPO-3881 Disallow DELETE of tombstone of objects in an Archival Group

Description

Currently you can delete an object in an Archival Group, you can also delete the tombstone. Because an Archival Group part is inside the Archival Group’s OCFL object it is not purged. So PUTting at that URI causes the version history to also show the versions from before the purge.

This ticket is to return a 405 Method Not Allowed when trying to purge the tombstone.
