FCREPO-3386 Bag import failure when directory references '.'

Description

When using the import-export-utility, the utility will fail to import a bag when the directory passed in is of the form './path-to-bag'. When using a relative path like this, the path's representation looks like /storage/bags/./path-to-bag which causes a MaliciousPathException to occur when the bagit-java library attempts to read the bag.
