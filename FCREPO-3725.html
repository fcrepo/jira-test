FCREPO-3725 Fedora deadlocks when the number of active requests exceeds the number of pooled db connections

Description

Fedora deadlocks when there are more concurrent requests than db connections in the pool. This is because it needs an additional db connection to create rdf types outside of the main request transaction. If there are no available connections, then none of the requests can complete.
