Description

When both fcrepo-audit and audit-triplestore are enabled, two extra events are created for each event:

1. The event for the creation of the audit node created by fcrepo-audit
2. The event for the audit container lastModified being updated

InternalAuditor has some logic to ignore these updates:

https://github.com/fcrepo4-labs/fcrepo-audit/blob/master/src/main/java/org/fcrepo/audit/InternalAuditor.java#L157

audit-triplestore should ignore these too.
