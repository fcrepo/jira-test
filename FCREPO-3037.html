Description

When someone runs this against fedora, they still get all the user managed triples:

`curl -H "prefer:return=representation; omit=\"http://www.w3.org/ns/ldp#PreferMinimalContainer\"" http://localhost:8080/fcrepo510/rest/BasicContainer/BasicContainer1 -ufedoraAdmin:fedoraAdmin`

With the `PreferMinimalContainer` in the `omit` list, one would expect that the user managed triples would be excluded.   Fedora is only paying attention to `PreferMinimalContainer` when it is in the `include` list.
