Description

When a client is allowed to perform acl:Append operations on an LDP-NR all DELETE, POST, and PUT requests must be denied.

An acl:Append operation applies when the acl governing a particular LDPR contains a "<> acl:mode acl:Append" triple.

c.f. https://fcrepo.github.io/fcrepo-specification/#append-ldprs : 5.7.3

Danny Bernstein, 2018-05-04 20:28 UTC

Once https://jira.duraspace.org/browse/FCREPO-2717 is finished,  this issue should be complete as well since DELETEs are currently disallowed for all resources where acl:Append applies.  Same is true for PUT, which is currently allowed in both the LDP-NR and LDP-RS cases when the resource does not exist. Completion of 2717 will ensure that it is denied when resource exists.   Finally POST on an LDP-NR is rejected already whether or not acl:Append applies.  The work of this ticket will likely be to add any missing integration tests.
