Description

Take an initial pass at the implementation of the OCFLPersistentStorageSession.  The OCFLPersistentStorageSession is responsible for maintaining the association between a session id,  the fedora resource  and an OCFLSession which should operate on a single OCFL resource.  So for each OCFLPersistentStorageSession there are one or more open OCFLSession.  On commit,  the OCFLPersistentStorageSession loops through the ocfl sessions and commits each one.
