Description

There are now new transaction related classes representing the new order.  FedoraTransaction, FedoraTransactionImpl, FedoraTransactionManager, and FedoraTransactionManagerImpl.  These will replace the older FedoraSession.  We may want to move some of the methods (especially related to expiration) to the FedoraTransaction.  

The task here is to determine what will need to change given the new approach to transactions.  Some interfaces will need to be removed (such as BatchService possibly), others will change (using FedoraTransaction instead of FedoraSession) and some may need to be added. 

The outcome of this Jira will be a series of JIRAs detailing the specific refactoring tasks to be done and order in which the should be performed.
