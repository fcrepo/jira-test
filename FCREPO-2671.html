FCREPO-2671 By default, minted identifiers should not have any pairtree structure

Description

Starting with Fedora 5.0.0, newly minted identifiers should create not contain any pairtree structure. In other words, the current behavior when you perform a POST on resource http://localhost:8080/rest/resource would be to create a new resource such as
http://localhost:8080/rest/resource/e9/cf/b6/4a/e9cfb64a-595c-4425-954c-98c8dfa251e4

In 5.0.0 by default the created resource path will look as follows:

http://localhost:8080/rest/resource/e9cfb64a-595c-4425-954c-98c8dfa251e4
