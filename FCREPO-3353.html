Description

The modified and created dates for the resource should be searchable via the /fcr:search endpoint.  These fields should support >, >=, <=, and < operators.

You should be able to search between two modified dates using the following urlencoded conditions:
/rest/fcr:search?condition=modified%3E2020-01-01&condition=modified%3C2020-07-01
