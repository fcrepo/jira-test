Description

Currently the fedora:TimeMap RDF type is present as part of the TimeMap's RDF.  It should use a memento standard triple instead.  The task of this ticket is to add the memento:TimeMap rdf type to the RDF alongside the old fedora:Timemap (to preserve backwards compatibility).
