Description

This task is to change the 500 response that currently occurs in the following scenario to a '406 Not Acceptable'.

To reproduce:

  1. Create a versioned resource
    curl -i -XPOST -H "Slug: obj" -H "Link: <http://mementoweb.org/ns#OriginalResource>; rel=\"type\"" "http://localhost:8080/rest/"
  1. Request the resultant TimeMap with a bad "Accept" header
    curl http://localhost:8080/rest/obj/fcr:versions -H"Accept: application/format-junk"

> Response: 500

Note: Non-TimeMap resource respond with the correct 406.
Also, the above scenario responds correctly when using "Accept: junk".
