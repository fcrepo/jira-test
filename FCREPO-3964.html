Description

We are seeing cases of reindexing failing due to transaction timeouts during the membership indexing step. The repository with this issue might not even have any direct or indirect containers, but more info is needed. We should investigate the membership indexing code to try to determine what would cause these timeouts, if we need to split up our transaction usage, and if there are other potential performance bottlenecks with membership reindexing.
