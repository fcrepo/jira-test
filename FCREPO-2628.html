Description

In https://jira.duraspace.org/browse/FCREPO-2608, the userAgent URI was introduced into the session. The HTTP user agent header definition is at odds with the way the term is being used here:

According the http spec the user-agent header is used for identifying the software agent acting on behalf of the user (https://www.w3.org/Protocols/rfc2616/rfc2616-sec14.html#sec14.43). In FedoraSession we are using it to mean a URI representation of the user proper.

To prevent confusion I propose changing the member to "userURI".
