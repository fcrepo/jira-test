Description

When the target version is 6+, add the ability to turn some objects into archival groups during the upgrade process. For our use case, this could be based on a list of RDF types. If a resource contains any of the specified RDF types, then it gets migrated as an AG and any children ldp:contained by it go into the same AG. If a resource that is contained by an AG in this way also has one of the specified RDF types, it has no affect.
