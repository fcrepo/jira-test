Description

Currently the property "fcrepo.persistence.defaultDigestAlgorithm" is pulled directly from the System.getProperties in ContentDigest.  I should be refactored so that it is set in one of the configurations - probably FedoraPropsConfig like the other general fedora properties.  Achieving this goal may require some refactoring as ContentDigest is a static class as is the class that references the DEFAULT_DIGEST_ALGORITHM, namely OclflPersistentStorageUtils.
