Description

Investigate existing interfaces to determine what steps would be necessary to support persisting binaries, containers and AGs to a filesystem backend, independent of some of the format specific concerns like OCFL. This could include changes to kernel interfaces or planning for how kernel impls would interact with the persistence layer.

Example possible persistence layouts can be found here:
https://gist.github.com/bbpennel/3dd2ec19d3545e0417071958177baa93

Currently the .fcrepo sidecar approach seems to be preferred, but it is still an open discussion.

Some concerns to pay attention to:

  • Separating server managed details from user provided triples
  • How the binary resources will carry details about binaries, but delegate persistence to the layer below.

The outcome of this could be followup tickets and/or a document describing the approach.
