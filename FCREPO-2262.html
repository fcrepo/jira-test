FCREPO-2262 The mime type text/csv should not be treated as RDF by fedora.

Description

curl -XPUT "http://localhost:8080/rest/sample" --data-binary @sample.csv -H "Content-Type: text/csv"

Once you PUT that CSV file you end up with an RDFSource Container that has no unique properties, and a bunch of odd (not even accessible) resources in ".well-known/genid". And the following registered namespaces:

PREFIX ns004: <http://localhost:8080/rest/sample#Column%201>
PREFIX ns003: <http://localhost:8080/rest/sample#Column%202>
PREFIX ns002: <http://localhost:8080/rest/sample#Column%203>
PREFIX ns001: <http://localhost:8080/rest/sample#Column%204>

For me, this was not the expected behavior. Could we just treat "text/csv" as non-RDF?
