Description

Binaries are getting misidentified as containers in the WebACFilter. This is in the test for whether to allow a POST request: https://github.com/fcrepo4/fcrepo4/blob/21378155eb620c31506ffbc5e5749ab4875de58c/fcrepo-auth-webac/src/main/java/org/fcrepo/auth/webac/WebACFilter.java#L199

The condition resource(repoPath) instanceof FedoraBinary is always returning false, even if the resource is a binary.
