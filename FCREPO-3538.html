FCREPO-3538 Wildcard searches and ids containing *

Updated2024-01-11 21:38 UTC
Componentscore, f4-core
Affects versionsFedora 6.0.0

Description

The search code does a string replace of * to % when constructing search queries. This makes it impossible to do an exact match search for an id that contains a * in it.
