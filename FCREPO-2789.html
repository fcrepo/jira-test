Ben Pennell, 2018-11-13 23:41 UTC

Address immediately

  • deprecate MOVE and COPY
  • support for creation of external content
  • helper for Want-Digest on GET/HEAD
  • helper for Accept-Datetime on GET/HEAD (Should this be scoped to a GetMementoBuilder subtype?)
  • POST/PUT helper for setting interaction model, constants for types from spec
  • POST/PUT add optional "acl" relational
  • PATCH should optionally allow for setting Content-Type
  • Add PostMementoBuilder, which extends PostBuilder and adds helper for memento-datetime header
  • Update dependencies

Suggested

  • Provide helpers/constants for specification defined GET Prefer headers
  • Add helpers for State Token headers
  • helper for Cache-Control: no-cache, as it is recommended in the spec for Want-Digest
  • General method for adding Link header to POST/PUT/PATCH
  • Some work to improve support for WebAC. Currently the client only does basic auth, could add support for an auth header.
  • Flag for whether to follow redirects, in the case of redirect ext content
  • GetTimemapBuilder, which defaults to "Accept: application/link-format"

Possible extras

  • More response method helpers, such as getting the ACL Location,
       * Or constants for response headers, like Accept-External-Content-Handling
       * Helper method for getting types, and/or hasInteractionModel
  • Constants for versioning concepts
      * http://mementoweb.org/ns#TimeGate
      * http://mementoweb.org/ns#TimeMap
      * http://mementoweb.org/ns#OriginalResource
      * http://mementoweb.org/ns#Memento
  • Link rels, original timegate timemap (acl)
  • Constants for link header rels
       * http://www.w3.org/ns/ldp#constrainedBy
       * http://fedora.info/definitions/fcrepo#ExternalContent
       * acl
       * original
       * timegate
       * timemap

Fcrepo community impl extension module

  • Add support for transactions (we have done so locally at unc, but its ugly and we can probably wait for sidecar spec)
