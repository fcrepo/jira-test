Description

When a client is allowed to perform acl:Append operations on an LDP-RS
1) a PUT request on an existing resource must be denied with a 403 Forbidden response
2) a PUT request to create a new resource must be allowed if the implementation supports creating resources using PUT (see: 3.6.3 Creating resources with HTTP PUT)

c.f. https://fcrepo.github.io/fcrepo-specification/#append-ldprs : 5.7.1

An acl:Append operation applies when the acl governing a particular LDP-RS contains a "<> acl:mode acl:Append" triple.
