Description

As we move through the memento implementation, FedoraVersioningIT is in the process of replacing FedoraVersionsIT. This ticket is a short list of refactorings to tidy up the integration tests.

1. Move any applicable tests in FedoraVersionsIT to FedoraVersioningIT
2. Remove FedoraVersionsIT
3. Move any versioning related tests from FedoraLdpIT to FedoraVersioningIT
4. Move methods from AbstractVersioningIT into FedoraVersioningIT and remove AbstractVersioningIT.
5. Make FedoraLdpIT inherit from AbstractResourceIT.
