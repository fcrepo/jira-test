Description

The import export utility should be able to export BagIt bags into a serialized format when they have a profile which specifies serialization is required. This should support zip, tar, and tar+gzip initially.

 

Work can be done after FCREPO-3205 Closed as serializing a bag after the fact does not change the structure of the bag itself, so if it is required a user can currently do it after the fact.
