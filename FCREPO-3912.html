Description

With https://github.com/fcrepo-exts/fcrepo-docker/pull/17 the naming scheme for the docker images has changed.

Docker image built the the pipeline of https://github.com/fcrepo/fcrepo/ should be tagged with the following tags:

  • fcrepo/fcrepo:MAJOR-tomcat9 (e.g. 6-tomcat9)
  • fcrepo/fcrepo:MAJOR.MINOR-tomcat9 (e.g. 6.4-tomcat9)
  • fcrepo/fcrepo:MAJOR.MINOR.BUGFIX-tomcat9 (e.g. 6.4.1-tomcat9)
