FCREPO-2377 Sort triples into graphs

TypeImprovement
StatusOpen
PriorityMinor
ReporterA. Soroka
AssigneeAaron Birkland
Created2017-01-05 17:45 UTC
Updated2021-09-17 17:42 UTC
Componentsf4-camel

Description

We could provide a configuration option to sort indexed triples into named graphs in the triplestores in use. The obvious pattern would be one graph per resource, with the graph URI taken straight from the resource URI.

Comments (2)

Aaron Birkland, 2017-01-05 18:18 UTC

I have some local in-progress code that does this as part of fcrepo4-labs/fcrepo-api-x#94, which I'd be happy to refactor into a PR to fcrepo-camel, since there seems to be a broader interest in doing so.

On a related note, the existing fcrepo-camel-toolbox SparqlUpdateProcessor currently relies on the fact that all triples share the same subject. For resources that contain hash URIs, it relies on the fact that a given fedora impl emits messages for the resource and all hash resources defined in it. The messaging spec doesn't (and probably won't?) specify this behavior with respect to hash URIs, so it's possible that the default SparqlUpdateProcessor behavior may need to be revisited at some point. A named graph approach where graphs are named by fedora resource URIs would be a bit more straightforward in this regard.

A. Soroka, 2017-01-09 19:11 UTC

I think that (refactoring for fcrepo-camel ) would be really useful.
