Description

publlic access currently requires authn as per https://jira.duraspace.org/browse/FCREPO-2632

Fedora should be configurable to allow anonymous access (i.e. on a read-only basis) to resources, whenever allowed by WebAC. One possible approach is to assign a single webac agent URI (e.g something like http://fedora.info/local-user#Anonymous) in the absence of any user principal provided by authn.

Comments (2)

Aaron Birkland, 2018-08-16 16:03 UTC

Right now, Fedora will accept un-authenticated requests and do the Right Thing (allow access if it has been granted to "evertbody" as per webac).  However, authentication is presumed to be external (container auth, or shib proxy, etc)

This ticket has been re-scoped to documentation.  In particular, document that:

  • authn is external to the repository right now
  • The repository will accept un-authenticated requests and apply webac policies as expected
  • Therefore, Fedora is OK with you expose some fcrepo resources in an un-authenticated manner, but cannot currently help you do that (as it is external)

That being said, the Shiro architecture brings the possibility of bringing authn realms into shiro.  Long-term, this opens the door to allowing Fedora to control the presence or absence of authn for individual resources
