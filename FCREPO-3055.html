Description

The inclusion of UWM ocfl-java https://github.com/uW-Madison-Library/ocfl-java introduced a dependency clash on commons-codec. We currently require 1.6 in the pom.xml but ocfl-java requires 1.13. As migration-utils only uses the library for a simple Base64 output, I suggest we upgrade the local requirement to match ocfl-java.

  • Update pom.xml to require commons-codec 1.13 instead of 1.6
