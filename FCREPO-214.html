Description

In addition to the various export contexts defined in DOTranslationUtility (INTERNAL, MIGRATE, PUBLIC, ARCHIVE), add support for a new export context (ZARCHIVE) that creates a ZIP archive of an object, with all inline and managed datastreams as individual files in the archive.

Use Atom as the initial, proof-of-concept, manifest format.
