Description

Currently simple search is piggy backing on the containment index.  While this works pretty well for fedora Id queries, it won't work as well when bringing on other fields such as created date, mimetype, size, etc.  

The task here is to move the simple search into its own table.  It might be populated by the rebuild routine on startup.  For ongoing updates, it should be populated by an event listener.
