FCREPO-805 Installer does not check for empty $CATALINA_HOME directory when using the included tomcat

Description

It is possible to configure the installer to use a $CATALINA_HOME directory outside of $FEDORA_HOME when using the Fedora-supplied Tomcat.

The installer checks, and warns, for an empty $FEDORA_HOME directory, but does not check for an empty $CATALINA_HOME directory when using the included Tomcat. The installer silently over-writes existing files, but this can lead to eg an updated $CATALINA_HOME/webapps/fedora.war but leaving the existing $CATALINA_HOME/webapps/fedora/ folder in place - ie any existing version is effectively left in place.

Ideally when deploying to either an existing tomcat or using the included tomcat, there should be some sort of warning if (a) an existing fedora.war is present and (b) the fedora webapps directory (from a previous installation) is present, with the option to overwrite the war file (which should automatically delete the webapps directory). This should also apply to the other wars that are deployed in Tomcat.
