Description

This wouldn't affect fedora6 migrations - only PLAIN_OCFL ones.

Currently, the migrator parses out the foxml and creates .nt RDF property files. This change would instead migrate the whole foxml file into OCFL, and not create the .nt property files (all datastream content would still be migrated as normal).

Should this be an option, or just happen automatically for PLAIN_OCFL migrations?
