FCREPO-2964 PUT against existing resource and invalid interaction model should return 409

Description

According to the Fedora Specification:
https://fedora.info/2018/11/22/spec/#http-put
> Implementations may allow the interaction model of an existing resource to be changed by specification of a new LDP type in a rel="type" link in the HTTP Link header. If supported, requests should be rejected with a 409 (Conflict) response unless the new LDP type specified is a subtype of the resource's current type.

Currently, Fedora responds with a 400 status code in the scenario tested in: https://github.com/fcrepo/Fedora-API-Test-Suite/blob/f40d613dc17fcde3ff74cc9e244fbed8c8d520ff/src/main/java/org/fcrepo/spec/testsuite/crud/HttpPut.java#L74
