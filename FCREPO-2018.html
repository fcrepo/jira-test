Description

It would be convenient to be able to configure the baseUrl (repository root) value in the fcrepo-camel component in such a way that all endpoints use that URL. This would allow, for instance, the ability to expose the fcrepo component as an OSGi service used by multiple camel contexts, while allowing users to configure the fcrepo endpoint centrally.
