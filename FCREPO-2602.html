Description

Discard existing serialization and use activitystream serialization as illustrated in the spec example.
https://fcrepo.github.io/fcrepo-specification/#minimal-notification-example

Translate all existing information into its ActivityStream equivalent, where possible. Create a new ticket for any information that does not map onto ActivityStream vocabulary, or does not seem appropriate to include.

For now, use a local hash URI #agent for the actor, and populate its name with the string name of the user principal.
