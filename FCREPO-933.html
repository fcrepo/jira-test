Description

In 3.5, the FeSL Relationships attribute finder module was enhanced to allow relationship-query-based attributes; and a similar relationships attribute finder module was added for the existing XACML implementation.

As these both conform to the same XACML interface, this code should be refactored to provide a single attribute finder module, with Spring configuration.
