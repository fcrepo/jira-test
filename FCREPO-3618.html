Description

Currently, there's the target-dir option, which is where the data directory and pid/resume.txt get written. There's also the index-dir option, which specifies where the datastream index cache gets written.

Suggestion: keep the target-dir just for the data, and add a "working-dir" (or some other name) option for migration working data (datastream cache, pid/resume.txt, ...). So the datastream index cache and pid/resume.txt would be written into the directory specified by the working-dir option.

Suggestion #2: if the migration-type is PLAIN_OCFL, just use target-dir as the ocfl storage root directly, instead of creating data/ocfl-root under target-dir (those directories would continue to be written for the default FEDORA_OCFL migration type).
