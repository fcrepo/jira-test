FCREPO-1040 listDatastreams fails with NPE when a policy specifies a subset of datastreams to give access to.

Componentslegacy - FeSL
Affects versionsFedora 3.5

Environment

FeSL authn enabled, FeSL authz enabled; apia-access auth required

Description

The attached policy basically allows access to apia methods to user "public" in group "public", but only if

  • the request does not specify a datastream ID; or
  • the request specifies a datastream ID in the "permitted" list (which is only DC in the example)

When doing a listDatastreams, logging in as public, there is an NPE caused by the post-method results filtering.
