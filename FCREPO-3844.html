FCREPO-3844 Runtime filtering options for the Camel Toolbox reindexing service

TypeImprovement
StatusOpen
PriorityLow

Created2022-08-25 15:48 UTC
Updated2022-10-13 05:32 UTC
Componentsfcrepo-camel-toolbox

Description

At present, the reindexing service of the Camel Toolbox accepts only one run-time option: a JSON array of queues where reindex messages should be sent. However, it might also be helpful to support some filtering parameters to control which resources are reindexed.

Example use case: I only need to index container resources, not the binary resources within them. It would be helpful to be able to obtain only the containers from the reindex service. Perhaps filtering by resource type or interaction model could help with this.

I should note that I have found other ways of meeting my reindexing needs, so I do not have a pressing need for this improvement; I’m just opening the ticket as a note that this could be useful to others in the future, and to create a place for further discussion as needed.
