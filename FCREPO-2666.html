FCREPO-2666 HTML UI does not update properly after binary resource reversion

TypeBug
StatusOpen
PriorityMinor
ReporterDanny Bernstein
Created2018-01-24 03:49 UTC
Updated2018-02-01 23:20 UTC
Componentsf4-core
Affects versionsFedora 4.7.5

Description

Steps to reproduce (on Chrome):

1. Create a binary with fileA.jpg

2. Create version v1.

3. Update binary with fileB.jpg

4. Create version v2.

5. Click on versions link and click on v1 link.

6. Click "Revert to this Version"

7. Return to binary resource metadata page. Notice the file associated with the version fileB.jpg rather than the expected fileA.jpg. It does not appear that the version was reverted.

The problem can be resolved with a hard refresh. However a refresh should not be required.
