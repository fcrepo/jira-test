Description

I have installed fcrepo4-oaiprovider-4.2.0 on Fedora 4.2.0 (plus-rbacl-audit). I have added sets using command below.
curl -X POST http://localhost:8080/fcrepo-webapp-plus-rbacl-audit-4.2.0/rest/oai/sets -H "Content-Type: text/xml" -d @oai_set.xml -u fedoraAdmin:fedoraAdmin

Here is my @oai_set.xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<set xmlns:ns2="http://www.openarchives.org/OAI/2.0/">
<ns2:setSpec>oai-test-set</ns2:setSpec>
<ns2:setName>oai-test-set</ns2:setName>
</set>

It was working for the first set. I have added another set, oai-test-set-2 and then list the set by using oai?verb=ListSets, but the response showed only first set.

Here are my questions

  • How can I make the OAI Provider to show all sets?
  • How can I update or delete oai set?
