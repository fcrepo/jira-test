Andrew Woods, 2015-09-02 20:06 UTC

I wonder if there is an issue with the client-request flow. The following scenario works on my local install:

  • Find an image file, name it 'test.jpg'
  • Upload file with 'application/pdf' mimetype
    curl -i -XPUT -H"Content-Type: application/pdf" --data-binary @test.jpg localhost:8080/rest/image
  • Verify NonRdfSourceDescription for 'application/pdf' mimetype
    curl -i localhost:8080/rest/image/fcr:metadata
  • Verify download of image
    curl localhost:8080/rest/image -o out
  • Change mimetype
    curl -i -XPATCH -H"Content-Type: application/sparql-update" --data-binary @patch.su localhost:8080/rest/image/fcr:metadata

...Where 'patch.su' is
-----------
PREFIX ebucore: <http://www.ebu.ch/metadata/ontologies/ebucore/ebucore#>

INSERT

{ <> ebucore:hasMimeType 'image/jpeg' . }

WHERE {}
-----------

  • Verify NonRdfSourceDescription for 'image/jpeg' mimetype
    curl -i localhost:8080/rest/image/fcr:metadata|less
