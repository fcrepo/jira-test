FCREPO-626 Message digest algorithms HAVAL, TIGER and WHIRLPOOL are not supported

Addressed byFCREPO-681 Update documentation to reflect message digest algorithms that are supported

Description

The hash algorithms HAVAL, TIGER and WHIRLPOOL are currently not supported by Fedora although the documentation suggests otherwise. Out of the box JDK6 provides support for MD2, MD5, SHA-1, SHA-256, SHA-384, SHA-512. Other algorithms can be supported by plugging in a provider, like jacksum[1] as described here[2].

The alternative course of action would be to remove these checksum algorithms from the documentation and the code in fedora/server/storage/types/Datastream.java

[1] http://www.jonelo.de/java/jacksum/
[2] http://java.sun.com/javase/6/docs/technotes/guides/security/crypto/CryptoSpec.html
