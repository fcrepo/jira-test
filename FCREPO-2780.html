FCREPO-2780 GET inbound refs incomplete response

Postgres/tomcat

Description

In short, the response/output of a GET request, which includes a Prefer Header for  InboundReferences, on a resource with thousands of incoming relationships is truncated and incomplete.

 

The bulk of the description that follows was initially reported on the fedora-tech group:

https://groups.google.com/forum/#!topic/fedora-tech/U7qR4_irzTI

 

We have a resource (X) that thousands, if not tens of thousands, of other resources pointed to.

A -> X
B -> X
C -> X
D -> X
...

We performed a repo-wide update that re-assigned those relations to a different (new) resource (Y).

A -> Y
B -> Y
C -> Y
D -> Y
...

Before updating an individual resource (A,B,C,D, etc) we versioned the resource. In the end, we never deleted resource X, even though it should no longer have had any resources pointing to it.  This is just as well because the versioned resources still reference X.

Given that the versioned resources (A,B,C,D, etc.) reference resource X, a GET request on resource X (with inbound references to be included) results in only a couple of hundred of the inbound references (when thousands were expected) and the output was truncated.
