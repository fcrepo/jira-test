FCREPO-3904 Fedora admin UI not showing hash URI resources on NonRDFSources

Description

Created from Slack question (https://fedora-project.slack.com/archives/C8B5TSR4J/p1692029486878149):

Fedora 6 does support the usage of hash URIs on NonRDFSources, but they are not visible on the Admin UI (section "Other resources" is missing for NonRDFSources on the Fedora UI).

A put to <NonRDFSource-URI>/fcr:metadata that includes such HashURIs (e.g with triples like <NonRDFSource-URI>#<someHash> <somePredicate> "someLIteral") is accepted. The additional resources are returned correctly on the API.
