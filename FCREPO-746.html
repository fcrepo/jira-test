FCREPO-746 risearch queries do not support mulgara:gt and mugara:lt (but mulgara:after and mulgara:before work)

Description

The Mulgara documentation suggests that querying against a datatyping model using the predicates mulgara:gt and mulgara:lt should be possible for XSD datatype int. However these do not work, but mulgara:before and mulgara:after do work.

eg RELS-EXT:

<rdf:RDF xmlns:fedora-model="info:fedora/fedora-system:def/model#" xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#" xmlns:myns="http://www.example.org/myns#">
<rdf:Description rdf:about="info:fedora/ns:pid">
<myns:temperature rdf:datatype="http://www.w3.org/2001/XMLSchema#int">30</myns:temperature>
</rdf:Description>
</rdf:RDF>

Non-working Query:

select $object $temp from <#ri>
where
$object <http://www.example.org/myns#temperature> $temp in <#ri>
and $temp <http://mulgara.org/mulgara#gt> '10'^^<xml-schema:int> in <#xsd>

Working Query:

select $object $temp from <#ri>
where
$object <http://www.example.org/myns#temperature> $temp in <#ri>
and $temp <http://mulgara.org/mulgara#after> '10'^^<xml-schema:int> in <#xsd>
