FCREPO-1539 Stop spewing UUIDs

TypeStory
StatusClosed

PriorityMajor

AssigneeAndrew Woods
Created2015-05-14 16:55 UTC

Componentsf4-core, f4-ontology
Affects versionsFedora 4.1.1
Fix versionsFedora 4.3.0
Labelsrefine
Depends onFCREPO-1552 Remove UUID from default transform

Description

Fedora is currently publishing JCR-assigned internal UUIDs as properties of resources. It should stop doing this. The property that is used to publish this internal-only information ("fedora:uuid") should be removed from the public ontologies.
