FCREPO-1405 JCR references leaked to JMS message headers

Description

Some of the predicates passed to the JMS producer (in the org.fcrepo.jms.properties header) use the JCR namespace.

For example: http://www.jcp.org/jcr/1.0lastModified,http://www.jcp.org/jcr/1.0createdBy

These should be replaced the the http://fedora.info/definitions/v4/repository# namespace.
