FCREPO-1583 License Header should not be JavaDoc Comment

Description

The current license header as enforced by Maven License Plugin is formatted as a JavaDoc comment. This is unfortunate as it tends to confuse source code tools that work with and format JavaDoc comments.

Ralf Claussnitzer, 2015-11-02 07:14 UTC

Depends how you see it.

It is not necessary because:

  • It has no effect on functionality.
  • Smart editors usually hide header comments in a code folding block so nobody ever sees them.
  • It is not a bug. It can always be fixed by running `mvn license:format`.
  • A lot of effort would go into fixing it (although I assume merge conflicts would be extremely rare).

It is necessary because:

  • It confuses source code tools (just as mixing tabs and spaces).
  • It violates JavaDoc because /** ... */ delimiters above package declarations are for annotating packages.
  • It violates JavaDoc because "The special comments in the Java source code that are delimited by the /** ... */ delimiters. These comments are processed by the Javadoc tool to generate the API docs.". License header are no API documentation.

As I see it, having proper file header comments is part of coding style. That's why I put `Documentation`, `minor` and `housekeeping`.
