FCREPO-3388 unify transaction/session language

TypeImprovement
StatusOpen
PriorityMinor
ReporterPeter Winckles
Created2020-07-22 20:01 UTC
Updated2021-07-07 17:07 UTC
Componentsf4-core
Affects versionsFedora 6.0.0
Labelsfcrepo-6.1.0

Description

Various parts of the code base refer to "transactions" as either transactions or sessions. There is a one-to-one relationship between API transactions and persistence sessions, and the transaction id is used as the persistence session id. Perhaps the language can be unified to avoid confusion.
