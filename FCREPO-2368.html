Danny Bernstein, 2017-05-16 05:49 UTC

So  both having reviewed the previous pull request  and having played a bit with the tool I would suggest that we consider the following changes: 

  1.  Standard out shows runtime summary of the tool.  
    1. It should answer at a glance: 
      1. Configuration information
      2. Progress
        1. % complete
        2. # of success
        3. # of failures
      3. estimated time to completion (if possible) 
    2. It should print updated stats every 10 seconds. 
  2. File-based log
    1. includes everything from standard out as well as  all log messages you are showing in verbose mode - ie resource level info with details (rel, orig, dest, and success/failure info and details) plus any warnings or errors. 
    2. Turning on -v would log debug level log messages such as http requests and responses, retries, etc. 
  3. All log messages would include timestamps,  message level,  file and line information in addition to messages for easier debugging.
