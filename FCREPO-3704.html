FCREPO-3704 fcrepo-java-client should close internal instance of CloseableHttpClient

Description

org.fcrepo.client.FedoraClient internally uses a instance of org.apache.http.impl.client.CloseableHttpClient to execute requests.

 

The development tutorial for HttpClient 4.5.x states in section 1.2.2 (https://hc.apache.org/httpcomponents-client-4.5.x/current/tutorial/html/fundamentals.html#d5e217):

"When an instance CloseableHttpClient is no longer needed and is about to go out of scope the connection manager associated with it must be shut down by calling the CloseableHttpClient#close() method."

 
Therefore FedoraClient should implement java.io.Closable to correctly shutdown the connection manager associated with the HttpClient.
