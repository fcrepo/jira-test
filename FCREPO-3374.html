Description

This bug can be observed by running the following script:
```
#!/usr/bin/bash

x=0;
r="http://localhost:8080/rest/";
while true;
do x=$(($x + 1));
r=`curl -s -H"Slug: $x" -XPOST $r`;
echo "r = $r";
done
```

We will likely want to catch PersistentStorageExceptions and send an appropriate response code to the client... instead of a stacktrace.
