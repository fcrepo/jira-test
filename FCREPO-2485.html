Situ, Longshou, 2017-05-25 16:35 UTC

Danny Bernstein I think you can replicate it in the following steps with the plan patent dataset (https://github.com/fcrepo4-labs/fcrepo-sample-dataset/blob/master/plantpatents/plants.tar.gz):

  • Restore the datatset to fedora:
    $ curl -i -X POST --data-binary "1473315261896-0" "http://localhost:8080/fcrepo/rest/fcr:restore"
  • Export the dataset with binary excluded:
    $ java -Dfcrepo.log.importexport=DEBUG -jar bin/fcrepo-import-export-0.1.1-SNAPSHOT.jar -a -d data_1 -m export -r http://localhost:8080/fcrepo/rest
  • Verify the exported resources with the verification tool:
    fcrepo-verify -l 1-export-log.txt -g DEBUG -v ./importexport.yml

./importexport.yml:
mode: export
predicates: http://www.w3.org/ns/ldp#contains
resource: http://localhost:8080/fcrepo/rest
source: http://localhost:8080/fcrepo/rest
dir: /Users/lsitu/Documents/Fedora_Import_Export/data_1
