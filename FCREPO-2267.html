FCREPO-2267 XHTML output isn't really XHTML

Description

When Fedora is asked to produce XHTML via Accept: application/xhtml+xml, the response claims to have a content-type of application/xhtml+xml, but the body of the response is plain HTML.

If someone really needs XHTML, then we should add support for it, but until then, we should remove the illusion of support.
