Description

Currently the Containment Index only preserves containment for the head state of a resource. This means that when getting a past version (a Memento) you do not get the correct containment as it appeared at that moment in the past.

This ticket is to modify the Containment Index implementation to use the pattern established in the Membership service to track all past versions of containment and provide the correct ones when viewing a Memento and the Original Resource.
