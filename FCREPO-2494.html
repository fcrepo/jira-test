components and steps to replicate:
Dataset: plan patent (https://github.com/fcrepo4-labs/fcrepo-sample-dataset/tree/master/plantpatents)
Import/Export version: fcrepo-import-export-0.1.1-SNAPSHOT (master @d2c9a17)
Fedora version: fcrepo-webapp-4.8.0-SNAPSHOT-jetty-console-a07a1a46.jar

  • Restore the plan patent dataset into http://localhost:8080/fcrepo/rest:
    $ curl -i -X POST --data-binary "1473315261896-0" "http://localhost:8080/fcrepo/rest/fcr:restore"
  • Export:
    $ java -jar bin/fcrepo-import-export-0.1.1-SNAPSHOT.jar -m export -b -d data -r http://localhost:8080/fcrepo/rest
  • Import:
    $ java -jar bin/fcrepo-import-export-0.1.1-SNAPSHOT.jar -m import -b -d data -r http://localhost:8686/fcrepo/rest
