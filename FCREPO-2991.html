FCREPO-2991 Cannot create resources with most identifiers containing :'s

Description

In Fedora 5 (as well as 4) when attempting to create a resource with a prefix containing ":", Fedora fails to create the resource if the prefix is not already known to the internal namespace registry. Including the prefix in the namespace prefix config file does not make a difference.

This seems counter to the intent of Fedora 5 to no longer use the internal Fedora/modeshape namespace registry in client interactions. Ideally, you would be able to create resources with prefixes, so long as they were not reserved, such as "fcr:".

 

 

curl -XPOST http://localhost:8080/rest/ -H"Slug: abc:123"
< HTTP/1.1 400 Bad Request
Prefix abc has not been registered
