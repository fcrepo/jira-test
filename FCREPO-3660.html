FCREPO-3660 Prefer HTTP headers not working on TimeMap (versions) endpoint

TypeBug
StatusOpen
PriorityMinor
ReporterScott Prater
Created2021-03-01 21:27 UTC
Updated2021-05-05 18:05 UTC
Componentsf4-core
Affects versionsFedora 6.0.0

Environment

Linux (CentOS 7), embedded jetty server

Description

HTTP Prefer: header omits and includes do not function on the fcr:versions endpoint as they do on plain resource endpoints.

Example PreferContainment results on resource (works):

$ curl -H "Accept: application/rdf+xml" -H "Prefer: return=representation; omit=\"http://www.w3.org/ns/ldp#PreferMinimalContainer\"; include=\"http://www.w3.org/ns/ldp#PreferContainment\"" "http://localhost:8080/rest/myresource"

    xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#"
    xmlns:ldp="http://www.w3.org/ns/ldp#" > 
  <rdf:Description rdf:about="http://localhost:8080/rest/myresource">
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/TECH0"/>
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/RELS-INT"/>
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/RELS-EXT"/>
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/MASTER0"/>
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/DC"/>
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/AUDIT"/>
    <ldp:contains rdf:resource="http://localhost:8080/rest/myresource/ADMINMD"/>
  </rdf:Description>
