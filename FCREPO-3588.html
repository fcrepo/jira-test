Description

This bug can be reproduced by:

  • Start f6
  • Try to create a container:
    > curl -i -XPUT --data-binary @data.json -H"Content-Type: application/ld+json" localhost:8080/rest/box
  • Where the content of "data.json" is:
    ``` { "@context": "https://json-ld.org/contexts/person.jsonld", "@id": "http://dbpedia.org/resource/John_Lennon", "name": "John Lennon", "born": "1940-10-09" }

    ```

The error response is:
> 400 Bad Request
> RDF was not parsable: loading remote context failed: info:fedora/https://json-ld.org/contexts/person.jsonld

The issue appears to be related to prepending the the json-ld context URL with "info:fedora"
