Kevin S. Clarke, 2014-12-04 17:42 UTC

Andrew Woods and Situ, Longshou If you want to test the Grinder spin up in AWS, I've update the README in the above repository, now, to link to some step by step instructions (which pick up from the point the README ends (i.e., you'll configure the build as described in the README first)). One thing that isn't mentioned, for testing from your machine, is to make sure your AWS security group you choose to use has ports 8080 and 6373 open to your machine's IP. The ingress rules that allow the Grinder agents to connect to the console are automatically added in the startup (and removed at shutdown) of the agents, but I haven't configured the fedora script to open up 8080 on the fedora machine or the grinder script to open up 6373 on the grinder console machine yet. Those need to be in your security group from the start. Please let me know of any road bumps you encounter with the process or the documentation. Thanks!
