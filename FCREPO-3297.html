FCREPO-3297 PUT and POST of BasicContainer does not support charset in Content-Type header

Description

This bug is seen when trying to create a basic container with a "charset" included in the "Content-Type" header.

For example, the following execution returns successfully:
$ curl -i -X PUT localhost:8080/rest/test -H'Link: <http://www.w3.org/ns/ldp#BasicContainer>; rel="type"' -H"Content-Type: text/turtle" -d "<> <http://example.com/title> 'Hello'"

However, by adding the charset parameter to the Content-Type, we get a 500 response:
curl -i -X PUT localhost:8080/rest/test -H'Link: <http://www.w3.org/ns/ldp#BasicContainer>; rel="type"' -H"Content-Type: text/turtle; charset=ISO-8859-1" -d "<> <http://example.com/title> 'Hello'"
