Description

The current codebase uses both the Jackson 1 and GSON libraries for handling JSON. In addition, Modeshape by default includes Jackson 2, which is excluded.

Ideally, we should use Jackson 2 included with Modeshape. If that is not possible for some reason, we should use a single JSON library.
