Description

There are several types in org.fcrepo.kernel.impl.utils.iterators that do nothing but create properly type-safe Iterators from pre-Java-generics JCR iterator types. These can be safely destroyed in favor of other idioms in client code, which will reduce the size of the codebase with no other changes.
