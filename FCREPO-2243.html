Description

See: https://www.w3.org/TR/json-ld/#flattened-document-form

The response from a request with this header: -H"Accept: application/ld+json; profile=\"http://www.w3.org/ns/json-ld#flattened\""

does not return the flattened JSON-LD profile. Instead, it returns the expanded JSON-LD profile. This is likely a problem with the underlying serialization library and may be solved with this issue: FCREPO-2242 Closed .
