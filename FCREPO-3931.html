Description

The "extensions" (-x) runtime configuration option of the Fedora 3 to 6 migration-utils migration tool, as originally requested and successfully tested in https://fedora-repository.atlassian.net/browse/FCREPO-3181, does not appear to be working.

I recently migrated a Fedora 3 object using the following command:

[foo@bar somedir]$ java -jar ../migration-utils-6.5.0-driver.jar -x -p=extensiontest.txt -t=legacy -f="http://someurl.nlm.nih.gov " -d=/foo/datastreams/2012/0316 -o=/foo/objects/2012/0316 -a=/bar/collections-small/data/ocfl-root
INFO 15:20:16.884 (PicocliMigrator) No working-dir option passed in - using current directory.
WARN 15:20:16.900 (InternalIDResolver) Index exists at "/bar/fedora6/headtest/index" and will be used.  To clear index, simply delete this directory and re-run the application.
INFO 15:21:08.133 (Migrator) Processing "nlm:nlmuid-0311156-bk"...
INFO 15:21:09.632 (Migrator) finished processing everything in pidlist - exiting.

This Fedora 3 object includes:

  • In-line XML datastreams DC, DMDINDEX, RELS-EXT with MIME type “text/xml”
  • Managed datastreams METS, MARCXML with MIME type “text/xml”
  • Other external datastreams of assorted MIME types, for which it is assumed this flag will have no effect

The in-line XML and managed datastreams are all migrated successfully to Fedora 6, but without any file extension.

Dan Field, 2024-05-21 16:18 UTC

Would you be able to share the FoxML for the datastream definitions and the relevant RELS-EXT for the object? The logic for creating file names uses the following:

 info:fedora/fedora-system:def/model#downloadFilename from RELS-INT
 LABEL from datastream meta
 Name of the datastream

In that order to generate a filename. However, if any of those contain a '.' then the extension will not be added.

Beyond that, there is a passing test for extensions within the ArchiveGroupHandler and you appear to be doing an Archival Group migration here as --atomic-resources is not specified on the command line you provided so there could be an issue with the test.

I’ll try and run my own test on some sample data too.
