Joshua Allan Westgard, 2016-09-02 19:10 UTC

I will need clarification on the difference between this and FCREPO-2166 Closed . The current dataset (when all the relationships are correctly built) includes a patent (pcdm:Object) and a single PDF (pcdm:File) for each patent. These are related objects, but I'm unclear on the intended difference between cross-object relationship and nesting. Is the idea to have direct containment? If that is what is meant by nesting we may need to add some different data for that.

Andrew Woods, 2016-09-02 19:14 UTC

Yes, "nested resources" would be DirectContainers, like:
/rest/parent/child

Cross-object relationships would be something like:
</rest/parent> pcdm:hasRelatedObject </rest/other>

Joshua Allan Westgard, 2016-09-02 19:19 UTC

Thanks, I will work on the other two for now then. If in the meantime nobody else has data that is more naturally nestable, I'm sure there is a way to nest some of this that would still make for a sensible dataset (i.e. meaningfully queryable by anyone using the data for testing in the future).
