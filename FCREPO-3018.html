FCREPO-3018 Binary mementos return incorrect Content-Type header

TypeStory
StatusOpen
PriorityMajor
ReporterDanny Bernstein
Created2019-06-28 17:48 UTC
Updated2019-06-28 18:00 UTC
Componentsf4-core, versioning
Affects versionsFedora 5.0.2
Labelsversioning

Description

To reproduce the issue:  

 

#Create a binary resource
curl -X PUT -u fedoraAdmin:fedoraAdmin -H "Content-Type: text/plain" --data-binary "this is a test" -i http://localhost:8080/rest/testbinary1
#Create a memento using a supplied body and memento-datetime header
curl -X POST -u fedoraAdmin:fedoraAdmin -H "Content-Type: text/plain" -H "Memento-Datetime: Fri, 5 Apr 2019 12:00:00 GMT" --data-binary "this is a test"  -i http://localhost:8080/rest/testbinary1/fcr:versions 
#Verify that the binary memento returns a Content-Type value of application/octet-stream rather than text/plain.
curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/testbinary1/fcr:versions/20190405120000 -i
