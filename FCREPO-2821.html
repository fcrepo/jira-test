Description

According to section 4.3.4, PUT requests to LDPCv (when implementations do not support them) shoudl return a 405 instead of the current 400 on:

curl -i -u fedoraAdmin:fedoraAdmin -XPUT -H"Content-Type: application/sparql-update" @patch.ru localhost:8080/rest/test4/obj/fcr:versions/new

Jared Whiklo, 2018-07-19 18:04 UTC

Danny Bernstein I believe this ticket is incorrect. The specification is referring to LDPCv which is the /fcr:versions endpoint. Your example above with /fcr:versions/new is PUTting an LDPRm which is disallowed by the specification but not with any requirements for responses.

Jared Whiklo, 2018-07-19 18:06 UTC

This ticket needs a function with @PUT specified in https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-http-api/src/main/java/org/fcrepo/http/api/FedoraVersioning.java to return a 405.

Situ, Longshou, 2018-07-19 18:44 UTC

Jared Whiklo I think we may not need to add the @ PUT method to FedoraVersioning.java. It'll return 405 by default if the PUT method isn't defined. And we've already added the tests here for both PUT and Patch: https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-http-api/src/test/java/org/fcrepo/integration/http/api/FedoraVersioningIT.java#L586-L599.

It seems like the issue here is how we want PUTing to memento to behave as the example in the spec with PUTing to "localhost:8080/rest/test4/obj/fcr:versions/new". But we may do nothing since as you said "...PUTting an LDPRm which is disallowed by the specification but not with any requirements for responses".

Jared Whiklo, 2018-07-19 20:15 UTC

Situ, Longshou you are correct. We do (at least I think) need to alter the FORWARD_COMPONENT_PATTERN as that would make GET requests to things like /fcr:versions/something fail with a 404 instead of a 400.

Situ, Longshou, 2018-07-19 20:55 UTC

Jared Whiklo It sounds good to me. I'll change the pattern for memento id in FORWARD_COMPONENT_PATTERN from one or more digits to one or more characters like

private final static Pattern FORWARD_COMPONENT_PATTERN = Pattern.compile(
            "(.*?)(/" + FCR_METADATA + ")?(/" + FCR_VERSIONS + "(/.+)?)?(/" + FCR_ACL + "(\\#\\w+)?)?$");
