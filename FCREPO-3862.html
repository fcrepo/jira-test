Description

This ticket is to add a configuration option to allow users to choose between upgrading existing objects (on write) to the current version of OCFL implemented by Fedora or leave them as the older version.

This uses the .setUpgradeObjectsOnWrite(true) flag described at https://github.com/UW-Madison-Library/ocfl-java#upgrading-ocfl-repositories
