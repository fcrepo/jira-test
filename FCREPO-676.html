Description

When generating triples for an object in the resource index, include a triple that specifies the PID namespace.

Requested by Janna Wemekamp -see http://sourceforge.net/mailarchive/message.php?msg_name=4BB65010.8040806%40gmail.com

For example:
$pid <fedora-model:hasPIDNamespace> 'c4oc'

The namespace and predicate will need to be decided. The Fedora model namespace seems appropriate as this includes other object properties, comments welcomed.
