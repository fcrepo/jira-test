POST/PUT requests may provide an interaction model, so a helper method should be added to populate a Link header with rel="type".

It would be helpful to user to provide a set of constants for interaction models defined by the specification, while also allowing for implementation specific models. The set of defined interaction models are:
* http://www.w3.org/ns/ldp#NonRDFSource
* http://mementoweb.org/ns#OriginalResource
* http://www.w3.org/ns/ldp#DirectContainer
* http://www.w3.org/ns/ldp#IndirectContainer
* http://www.w3.org/ns/ldp#DirectContainer
* http://www.w3.org/ns/ldp#Resource
