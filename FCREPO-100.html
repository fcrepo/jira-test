Description

Fedora currently tries to compensate internally if something fails while committing a change to the foxml and/or datastream files. This improvement would change that so the work occurs in a transaction. Goals include: simplifying the compensation code (mostly in DefaultDOManager) and having greater assurance that, when things go wrong (part of the overall transaction fails, power goes out, etc), storage comes up in a consistent state rather than requiring manual intervention.
