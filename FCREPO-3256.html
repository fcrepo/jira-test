Description

This task is to ensure that ghost nodes are immutable. In other words, once a ghost node, always a ghost node.
https://docs.google.com/document/d/1bzNvqctv_fzZxDYQFPSfc9_O_9EZl9iJ657dByzaKi0/edit#heading=h.o04fva3x471c

The following script shows that ghost nodes can currently be re-created as Fedora resources:
```
#!/usr/bin/bash

  1. Create 'a'
    curl -i -XPUT localhost:8080/rest/a
  1. Create 'a/b/c' ('b' is a ghost node)
    curl -i -XPUT localhost:8080/rest/a/b/c
  1. GET 'a/b' - expect 404
    curl -i localhost:8080/rest/a/b
  1. Create 'a/b' - expect 409 – but no!, it is a 201
    curl -i -XPUT localhost:8080/rest/a/b
  1. GET 'a/b' - expect 404 – but, no! it is a 200
    curl -i localhost:8080/rest/a/b
    ```
