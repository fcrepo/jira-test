Description

Modify the class org.fcrepo.client.utility.AutoPurger to optionally take as an argument the path to a file containing a list of PIDS of objects to be purged, in lieu of a single pid. Open the file, loop through the PIDs and purge each one, logging a message for each purge event.

Throw an exception if the file specified on the command line does not exist or cannot otherwise be read.

Update the fedora-purge.* scripts to accept the optional file parameter on the command line.
