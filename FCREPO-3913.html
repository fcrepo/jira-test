One way to filter out the latest tag would be:

# Fetch all tags from remote
git fetch --tags

# Get latest major release number
LATEST_MAJOR_RELEASE=$(git tag --sort=-creatordate | grep '^fcrepo-' | sed -E 's/^fcrepo-([[:digit:]]+)\..*/\1/' | sort -n | uniq | tail -n1)

# Get latest release tag
LATEST_RELEASE_TAG=$(git tag --sort=-creatordate | grep -E "^fcrepo-$LATEST_MAJOR_RELEASE\.[[:digit:]]+\.[[:digit:]]+$" | head -n1)

Might be possible to simplify the bash commands…
