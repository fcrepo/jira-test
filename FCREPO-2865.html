FCREPO-2865 Camel Toolbox should not index mementos

Depends onFCREPO-2804 Alter the event generated on inbound reference to a new ActivityStream type

Description

The creation of mementos generates creation events.  The triples comprising a mementos, unlike all other resources, use the subject of the original resource uri rather than the memento uri.  Since the camel toolbox listens to events and indexes changes to resources, it is probable that the indexed version of the original resource would contain the triples of all previous versions.  To avoid this state of affairs, the camel toolbox should check the headers of resources and ignore any Memento resources.  Furthermore, a note in both the camel documentation as well as the Messaging documentation should emphasize this point.
