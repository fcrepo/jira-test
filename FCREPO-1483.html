Description

InternalAuditor creates audit nodes which link to resources with URIs instead of references, so the link isn't removed if the resource is deleted. This is to support the use case of maintaining audit records for deleted nodes.

When the audit nodes that link to deleted nodes are accessed, there is an error when the URI pointing to the deleted node is treated as a reference and checked for being a Skolem.
