Description

This task is to refactor the fcrepo4-oaiprovider project to no longer need any of the classes in the org.fcrepo.oai.jql package:
https://github.com/fcrepo4-labs/fcrepo4-oaiprovider/tree/master/src/main/java/org/fcrepo/oai/jql

Where these classes are used (such as by: https://github.com/fcrepo4-labs/fcrepo4-oaiprovider/blob/master/src/main/java/org/fcrepo/oai/service/OAIProviderService.java) the SPARQL queries should be replaced by direct JQL queries.
