FCREPO-3252 Disallow creating mementos within the same second

TypeBug
StatusOpen
PriorityMinor
ReporterPeter Winckles
Created2020-03-17 13:13 UTC
Updated2021-07-07 17:07 UTC
Componentsf4-core
Affects versionsFedora 6.0.0
Labelsfcrepo-6.1.0
Is caused byFCREPO-3245 Retrieve mementos

Description

Mementos are granular to the second. F5 returns a 409 when multiple mementos are created within the same second. F6 currently allows it, but only the state of the last memento created is retrievable.

Example:

curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/mem-test -H "Link: <http://www.w3.org/ns/ldp#NonRDFSource>; rel=type" -v -H "Content-Type: text/plain" -X PUT --data-binary "testing"

curl -u fedoraAdmin:fedoraAdmin -X POST -v http://localhost:8080/rest/mem-test/fcr:versions && curl -u fedoraAdmin:fedoraAdmin http://localhost:8080/rest/mem-test -H "Link: <http://www.w3.org/ns/ldp#NonRDFSource>; rel=type" -v -H "Content-Type: text/plain" -X PUT --data-binary "testing-update" && curl -u fedoraAdmin:fedoraAdmin -X POST -v http://localhost:8080/rest/mem-test/fcr:versions
