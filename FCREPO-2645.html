Description

Currently you can't use fedora: namespaced properties but you can create fedora namespaced resources.

This ticket is to block interaction with any URI with /fedora: inside.

Use of the hasFedoraNamespace predicate can be useful
https://github.com/fcrepo4/fcrepo4/blob/master/fcrepo-kernel-api/src/main/java/org/fcrepo/kernel/api/RdfLexicon.java#L258-L259

Return a 409 Conflict with an appropriate explanation.
