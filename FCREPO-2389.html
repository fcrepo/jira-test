Description

This task is to update fcrepo-webapp-plus such that there is only one maven profile that is not active by default.
This profile turns web.xml configuration of AuthZ on.

The other components (audit, webac, rbacl, xacml, mint) should have example spring.xml configuration(s) along with documentation for describing:

  • how to enable these components and
  • how to reference such a configuration via system properties.

Andrew Woods Is the task here to provide a bunch of different spring configurations in different folders that someone can copy over the default and build to get their desired setup or is it to just document the sections of the various configuration files that need to be edited to enable the various features?

Andrew Woods, 2017-01-26 15:09 UTC

I was thinking about consolidating the various spring configuration files into a single one, with commented out sections for various modules. This would also be accompanied by some documentation, potentially in the fcrepo-webapp-plus readme.md, that describes who the meaning of the configuration elements and how/why to enable them.

I would like to:
1. get away from having to generate build artifacts for the permutations of optional modules, and
2. highlight to the community a more flexible approach to site-specific wiring of components.

I will also note that the actual implementation of this ticket may take on a different flavor once the details surface in the course of the work.
