Description

When using the web admin to add a managed datastream from a local file (using Firefox) the dialog which allows you to select the file is never removed, even after the file upload to Fedora has completed. This makes it appear as if the file upload is hung, but the datastream is actually created properly, the dialog box is simply not removed.

Bill Branan, 2010-08-18 19:53 UTC

Just a note that the upload capability in the web admin actually jumps out of the Flash/Flex world and makes use of javascript to allow the selection and upload of files. The reason for this departure is because currently Flash cannot handle file uploads over https. See http://bugs.adobe.com/jira/browse/FP-1044 and https://bugs.adobe.com/jira/browse/FP-201. If these issues are ever resolved, the file upload function of the web admin should be handled by Flex directly.
