Description

Fedora objects are created for policies by the FedoraPolicyStore class. Although currently only used for loading bootstrap policiesfrom files and for testing, the conversion of the policy name to a PID is not safe. Non-bootstrap-policy names are not correctly picking up the PID namespace, and there is no conversion for non-safe characters.
