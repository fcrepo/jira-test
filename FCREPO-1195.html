Description

Hi all,

I am working with fscu to try to migrate from legacy to akubra low level storage.

I configured both lls appropriately and run the command below.

/opt/fedora/fedora-3.6/fcrepo-store-util-0.1.0-SNAPSHOT/bin$ ./fcsu copy legacy akubra

Then after sometime (I think it uses a DB to stage the file names to transfer) I can see messages about the transfer progress, however I see messages, like the one at the end of the e-mail, very often after some examination it seems that objects that contain an xml entry for audit:auditTrail won't work and just be ignored by fscu.

Has anyone have some advice on how to make fscu work properly with those entries?

Thanks,
Javier
