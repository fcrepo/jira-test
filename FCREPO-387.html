MySQL, possibly other databases

Description

Fedora's ConnectionPool class (a wrapper around DBCP) doesn't allow one to configure a "validationQuery", which is a standard commons-dbcp configuration value. According to the following page, there is no default value for this, and since it's not set, it has the effect of disabling testOnBorrow and testOnReturn:

http://issues.apache.org/jira/browse/DBCP-71

This can cause periodic 500 errors on Fedora's front end when connection to the database become invalid.
