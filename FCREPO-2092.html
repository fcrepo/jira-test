Esmé Cowles, 2016-07-26 21:09 UTC

Not directly related to this issue, but it's possible to invert the member relation and use an inverse predicate. E.g., instead of doing "<col1> pcdm:hasMember <obj1>" you can instead do "<obj1> pcdm:memberOf <col1>". Then the IndirectContainer is located on the object, and creates the link from the object to the collection. The InboundReferences Prefer header can be used to retrieve the collection with all of the objects that link to it.

I have a sample script demonstrating this pattern here: https://gist.github.com/escowles/43e434979c9fd3762cb1ad1225655abf#file-10k-memberof-sh
