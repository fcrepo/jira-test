FCREPO-3730 Transactions that are marked as failed should immediately release locked resources

TypeImprovement
StatusOpen
PriorityMedium
ReporterPeter Winckles
Created2021-05-28 18:13 UTC
Updated2024-01-11 21:55 UTC
Componentscore, f4-core
Affects versionsFedora 6.0.0

Description

Currently, when a long-running tx fails, the resources that it locks are not release until the tx is rolledback. Because failed transactions can no longer be used, the resources that they lock should be immediately released.
