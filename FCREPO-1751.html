Description

fcrepo-webapp-plus is using the wrong version of various Spring schemata in its XML wiring, for example in src/rbacl/webapp/WEB-INF/classes/spring/auth-repo.xml. It is using 3 when it should be using 4. This is causing problems using it in various deployments, particularly with Jetty's Maven plugin for integration tests.
