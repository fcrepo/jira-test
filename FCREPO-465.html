Description

Because Fedora 2.2.4 uses Mulgara instead of Kowari, the OAIProvider (v1.1) isn't forward-compatbile. The tucana#before and tucana#after predicates have changed to mulgara#before and mulgara#after, so the date-related queries don't work.

Comments (1)

Chris Wilper, 2009-03-09 17:53 UTC

Fixed by updating these predicates in oaiprovider/branches/maintenance-1.1. OAIProvider 1.1.1 has been released with this change. Note that 1.1.1 it is not backward-compatible with Fedora 2.2.3 – it only works with Fedora 2.2.4.

Download OAIProvider 1.1.1 here:
http://downloads.sourceforge.net/fedora-commons/oaiprovider-1.1.1.zip

Source distribution:
http://downloads.sourceforge.net/fedora-commons/oaiprovider-1.1.1-src.zip

To upgrade from OAIProvider 1.1:

  • make a copy of your original WEB-INF/classes/proai.properties file
  • install the new web app in place of the old one
  • copy your old proai.properties back into WEB-INF/classes/
