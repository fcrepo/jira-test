Description

This task is to enable passing a file containing a list of resources as an argument into the import/export jar.

Note: this is not necessarily a phase-1 requirement.

Helpful design requirement:

Allow for a BagIt bag for all resources in a collection, and/or individual bags for each resource

  • One bag per request; if there are multiple resources, they are all in one bag
  • If you want a bag per resource, the utility must be called multiple times
