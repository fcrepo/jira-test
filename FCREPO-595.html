Environment

Mac OS X 10.6

Description

When running the Fedora installer and prompted to select the location of Fedora home directory, the installer warns that the directory is not empty, even when a new directory has just been created.

In fact, the directory isn't technically empty, but contains the hidden file .DS_STORE on OS X. However, this should simply be ignored.
