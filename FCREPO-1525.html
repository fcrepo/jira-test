Description

Requiring maven to use the migration-utils makes it less approachable.

Create a packaging that's easier to use, like a executable jar.

If possible, the configuration options could allow you to specify a spring xml configuration (either from a couple pre-configured or a custom one).

Of the pre-set configuration options, maybe we want to expose enough optional parameters to allow configuration of the most variable components.

The following seem to be the most likely simple parameters that would be overridden:

1. the destination fedora 4 repository URL
2. the source foxml directory and datastream store

If you think other things should be simplified, please write up tickets for those prerequisite simplifications. (ie, we could auto-detect the fedora 4 source files if you thought that were a barrier)
