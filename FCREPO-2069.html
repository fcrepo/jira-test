Description

When restoring a backup from a 4.5.1 repository, I often see this error and the restore fails:

ERROR 08:42:50.311 (FedoraRepositoryRestore) Problems restoring up the repository:
java.sql.BatchUpdateException: Batch entry 615 INSERT INTO MODESHAPE_REPOSITORY (ID, CONTENT) VALUES ('87a0a8c317f1e7jcr:system/mode:metadata', ?) was aborted. Call getNextException to see the cause.

Esmé Cowles, 2016-07-04 10:12 UTC

After some digging, it looks like the problem is that the metadata backup contains duplicate entries that all look like this:

{ "metadata" : { "id" : "87a0a8c317f1e7jcr:system/mode:metadata" } , "content" : { "key" : "87a0a8c317f1e7jcr:system/mode:metadata" , "properties" : { "" : { "workspaces" : [ "default" ] , "accessControl" : false } } } }

Removing the duplicate entry is not hard to do with a text editor, and I've created a prototype of a Java utility to automate this process: BackupFixer.java . After removing the duplicate entry, I've been able to restore backups successfully.
