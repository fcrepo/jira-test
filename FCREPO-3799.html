FCREPO-3799 allow for the concurrent creation of child resources

TypeNew Feature
StatusOpen
PriorityMinor
ReporterPeter Winckles
Created2022-01-13 18:19 UTC
Updated2022-01-13 18:47 UTC
Componentscore
Affects versionsFedora 6.1.1

Description

When you create a resource the resource and its parent are locked. This means that it isn't possible to concurrently create child resources in separate transactions because only one transaction can lock the parent. It would be nice if it was possible to lock the parent so that it could not be deleted, but still allow children to be concurrently created.
