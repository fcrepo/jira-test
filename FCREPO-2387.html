Description

In the HTML UI, when navigating to a binary resource that links to external content, the view should redirect to the description of the binary resource, not the binary itself.

For example:
> curl -i -X PUT -H"Content-Type: message/external-body; access-type=URL; URL=\"http://animal-dream.com/data_images/cow/cow8.jpg\"" "http://localhost:8080/rest/external"

In the HTML UI, navigate to the root of the repository, then click on the "external" link... the user should be redirected to the description instead of the external resource.

For comparison, create a managed binary resource and navigate to it in the HTML UI:
> curl -i -X PUT -H"Content-Type: image/png" --data-binary @image.png "http://localhost:8080/rest/internal"
