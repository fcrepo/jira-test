Description

This task is to update the the fcrepo/pom.xml to use the latest version of the DuraSpace checkstyle configuration: 1.0.1

The updated version of of the checkstyle rules reinstitutes a 120 character line length limit, with the exception of lines that match the following patterns:

  • ^package.*
  • ^import.*
  • http://
  • https://
  • @link
