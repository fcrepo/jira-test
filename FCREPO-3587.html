Description

It turns out that the default Guava EventBus is not asynchronous.

https://github.com/fcrepo/fcrepo/blob/87d9e428669b89a3c41218aa8e46bad699b72c2a/fcrepo-webapp/src/main/resources/spring/fcrepo-config.xml#L196

We could try to using the Async version instead: https://guava.dev/releases/snapshot/api/docs/com/google/common/eventbus/AsyncEventBus.html

Alternatively, I think that we could just ditch the event bus entirely and just use an executor service directly for our async processing. I haven't been able to identify a great alternative library.
