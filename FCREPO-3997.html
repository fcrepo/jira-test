I have bumped the versions of Amazon Linux and Postgres SQL to that the script will deploy without giving errors. I have moved the versions of software into variables.tf so that editing main.tf  should usually be unnecessary when updating versions in future.

 

I have reduced the number of variables one needs to supply: a user now needs to supply only the bucket name. Terraform will pick up default profile values (if the user has an AWS profile). Supplying the EC2 keypair is also optional - it always was - but the documentation isn’t clear on this.
