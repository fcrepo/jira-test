FCREPO-3540 fcrepo doesn't run on postgres when running on AWS RDS

Fix versionsFedora 6.0.0, fcrepo-6.0.0-alpha-2
ParentFCREPO-3142 Modeshape out, OCFL In.

Description

The problem is that we are trying to disable triggers in order to truncate the search tables when doing so requires super user control of the database.  In RDS, since AWS partially manages the instance, some super user permissions are not available to the root user.
