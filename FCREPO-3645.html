Description

In Fedora 5 when you try to PUT or PATCH to add a managed type it throws an Exception, even when the server is in RELAXED mode for updated some server managed properties.

Fedora 6 just ignores these triples silently, which could be a feature but is also a deviation from Fedora 5 behaviour.
