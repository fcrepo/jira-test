Description

Flyway DB manages DB migrations. (https://flywaydb.org/)

It can be used in a variety of ways. One way is to have it run on app startup and it will automatically apply any changes that have not been applied to the db. 
 
When you make schema changes, you create a new sql file for the migration
Otherwise, we'd need to provide sql scripts for users to run manually on upgrade
Some people prefer the manual approach rather than doing migrations as part of running the app.   
 
The approach taken will be discussed in the next Fedora Tech Meeting.
