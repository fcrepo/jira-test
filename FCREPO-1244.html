FCREPO-1244 Disallow the creation of the namespace: 'fcr'

Description

For example, a user should not be able to implicitly create a namespace with prefix: "fcr".
Such as, by updating a resource's property including the statement:
PREFIX fcr: <http://xmlns.com/my-fcr/>

The issue of creating the "fcr" namespace prefix can be seen when calculating the fixity of a versioned resource:
curl localhost:8080/rest/collection/image/fcr:versions/v0/fcr:fixity
