Description

This task is to create external, standalone tooling that exports RDF and optionally binaries from a running Fedora repository.
The output of running this tooling should result in file on the filesystem structured in the same way as the existing, message-driven tooling persists to disk:
https://github.com/fcrepo4-exts/fcrepo-camel-toolbox/tree/master/fcrepo-serialization

For context, this export tooling should be able to act as a counterpart to the import tooling defined in this ticket:
https://jira.duraspace.org/browse/FCREPO-1990
