Description

There are a lot of concepts exposed via headers which clients need to be able to interact with. It would be helpful to provide users with the Fedora defined/used values and make them easier to locate. This could include:

GET Prefer header relation values

  • http://fedora.info/definitions/fcrepo#PreferInboundReferences
  • http://www.w3.org/ns/oa#PreferContainedDescriptions
  • http://www.w3.org/ns/ldp#PreferContainment
  • http://www.w3.org/ns/ldp#PreferMembership
  • http://www.w3.org/ns/ldp#PreferMinimalContainer

Constants for versioning types

  • http://mementoweb.org/ns#TimeGate
  • http://mementoweb.org/ns#TimeMap
  • http://mementoweb.org/ns#OriginalResource
  • http://mementoweb.org/ns#Memento

Constants for link header rels

  • http://www.w3.org/ns/ldp#constrainedBy
  • http://fedora.info/definitions/fcrepo#ExternalContent
  • acl
  • original
  • timegate
  • timemap
  • describes / describedby

Constants for non-standard header names

  • Accept-External-Content-Handling
  • Accept-Datetime
  • Memento-datetime
  • X-State-Token
  • X-If-State-Token
  • etc
