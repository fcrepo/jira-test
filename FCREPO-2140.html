FCREPO-2140 Return to single-artifact builds for fcrepo-webapp

PriorityMinor

Updated2021-09-17 17:49 UTC

Componentsf4-core

Description

Having multiple artifacts for "one-click" demo operation and deployment into servlet containers is unnecessary, confusing to users, and results in a needlessly complicated release process.

One artifact, both usable as an executable and deployable as a web app, should be created.

Comments (3)

Andrew Woods, 2016-08-30 17:52 UTC

One complication to consider is that the one-click should (and currently does) include a pre-configured property for "-Dfcrepo.modeshape.configuration" that points to an actual configuration. We want the one-click to "just work".
However, the fcrepo-webapp war should not (and currently does not) include this property since we want users to choose their backend configuration (file-based, MySQL, PostgreSQL, etc).

A. Soroka, 2016-08-30 18:45 UTC

We can override the launcher class provided by the Maven plugin and supply our own custom logic for choosing (or not choosing) a config.
