I use the default docker image/start command with the following additions:

Running via a docker compose file with the following mount:

    volumes:
      - fedora-data:/usr/local/tomcat/fcrepo-home/data

How I create/delete this example container:

I have a wrapper CLI (node) that uses a POST command to create the container with a SLUG header wrapped in a transaction. The transaction is rolled back if the container fails to be created at the requested slug.

Create Commands:

  • POST to /fcr:tx
  • POST to path with slug header.
  • Either PUT to /fcr:tx/[id] or DELETE /fcr:tx/[id] depending if the POST was created at requested path

Delete Commands

  • DELETE path/to/container
  • DELETE path/to/container/fcr:tombstone

I was trying to migrate to the PUT command instead of the POST command to create LDP containers, when the POST command stoped returning the request slug in the path. When I tried the PUT command via curl, the 404 was returned.
