Description

Using a fresh Maven setup (empty local repository), Maven can not resolve dependencies for project org.fcrepo:fcrepo-common. Looks like there is an SSL issue with https://m2.duraspace.org/content/repositories/releases.

The repository is accessible via web browser but Maven always stops the resolving process with "peer not authenticated" error.

I tried to trick Maven into accepting all SSL with http://stackoverflow.com/questions/21252800/maven-trusting-all-certs-unlimited-java-policy, but this just leads to "unable to find valid certification path to requested target" error.
