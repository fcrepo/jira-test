FCREPO-2181 Exported resource filenames need to be escaped in an unambiguous manner

Description

Currently we replace colons with underscores... this causes a name collision if "test:test" and "test_test" exist. For this ticket use URLEncoder.encode(string, "UTF-8") and URLDecoder.decode(string, "UTF-8") on the filename (or path element).
