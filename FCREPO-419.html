Description

Fedora's server code currently uses three separate libraries for Base64 handling: O'Reilly Servlet (com.orielly.servlet.Base64Encoder/Decoder), Axis (org.apache.axis.encoding.Base64), and Commons Codec (org.apache.commons.codec.binary.Base64). Of these, Commons Codec's implementation is most geared toward generic use. Using commons-codec for this, in addition to FCREPO-418 Closed , will allow removal of the dependency on cos.jar.
