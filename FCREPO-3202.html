FCREPO-3202 Configuration option for default OCFL digest

Description

Add a configuration option which allows administrators to specify what digest algorithm fedora should tell the OCFL client to use for all files stored. It should default to SHA512.

At the moment, the ocfl client allows the algorithm to be specified as follows:
new OcflRepositoryBuilder()
.ocflConfig(new OcflConfig()
.setDefaultDigestAlgorithm(DigestAlgorithm.sha256))
May relate to https://jira.lyrasis.org/browse/FCREPO-3201
