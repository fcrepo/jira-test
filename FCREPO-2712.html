FCREPO-2712 GET with Prefer=InboundRefs on /fcr:metadata does not include InboundRefs

TypeBug
StatusOpen
PriorityMinor
Reporterkefo
Created2018-03-09 17:05 UTC
Updated2021-09-17 17:42 UTC
Affects versionsFedora 4.7.1

Environment

Tomcat, Postgres

Description

This gist shows two CURL requests, both of which set the Prefer header to include InboundReferences. The first is a GET request to a binary's /fcr:metadata resource. The output should include, I believe, a triple showing that this binary resource is the object (an Inbound Reference) of the resource that is the target of the second GET request in the gist. Line 183 demonstrates that the second resource certainly references the first resource in the gist.
