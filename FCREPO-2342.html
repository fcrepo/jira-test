FCREPO-2342 verification tool cannot handle exports performed with no binaries (-b flag)

Description

The verification tooling needs to handle exports with no binaries.

There is a boolean in the configuration object (config.bin) that should be checked when a binary resource is encountered in the original tree. If config.bin is True, the desintation location should be compared, but if config.bin is False, the resource will not be in the destination, so should be skipped.
