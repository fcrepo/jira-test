Description

eIn Fedora 5.1.0 we had the repository.json (a modeshape-ism) which provided a single location for configuring Fedora.

In Fedora 6.0.0 we are using system properties for configuration passed via the command line.  It would be nice to have a single location for all config rather than a peppering of system properties.

What does the configuration need to contain? Here's a starting list

  1. jdbc config for indices
  2. storage location (mount point, cloud storage configuration)
  3. other settings (such as auto versioning)
