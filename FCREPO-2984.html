Description

Once the fcrepo-upgrade-utils skeleton is ready, this task is to add support for transforming version representation from 4.7 format to 5.x format.  This will involve at the very least: 

  1. changing the subjects of the versioned rdf to the original resource URI.
  2. renaming the version file to the fedora:lastmodified formatted as RFC1123.
