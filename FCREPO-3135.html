FCREPO-3135 Refactor HTTP dependent aspects of CreateResourceService from kernel layer service

TypeStory
StatusOpen
PriorityMinor
ReporterBen Pennell
Created2019-11-20 14:16 UTC
Updated2021-09-17 17:42 UTC

Description

Refactor CreateResourceServiceImpl such that HTTP related aspects are contained by an http layer service rather than a kernel service. This includes inspection/manipulation of link headers, and could also involve translation of external ids. The result might be moving the service to http-common, or splitting it into multiple services, some in http-common and some in the kernel.
