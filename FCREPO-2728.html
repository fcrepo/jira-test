Description

In concert with FCREPO-2727 Closed we are moving our granularity for Memento Datetime to RFC-1123 which is seconds.

If someone tries to make a Memento with the same Datetime at the second granularity the server should return a 409 Conflict response.

When this issue is resolved the @Ignored on FedoraVersioningIT#testCreateTwoObjectsWithVersionsWithTheSameLabel() should be removed.
