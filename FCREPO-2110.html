Andrew Woods, 2016-08-10 01:27 UTC

This is only a configuration issue.
The problem for both running a fcrepo-webapp-plus locally, or via vagrant is that the following system property must be set as follows when using authorization:

JAVA_OPTS="${JAVA_OPTS} -Dfcrepo.modeshape.configuration=classpath:/config/servlet-auth/repository.json"
