FCREPO-1435 Version history container should be discoverable via Link header

Affects versionsFedora 4.0.0, Fedora 4.1.0

Description

The URI for the versions container should be advertised, where available, in a Link header similar to the the metadata container:

Link: <./fcr:versions>;rel="version-history"

This is following the patterns adhered to by LDP and the conventions outlined in RFC5829 (http://tools.ietf.org/html/rfc5829).
