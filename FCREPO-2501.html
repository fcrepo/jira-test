Andrew Woods, 2017-06-15 13:47 UTC

My understanding was that in order to re-import resources that were exported either with:

  • a user-provided predicate that associates the target resource with others repository resources that are outside of the hierarchy of the target resource or
  • with the "inbound" flag that also associates repository resources that are outside of the target resource's hierarchy, 

it is required to import the entire data directory that was exported, versus configuring the import to point at the target resource.

Is that your understanding, Esmé Cowles?

Esmé Cowles, 2017-06-15 13:58 UTC

Andrew Woods, Yes, that's my understanding.  If you import just the exported resource, you are likely not going to get all the resources exported (because the inbound triples are filtered out).  You may get placeholder resources created to make the links to those resources work, but the actual triples from that resource may not be loaded.
