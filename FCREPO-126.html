Description

Prior to CMDA, there were referential integrity constraints in the admin client that prohibited editing of certain datastreams(e.g., MethodMap, WSDL, DSInputSpec, etc.) in bdef/bmech objects. This refactoring feature MUST remove any remaining constraints from the admin client to conform with the looser coupling provided by CMDA.
