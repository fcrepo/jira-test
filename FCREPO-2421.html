Create: new AWS/S3 page
Create: Readme in 'fcrepo-configs/src/main/resources/config' that references the appropriate wiki pages.

In terms of content, the recommendations are:

  • Externalize configuration files, and include passwords directly therein
  • Only use system properties for passwords if you are fully comfortable with the risk of exposing that information to others who have access to the system.
