Description

The GitHub actions workflow “Rebuild latest release image version” seems to build Docker images in the deploy job, but never pushes them to Docker Hub.

The script build-and-push-to-dockerhub.sh from fcrepo-exts/fcrepo-docker used to build the Docker image, only pushes the Image to Docker Hub, when the command line flag --push as been specified. This flag is currently missing in the workflow.
