FCREPO-3674 migration-utils: add option to migrate HEAD version only

TypeStory
StatusClosed
ResolutionFixed
PriorityHigh
ReporterDanny Bernstein
AssigneeMichael Ritter
Created2021-03-16 17:44 UTC
Updated2022-11-16 17:57 UTC
Resolved2022-11-16 17:57 UTC
Componentsmigration-utils
Fix versionsmigration-utils-6.3.0

Description

Some users of migration-utils may not be interested in bringing their entire object histories with them during the migration.   Since the migration-utils migrate object history by default, the task here is to provide the option to migrate only the latest version of each datastream.

Comments (6)

Paul Trilsbeek, 2022-03-22 08:54 UTC

I’m also interested in this, but I would like to be able to choose for which datastream IDs to disregard the history (or for which ones to keep it). E.g. we have many objects with large numbers of POLICY (XACML) and RELS-EXT datastream versions, which I’m not particularly interested in keeping, but I would like to keep any versions of the main OBJ datastream.

Jakov M. Vežić, 2022-03-25 11:34 UTC

We are also interested in this feature, as well as in what Paul Trilsbeek is suggesting. There are some specific datastream IDs for which we have no interest in keeping the history and where we only need the latest/active datastream (TN - thumbnail and DC - Dublin Core being some examples).

Another feature which would be very welcome for us is to disregard some datastream IDs completely and ignore them for migration. For example, we have a FULL_TEXT datastream on nearly every object which we used for indexing purposes, but we will handle this differently once we migrate to F6, so that specific datastream becomes obsolete and is not needed for our migration. If you want, I can create a separate ticket for this.

Michael Ritter, 2022-04-25 20:07 UTC

PR available: https://github.com/fcrepo-exts/migration-utils/pull/185

This adds functionality for specifying datastream ids which should be migrated HEAD only, but not for ignoring datastreams. I believe we will need a separate ticket for that.
