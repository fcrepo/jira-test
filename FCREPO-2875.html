Description

Update the versioning documentation to explain the Accept-Datetime negotiation algorithm used by the community implementation in order to select which memento will be returned.

It goes roughly along the lines of: it will give you the nearest memento that is older (or the same age) as the datetime provided, unless the datetime is before the first memento, then you get the first memento
