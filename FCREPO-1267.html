Description

The fcrepo ontology (http://fedora.info/definitions/v4/repository#) contains properties that were used for the JMS event system before the 4.0.0 release. Those properties are no longer used by the eventing system, and they should be removed from the ontology.

The properties in question are: identifier, baseURL, eventType, properties and timestamp

See also: https://github.com/fcrepo4/ontology/issues/10
