Migrate all source code currently hosted under the fedora-commons project at sourceforge to github.

Vote passed on December 7th: http://www.mail-archive.com/fedora-commons-developers@lists.sourceforge.net/msg00990.html

Chris Wilper, 2011-01-18 17:03 UTC

Note: Git does not support empty directories, and prior to the migration, the build depended on a couple of them. These have been fixed in maintenance-3.4 and master. For example:

https://github.com/fcrepo/fcrepo/commit/d6f8a8baad7116f003277a8d132cc95475ca897d

Chris Wilper, 2011-01-18 17:05 UTC

Note: The maven-buildnumber-plugin does not support git. It has been disabled in our builds as part of the migration, in maintenance-3.4 and master:

https://github.com/fcrepo/fcrepo/commit/58fb71d649ae764c44e4517c22994df7bfcca938

Chris Wilper, 2011-01-18 17:10 UTC

Reopened due to problem discovered while spot-checking the 3.4.2 release: The removal of the buildnumber plugin was not complete: The $

{buildNumber}

and $

{timestamp}

variables still exist in Server.properties and Client.properties, but are not replaced with any values. Plan is to remove buildNumber entirely (and uses of it in the code), and to make sure timestamp is populated, possibly via another maven plugin. This needs to happen on maintenance-3.4 and master.

Chris Wilper, 2011-01-18 18:54 UTC

Resolved: all traces of buildNumber removed, and using standard $

{maven.build.timestamp}

variable to populate timestamp properties where needed.
