This task is to create a configuration class (ConfigurationProperties.java ?) that provides a means of:

  • collecting the currently dispersed System Properties into a centralized utility class
  • setting these properties either via Spring or System Properties

The current System Properties that are used within the code base are found in the following classes:

  • MetricsConfig.java
  • StreamingBaseHtmlProvider.java
  • FedoraBaseResource.java
  • FedoraSessionImpl.java
  • BNodeSkolemizationUtil.java
  • RdfLexicon.java
  • DefaultPropertiesLoader.java - this one can remain as it is
