Description

Currently acl:default (formerly acl:defaultForNew) as defined in https://github.com/solid/web-access-control-spec#acl-inheritance-algorithm

The task here is to ensure that ACLs on containers  that are intended to be inherited by child resources must use the acl:default predicate.  In other words, apply parent ACLs to a resource only if it contains an acl:default predicate.
