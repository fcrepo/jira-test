Description

The current behavior of dissemination machinery is to URL-encode datastream addresses if the entire dissemination URL contains "=(". This is a pretty simple-minded test and makes the use of 'E' datastreams less flexible than otherwise might be the case. The test can be made more subtle.

Comments (5)

A. Soroka, 2012-05-14 07:07 UTC

The current test for URL-encoding is:

dissURL.indexOf("=(") != -1

Changing this to:

dissURL.indexOf("(" + bindingKeyPattern + ")") > 0

will create the following changes in behavior:

Input pattern 1:
dissURL?queryparameter=(bindingKey)

Old output pattern:
dissURL?queryparameter=URL-encoded-datastream-URL

New output pattern:
Same.

Input pattern 2:
dissURL/(bindingKey)

Old output pattern:
dissURL/NON-URL-encoded-datastream-URL

New output pattern:
dissURL/URL-encoded-datastream-URL

Input pattern 3:
(bindingKey)

Old output pattern:
URL-encoded-datastream-URL

New output pattern:
NON-URL-encoded-datastream-URL

The immediate advantage is that using datastream URLs as part of the ultimate dissemination URL becomes practical. This allows for the storage of service addresses as external datastreams, and the form of action against them to be encoded in dissemination metadata.
