Description

The Audit requirements includes guidlines for the properties and classes to use for recording audit information:

https://wiki.duraspace.org/display/FF/Audit+Service+PROV-O+vs+PREMIS

This ticket is to document the RDF that will be used to record audit events and gather community feedback:

  • Verify that these guidelines cover all of the required information in the Audit specification
  • Create a wiki page documenting the classes, properties and values that will be used
  • Post a message to the fedora-tech mailing list asking for feedback on the wiki page

I've created a PR for adding a new ontology defining some audit types that aren't defined in PREMIS:

https://jira.duraspace.org/browse/FCREPO-1422

This includes four event types suggested by UCSD that aren't present in PREMIS: metadata modification, content modification, derivative creation and indexing. It also includes two OWL Classes for internal and external events.

I've updated the wiki pages that list the types and RDF vocab examples to use the new terms:

https://wiki.duraspace.org/display/FF/Audit+Service+Repository+Events+and+Agents
