Description

This task is to change the body of a 404 response from the current low-level text to what was found in Fedora 5.

Currently, if a resource localhost:8080/test does not exist, the 404 body is:
```
Error: org.fcrepo.persistence.api.exceptions.PersistentItemNotFoundException: info:fedora/test
```

This text could be improved by changing it to:
```
Resource at /text not found
```
..and if the resource used to exist, and a tombstone is there now:
```
Discovered tombstone resource at /test, departed: 2020-03-26T14:42:19.747-04:00
```
