Description

In the use of a DirectContainer or IndirectContainer the object in the triple
?subject ldp:hasMemberRelation ?object becomes the predicate in subsequent inserted triples.

So while we block RDF that contains
?subject fedora:somePredicate ?object
or
?subject ldp:container ?object

We are NOT blocking
?subject ldp:hasMemberRelation fedora:somePredicate
or
?subject ldp:hasMemberRelation ldp:contains

In a DirectContainer, this means that when a new child is added to the DirectContainer we will have caused the server to add a Server Managed Triple to the DirectContainer.
