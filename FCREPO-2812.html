FCREPO-2812 406 (Unacceptable) should be returned by LDPRv when there are no LDPRms

Description

If no LDPRm is appropriate to the Accept-Datetime value, an implementation should return a 406 (Unacceptable).

To reproduce: 

1. create an LDPRv:

curl -X PUT http://localhost:8080/rest/versioned_resource 

2. Perform get on the resource with Accept-Datetime header

curl -v -X GET http://localhost:8080/rest/versioned_resource  -H "Accept-Datetime: Thu, 1 Jan 1970 00:00:00 GMT"

Confirm the result is 404 (there are no LDPRm).  The status should be 406 according to the spec (section 4.1.1)
