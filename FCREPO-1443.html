FCREPO-1443 fcrepo-client should use Link rel="describedby" header for description

Created2015-04-07 18:58 UTC
Updated2016-02-20 00:03 UTC

Componentsf4-java-client
Affects versionsFedora 4.2.0

Description

The Java client should inspect the headers of NonRDFSources to find where the description is, rather than adding fcr:metadata to the end of the NonRDFSource URI.

When creating a NonRDFSource or doing a HEAD on it, there will be a Link rel="describedby" header indicating the URI of the description.
