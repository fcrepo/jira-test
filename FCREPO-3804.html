Environment

Linux, Docker

Description

The Camel reindexing endpoint provided a usage message with examples. The generated links in those examples should contain the services hostname in the URLs. When running in a Docker environment resolving the local hostname fails, leading to unresolvable URLs e.g:

Configured REST endpoint: 0f4c88fb87f6:9080/reindexing

How to reproduce

$ git clone git@github.com:fcrepo-exts/fcrepo-camel-toolbox.git
$ cd fcrepo-camel-toolbox/docker-compose
$ docker-compose up
$ curl localhost:9080/reindexing

Ralf Claussnitzer, 2022-02-07 13:31 UTC

It seems the docker host name and portmappings are opaque for containerized applications. An easy way to avoid the misguiding usage message is to mention docker and the fact that the endpoint URL might be actually localhost:9080 (docker-compose default).

There is a common but undocumented way by checking for the existence of the .dockerenv file.
