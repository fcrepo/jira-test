FCREPO-2445 FedoraDatasetImport relies on fcr:import endpoint

Description

In fedora-sample-datasets, the top level "main" directory datasets can no longer be loaded using the instructions in the README because FedoraDatasetImport.java uses the fcr:import endpoint, which no longer exists in recent versions of Fedora (e.g., 4.7.2). Not sure exactly when it went away. The "additional datasets" can be successfully loaded because they use fcr:restore.
