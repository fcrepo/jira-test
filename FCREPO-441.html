Description

This idea has been stewing for quite some time. However, it did not make the 3.0 cut in the interest of time. People continue to ask for this, or something like it. See Ben O'Steen's recent blog post

http://oxfordrepo.blogspot.com/2008/05/internal-object-relationships-in.html

This needs to be nailed down and implemented. The basic idea is a datastream where relationships emanating from datastreams can be asserted in a Fedora-recognized way. We talked at one time on the developer's list about the difference between RELS-INT and just relaxing RELS-EXT to allow for datastream assertions. No formal decision was made on this. That's where it stands.
