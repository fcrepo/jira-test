Description

Resource headers should be validated before writing and after reading. https://jira.lyrasis.org/browse/FCREPO-3560 adds validation logic that is applied when OCFL objects are reindexed. A subset of this logic, `HeadersValidator`, should be applied to resource headers as part of the normal operation of Fedora to ensure that does not produce or interact with corrupt objects.
