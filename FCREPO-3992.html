Jared Whiklo, 2025-02-07 02:25 UTC

More digging, we check for the expected serialization file extension. If it has that extension, then we attempt to “upgrade” it. If it doesn’t we just copy it over.

So maybe this is not as big a deal as I thought, but I still think we should not be saying the file is “upgraded” if we just copy it. I’ll look to just change the logging messages.
