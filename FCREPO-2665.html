Description

I wasn't able to perform a sanity build (mvn clean install) in Windows 10 due to some integration tests in fcrepo-kernel-modeshape failing. A few of them were failing because the last modified date for binaries was not updating all of the time (tests were flapping). This seems to affect only non-hyper-visor based windows install. Ben Pennell, Aaron Birkland and Yinlin Chen have wrestled with the issue.
