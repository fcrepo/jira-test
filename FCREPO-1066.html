Description

Maven builds (mvn compile) are currently failing due to two issues:

1) The git-site dependency was on a SNAPSHOT version, and the snapshot has been deleted. Change to use a released version (0.3.1) as fcrepo-misc does.
2) The use of m2e's lifecycle-mapping "plugin" incorrectly listed it directly under plugins. It's not an actual plugin, so builds fail if it's there and maven can't find it in any repository. Just having it in the pluginManagement section is sufficient.
