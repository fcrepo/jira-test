Added branch here:
https://github.com/fcrepo4-exts/fcrepo-webapp-plus/tree/fcrepo-1821

By default it seems that authentication has to be explicitly defined. Using the jetty-console plugin I can get closer but only by adding in the jettyXml plugin jetty-console-log4j-plugin and setting up a jetty-web.xml or jetty-console.xml and passing them via command line.

java -jar target/crepo-webapp-plus-4.4.1-SNAPSHOT-jetty-console.jar --jettyXml jetty-console.xml

or

java -jar target/crepo-webapp-plus-4.4.1-SNAPSHOT-jetty-console.jar --jettyWebXml jetty-web.xml

Not much documentation on this plugin.

I tried to add the jetty-web.xml to the individual WEB-INF directories for each profile, but that breaks the setting up jetty for integration testing.
