Description

I have a "collection" object and a number of "member" objects. The member objects each have a predicate (e.g., info:fedora/fedora-system:def/relations-external#isMemberOfCollection) relating them to the collection but the collection object does not have a predicate enumerating its members. I would like to be able to use the import-export tool to export/import the collection and its members.
