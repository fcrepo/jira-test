FCREPO-1228 ActiveMQ Broker won't start when configured via Spring Bean

Description

Sample Spring Bean Broker set-up is invalid.

Putting an activemq.xml to $FEDORA_HOME/server/config/spring somehow interferes with the default broker instantiation. The broker won't start if configured the Spring way. Using default broker instantiation via Messaging Module (configured via fedora.fcfg) works fine.
