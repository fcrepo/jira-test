Peter Winckles, 2020-02-17 20:31 UTC

The problem here is that the path to the sidecar file it's trying to load is computed differently on reload than when it's originally written.

AbstractRDFSourcePersister calculates that path from the id "test/child" to create the path "child.json", selecting the path part after the final slash character. However, on reload FedoraToOCFLObjectIndexUtilImpl maps the id "test_child" (which is the OCFL id of the same object) to "test_child.json". On reload, the subpath code does not generate the same path because the OCFL object id does not have a slash in it, because slashes in fedora ids are converted to underscores when they're turned into OCFL ids.
