FCREPO-1900 Prefer Jena Node to Jena Resource

Description

We are using Jena's Resource type in places in which we should be using Jena's Node type. The use of Resource should be limited to places for which a genuinely natural Model context is available. Places (and APIs/SPIs) where there is no such context, or where one is artificially created just to translate Nodes into Resources should be altered to simply use Nodes.
