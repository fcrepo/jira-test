FCREPO-4004 Allow system managed predicates on non-binary containers

Description

From Chris Colvard at https://github.com/fcrepo-exts/fcrepo-upgrade-utils/pull/63

When migrating my fedora repository I saw that ebucore:filename statements were being dropped from my non-binary resources. I realized that my application has been using a predicate that fedora 6 is now treating as server managed for binary resources. This PR only treats the binary properties as server managed when they appear in fcr:metadata resources attached to binary resources. This allows my migration to succeed without negatively affecting binary resources.
