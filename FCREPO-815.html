ReviewBoard requires a local copy of the repository to work...so I set up a cron job to pull from github every 30 mins. Looks like it works...here's an example review, where I posted the diff of the most recent commit to the repo: https://review.duraspace.org/r/23/

This functions, but it's probably worth considering, if we move to github, whether to just use its built-in code review capability. It looks pretty nice, and doesn't require people to generate diffs...
