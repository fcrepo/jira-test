Stephen Bayliss, 2011-12-06 15:12 UTC

Would seem sensible to try and resolve this as part of upgrading to a newer version of Mulgara

Stephen Bayliss, 2011-12-12 17:44 UTC

Looks like this is due to an NPE thrown only in DEBUG by org.mulgara.store.xa.FreeList.Phase

Method use() attempts to append to stack, which is set to null on construction.

Reported on Mulgara lists.

http://lists.mulgara.org/pipermail/mulgara-general/2011-December/001222.html

Stephen Bayliss, 2011-12-12 17:45 UTC

Work-around is to make sure logging is not set to DEBUG for that package, if it is set to DEBUG elsewhere.

So in logback.xml, have:

<logger name="org.mulgara.store.xa" additivity="false" level="WARN">
<appender-ref ref="FEDORA"/>
</logger>

Should we maybe include that in the distribution, until the Mulgara NPE is fixed?

Stephen Bayliss, 2011-12-15 03:30 UTC

Looks like there will be a new version of Mulgara out very shortly with this fixed, so probably should upgrade to that for 3.6

Stephen Bayliss, 2012-01-03 14:41 UTC

Mulgara issue - fixed by upgrading to Mulgara 2.1.12
