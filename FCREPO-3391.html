Description

The Fedora 5->6 migration path will require transforming the exported Fedora 5 repository into Fedora-aware OCFL.  In order to perform this transformation,  we need to be able to read a Fedora 5 export.  The plan is that fcrepo-upgrade-utils will perform this task of transforming Fedora 5 into Fedora 6 compliant OCFL.

The task at hand here is to pull all the code that facilitates reading the Fedora 5 export generated by fcrepo-import-export into a separate library that can be referenced by both fcrepo-import-export and fcrepo-upgrade-utils.

Included in this task is any refactoring of fcrepo-import-export that will be necessary in order to achieve this objective.

If it makes sense to do so,  we might break this task into two parts:  1) create the library and a set of interfaces.  2) do the refactoring to extract an migrate the code from fcrepo-import-export into the new library.
