FCREPO-3825 Timemap has incorrect ACL link header

Description

Currently a GET of an resource’s TimeMap (i.e. ending in /fcr:versions) returns a Link header like

Link: <http://localhost:8080/rest/test_authz/773a30c9-ac26-4ad4-8479-b8eb428b7791/fcr:versions/fcr:acl>; rel="acl"

This is incorrect as the Timemap and Mementos share the same ACL as the LDPRv (versioned resource).

It also is inaccessible and returns

HTTP/1.1 400 Bad Request
Date: Thu, 12 May 2022 17:10:34 GMT
Set-Cookie: JSESSIONID=node0146lkctpzzlysgsua5eivrx2b33.node0; Path=/
Expires: Thu, 01 Jan 1970 00:00:00 GMT
Set-Cookie: rememberMe=deleteMe; Path=/; Max-Age=0; Expires=Wed, 11-May-2022 17:10:34 GMT; SameSite=lax
Content-Type: text/plain;charset=utf-8
Content-Length: 86
Server: Jetty(9.4.44.v20210927)

Path is invalid: /test_authz/773a30c9-ac26-4ad4-8479-b8eb428b7791/fcr:versions/fcr:acl
