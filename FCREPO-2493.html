FCREPO-2493 verification tool should respect legacyMode option

Description

Now that the import-export tool can overwrite server-managed triples if the repository supports it, the current tool should be able to verify RDFsources in imports.

For repositories that do not support server-managed triple modification, it would be nice if the verification tool respected the legacyMode parameter in the import-export tool config, and did not attempt to verify server-managed triples.

In short, it would be nice if the verification tool had a legacyMode of its own.
