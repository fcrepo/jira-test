Description

ActiveMQ 3.6.0 introduced support for leveldb, promising up up to 5x speed increase over the default KahaDB.

It also introduces ~17MB in additional dependencies. I believe a performance-driven deployment of ActiveMQ is going to be run apart from Fedora anyway, so I think we're ok removing the dependency from fedora.war.
