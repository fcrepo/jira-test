Description

This task is to remove the leaked JCR details exposed when GETting a tombstone.
To reproduce:

  • curl -XPUT localhost:8080/rest/collection
  • curl -XDELETE localhost:8080/rest/collection
  • curl -XGET localhost:8080/rest/collection
    —
    Discovered tombstone resource at /collection {jcr:createdBy=bypassAdmin, jcr:primaryType=fedora:Tombstone, jcr:created=2016-04-17T12:45:49.151-04:00}

    —

As a follow-on ticket, an HTML UI view for tombstones should be created.
